# 예시: 네이버 블로그 붙여넣기 묶음 (가상 빵집 '밀과결')

> **가상 가게** 예시다. 글 내용은 `examples/blog-sample-output-B09.md`를 묶음으로 바꾼 것이다. 빈칸 2곳(맛 한 줄, 전화번호)은 사장님 답을 받아 채웠다고 가정한 **가상 값**이다. 형식 규칙은 `guides/upload/index.md` 6).
> 폰 화면(390px)에서 본 모습: `gallery/paste-bundle.png`

에이전트는 아래 블록을 **메시지 하나에 블록 하나씩** 보낸다. 사장님은 블록을 길게 눌러 복사 → 앱에 붙여넣기만 한다.

## 블록 0. 순서표 (보기만 하세요)

```
오늘 블로그 글 올리는 순서 (1~2분)

사진 폴더: [구글 드라이브 링크] 블로그_12월1일

1. 사진 폴더 열기 → 전체 선택 → 폰에 저장
2. 블로그 앱 → 글쓰기
3. 제목 칸에 [제목] 붙여넣기
4. 본문에 [본문] 붙여넣기
5. 본문 맨 끝에서 사진 버튼 → 사진1부터 사진7까지 순서대로 한 번에 선택
6. 장소 버튼 → "밀과결" 검색해서 추가
7. 태그 칸에 [태그] 붙여넣기 → 발행
8. 올라간 글 주소를 복사해서 보내 주세요

(선택) 【 】 줄은 그대로 둬도 돼요. 시간 되시면 그 줄만 인용구로 바꾸셔도 좋아요.
AI 활용 표시: 끄기 (사진 7장 모두 사장님이 찍은 사진)
```

## 블록 1. 제목

```
정발산동 밀과결 겨울 한정 밤 크루아상, 하루 40개만
```

## 블록 2. 본문

```
안녕하세요, 정발산동 빵집 밀과결입니다.
12월 1일 화요일부터 겨울 한정 '밤 크루아상'을 굽기 시작해요.
하루 40개만, 11시·15시에 20개씩 나옵니다.

【밤은 저희가 직접 까서 졸여요】

밤 크림은 사 온 페이스트가 아니라 저희가 껍질을 벗겨 냄비에 졸여 만들어요.
단맛보다 밤 맛이 먼저 나게 했어요.

【두 번 주저앉고 세 번째에 잡았어요】

사실 처음 두 번은 실패했어요.
크림이 너무 묽어서, 굽고 나면 빵 가운데가 푹 꺼졌어요.
밤 졸이는 시간을 40분에서 1시간 10분으로 늘리고 나서야 모양이 섰어요.
그래서 하루에 만들 수 있는 양이 40개예요.

【가격과 판매 안내】

· 밤 크루아상 1개 4,800원
· 하루 40개, 11시·15시에 20개씩 나와요
· 판매 시작 12월 1일(화), 2월 말까지 예정 (끝나는 날은 정해지면 이 글에 고쳐 둘게요)
· 예약은 받지 않아요

남은 수량이 궁금하시면 전화 주세요. 031-000-0000
영업은 화요일부터 일요일까지 오전 8시~오후 7시, 월요일은 쉬어요.

아래 사진은 단면, 밤 까는 손, 졸이는 밤, 처음 실패한 빵, 오븐에서 막 나온 트레이, 진열대, 가게 입구 순서예요.
```
