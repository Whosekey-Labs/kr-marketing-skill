# 예시 입력: 가상 동네 빵집 '밀과결'

> 이 가게는 예시를 위해 만든 **가상 가게**다. 실제 가게·주소와 관계없다.

## 브랜드 프로필 (요약)

| 항목 | 값 |
|---|---|
| 상호 | 밀과결 |
| 업종 | 베이커리(동네 빵집, 1인 + 아르바이트 1명) |
| 지역 | 경기 고양시 일산동구 정발산동 (상권: 주거지 동네형) |
| 영업 | 화~일 8:00~19:00, 월요일 휴무 |
| 채널 등급 | 핵심: 네이버 플레이스·블로그, 인스타 / 확장: 클립, 당근 / 제외: 링크드인(B2B 아님) |
| 블로그 말투 | V3 담백한 안내형 (사장님 요청: 이모티콘 거의 없이, "저희") |
| 금지 표현 | "건강빵", "속 편한", "다이어트", 다른 빵집과 비교 |
| 내 요청사항 | 가격은 꼭 글로도 적기 |

## 이번 소재 (사장님이 보낸 메모)

- 12월 1일(화)부터 겨울 한정 '밤 크루아상' 판매 시작. 1개 4,800원.
- 하루 40개만 굽는다. 11시·15시에 20개씩 나온다.
- 밤은 사장님이 직접 껍질 벗겨 졸인다. 처음 두 번은 크림이 너무 묽어서 빵이 주저앉았다. 세 번째에 밤 졸이는 시간을 40분에서 1시간 10분으로 늘려서 잡았다.
- 판매는 2월 말까지 예정. 날짜는 아직 확정 아님.
- 예약은 받지 않는다. 전화 문의는 가능: [직접 입력: 매장 전화번호]

## 사진 (이번에 새로 찍음)

1. 크루아상 단면 (밤 크림 보이게)
2. 밤 껍질 벗기는 손
3. 냄비에서 졸이는 밤
4. 실패한 첫 번째 빵(주저앉은 모양)
5. 오븐에서 나온 트레이
6. 진열대에 놓인 모습 + 가격표
7. 매장 입구

## 레퍼런스 분석 (요약)

| 항목 | 같은 업종 글(카페 겨울 신메뉴) | 다른 업종 글(꽃집 새 꽃 입고) |
|---|---|---|
| 제목 틀 | 계절 + 메뉴 이름 | "이번 주 들어온 ○○" |
| 첫 3문장 | 출시 소식 한 줄 → 메뉴 소개 | 사진부터, 글은 짧게 |
| 소제목 | 없음, 사진이 흐름 | 없음 |
| 사진 | 10장 안팎, 첫 사진 바로 | 20장, 글 500자 |
| 사장님 경험 | 거의 없음 | 입고 과정 한 줄 |
| 마무리 | 매장 방문 + 지도 | 주문 문의 |

빌릴 것: 사진이 흐름을 이끄는 구성, 첫 사진을 빨리. 우리가 더할 것: 실패 두 번 이야기(경험), 하루 수량·나오는 시각.
