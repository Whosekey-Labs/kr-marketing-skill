# 숏폼 갤러리 견본 사진 출처

이 폴더의 영상(`G1.mp4`~`G9.mp4`)과 장면 시트(`G1.png`~`G9.png`, `feel-calm.png`·`feel-info.png`·`feel-fast.png`)는 `tools/shortform.py build`·`frames --sheet`로 만든 **견본**이에요.

- 브랜드는 모두 가상이에요: 동네 빵집 '밀과결', 디저트 카페 '오후세시반', 필라테스 '코어담필라테스', 인테리어 '틈새집 인테리어'. 가격·이야기·시간도 견본용으로 지은 것이고 실제 가게 정보가 아니에요.
- 사진은 위키미디어 공용(Wikimedia Commons)의 **CC0 1.0(퍼블릭 도메인 기증)** 사진이에요. 상업 이용·수정이 가능하고 출처 표시 의무는 없지만 아래에 적어 둬요. 실제 가게 사진이 아니고, 실제 가게는 사장님 사진·영상으로 바꿔요.
- G2(전후 비교)의 '전'과 '후'는 **서로 다른 공간** 사진이에요(영상 마지막 장면에도 적음). 실제로는 같은 자리·같은 각도로 찍은 전·후 사진을 써요.
- G6(사장님이 직접 말하기)은 얼굴 영상 자리에 사진을 넣은 견본이에요. 실제로는 가운데 띠에 사장님 얼굴 영상이 들어가요.
- 브랜드 로고가 크게 보이는 사진은 뺐어요. 작은 글자(간판·기구 상표 등)가 남은 사진이 있을 수 있어요.
