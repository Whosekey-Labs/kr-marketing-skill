# 학원·교습소·과외 검수표 (`academy.md`)

> 법률 자문이 아닙니다. 2026-11-17에 확인한 조문·공식 자료로 만든 점검표입니다. 최종 판단은 사장님(필요하면 담당 기관·전문가)이 합니다.

## 꼭 지킬 것 (요약)
- 모집 광고에 교습비(기타 경비 포함)를 쓴다.
- 등록(신고) 번호, 학원·교습소 이름, 교습과목을 쓴다.
- 교습소는 "학원"이라고 쓰지 않는다.
- 합격 실적·"성적 보장" 같은 과장은 근거 없이 쓰지 않는다.

아래 표는 걸렸을 때나 확인이 필요할 때 자세히 본다.

## 1. 적용 대상

- 학원 설립·운영자, 교습소 교습자, 개인과외교습자.
- **인쇄물·인터넷 등**으로 학습자를 모집하는 광고 전부(블로그, 인스타, 숏폼, 전단, 당근 모두).
- 성인 취미 클래스·공방 원데이 클래스가 학원법상 학원·교습소인지는 등록 여부로 판단한다. 모르면 "학원 등록(또는 교습소 신고)을 하셨나요?"부터 묻는다.
- 원생 사진·후기를 쓰면 `guides/compliance/children.md`, `guides/compliance/common.md`도 같이 켠다.

## 2. 금지·의무

| # | 규칙 | 근거(조문·고시) | 확실도 |
|---|---|---|---|
| 1 | 모집 광고에 **교습비등(교습비 + 기타경비)**을 표시한다 | 학원법 제15조③ | 확실 |
| 2 | 모집 광고에 **① 등록(신고) 번호 ② 학원·교습소 명칭 ③ 교습과정(교습과목)**을 표시한다 | 시행령 제16조의3 | 확실 |
| 3 | 교습비를 거짓으로 표시하거나, 표시·등록한 금액보다 더 받으면 안 된다 | 제15조④ | 확실 |
| 4 | 명칭은 "○○학원", "○○ 수학 교습소" 형식. 교습소가 "학원"이라 쓰면 안 된다 | 제15조의2 | 확실 |
| 5 | 학습자 모집 때 **과대·거짓 광고** 금지 | 제17조①9호 | 확실 |
| 6 | 합격률·"서울대 ○명" 같은 실적 광고를 직접 정한 학원법 조문은 없다. 과대·거짓 광고(제17조①9호)와 표시광고법 제3조(거짓·과장, 실증 책임)로 판단 | 학원법 제17조, 표시광고법 제3·5조 | 확인 필요 |

**광고 필수 표시 칸(카드뉴스·블로그 끝에 그대로 붙인다)**

```
[직접 입력: ○○학원 / ○○ 교습소] | 등록번호 [직접 입력: 제○○호]
교습과정: [직접 입력: 예) 초등 수학]
교습비: [직접 입력: 월 ○○원] / 기타경비: [직접 입력: 교재비 ○○원 등]
```

- 금액은 교육청에 **등록·신고한 금액 그대로** 쓴다. 에이전트는 금액을 지어내지 않는다.
- 기타경비가 없으면 "기타경비 없음"으로 쓴다(사장님 확인 후).

## 3. 자주 걸리는 문장 → 고친 문장

| 원문 | 걸리는 이유 | 고친 문장 | 확실도 |
|---|---|---|---|
| "겨울방학 특강 모집! 상담은 DM 주세요" | 교습비·등록번호·명칭·과정 없음 | "겨울방학 특강 모집" + 위 필수 표시 칸 | 확실 |
| "월 19만원" (실제 등록 금액은 다름) | 교습비 거짓 표시 | "월 [직접 입력: 등록한 교습비]원" | 확실 |
| (교습소인데) "○○영어학원" | 명칭 위반 | "○○ 영어 교습소" | 확실 |
| "가격은 전화로 문의하세요" | 교습비 미표시 | 교습비·기타경비를 본문에 적는다 | 확실 |
| "3개월이면 무조건 1등급" | 과대 광고 + 결과 보장 | "[직접 입력: 수업 방식] 수업을 합니다" | 확실 |
| "합격률 98%", "서울대 10명 합격" | 근거 없으면 거짓·과장, 사업자가 실증해야 함 | 근거 자료(연도·대상 인원·계산 방법)가 있으면 함께 적는다. 없으면 삭제 | 확인 필요 |
| "지역 1등 학원" | 근거 없는 1등 | 삭제하거나 근거 출처를 적는다 | 확실 |
| "원생 후기: ○○이(○○초) 성적 30점 올랐어요" + 사진 | 개인정보·초상권 + 효과 주장 | 보호자 동의가 있을 때만, 이름·학교는 가리고 실제 사례 그대로 | 확실 |

## 4. 채널별 주의

- **블로그**: 글 끝에 필수 표시 칸을 고정 문단으로 넣는다. 시리즈 글마다 매번 넣는다.
- **카드뉴스**: 마지막 장에 필수 표시 칸. 첫 장에 "특가"만 크게 쓰고 금액을 빼면 안 된다.
- **숏폼(릴스·숏츠·클립)**: 영상 끝 화면 또는 설명란 첫 줄에 필수 표시. "DM으로 가격 문의"만 쓰지 않는다.
- **당근·플레이스 소식**: 짧은 글도 모집 광고면 같은 규칙.
- **문자·카톡 모집 안내**: `guides/compliance/ad-messaging.md` 같이 적용.
- 뒷광고·가짜 후기·원생 사진은 `guides/compliance/common.md` 참조.

## 5. 제재 수준

| 위반 | 제재 |
|---|---|
| 교습비등·필수사항 표시 누락 | 과태료 1차 50만원 / 2차 100만원 / 3차 200만원(시행령 별표5) |
| 교습비 거짓 표시 | 과태료 1차 100만원 / 2차 200만원 / 3차 300만원(시행령 별표5, 법 제23조 최대 300만원) |
| 모집 시 과대·거짓 광고(학원) | 등록 말소 또는 1년 이내 교습정지 사유(제17조①9호). 처분 기준은 시·도 조례 |
| 교습소·개인과외 위반 | "그 밖에 이 법을 위반한 경우"로 처분 |
| 실적 광고 거짓·과장 | 표시광고법 제재(시정명령, 과징금 등). `common.md` 참조 |

## 6. 확인 필요 (단정 금지)

1. 합격률·합격자 수 광고의 실무 기준(시·도 조례, 교육청 지침, 공정위 사례).
2. 성인 대상 클래스가 학원법 적용 대상인지(등록 여부에 따라 다름).
3. 과대·거짓 광고 처분의 지역별 기준(시·도 조례).

사장님 안내 예: "합격 실적은 근거 자료가 있으면 쓸 수 있지만, 기준이 지역 교육청마다 달라요. 자료(연도·인원)를 주시면 그대로 적고, 없으면 빼 둘게요."
