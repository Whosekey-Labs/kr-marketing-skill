# 주류 검수표 (`alcohol.md`)

> 법률 자문이 아닙니다. 2026-11-17에 확인한 조문·공식 자료로 만든 점검표입니다. 최종 판단은 사장님(필요하면 담당 기관·전문가)이 합니다.

## 꼭 지킬 것 (요약)
- "술 서비스·무료" 같은 경품 표시를 하지 않는다(해당 여부 확인 필요).
- 마시라고 권하거나 부추기지 않는다. 운전·작업 중 음주 장면 금지.
- 미성년자·임산부를 등장시키지 않는다.
- 술이 건강·체력에 좋다는 말을 하지 않는다.
- 술 택배·온라인 판매는 원칙적으로 안 된다(전통주 등 예외).

아래 표는 걸렸을 때나 확인이 필요할 때 자세히 본다.

## 1. 적용 대상

- 술집·포차·와인바·이자카야, 술을 파는 식당, 양조장·전통주 업체.
- 광고할 수 있는 사람은 **주류 제조면허·판매업면허를 받은 사람과 수입업자뿐**이다(국민건강증진법 제8조의2①).
- 영업신고를 한 음식점이 세무서에 주류 판매 신고를 하면 판매업면허를 받은 것으로 본다(주류면허법 제5조②). 그래서 술집·식당은 광고 주체가 될 수 있다.
- **조문 정정**: 주류 광고 제한은 국민건강증진법 **제8조의2**다. 제8조(금연·절주운동, 경고문구)로 적힌 자료는 틀렸다.

## 3. 자주 걸리는 문장 → 고친 문장

| 원문 | 걸리는 이유 | 고친 문장 | 확실도 |
|---|---|---|---|
| "오늘 같은 날은 소주 한잔 해야죠!" | 음주 권장 | "오늘 저녁 메뉴: [직접 입력: 안주 이름]" | 확실 |
| "불금엔 무조건 달려야죠" | 음주 권장·미화 | "금요일 [직접 입력: 영업시간]까지 영업해요" | 확실 |
| "첫 방문 소주 1병 서비스" | 경품 표시 소지 | 술 대신 음식 혜택: "첫 방문 [직접 입력: 음식 서비스]" | 확인 필요 |
| "리뷰 쓰면 하이볼 무료" | 술을 경품으로 주는 표시 소지 + 리뷰 이벤트 | 리뷰 이벤트는 먼저 권하지 않는다. 사장님이 원하면 `common.md` 2-5 조건대로, 혜택은 술이 아닌 것: "[직접 입력: 음식·무알코올 음료 혜택]" | 확인 필요 |
| "막걸리는 장 건강에 최고" | 건강 효과 주장 | "[직접 입력: 양조 방식·재료]로 빚은 막걸리" | 확실 |
| "하이볼 마시고 스트레스 날리세요" | 정신건강에 도움 표현 | "레몬을 직접 짜 넣은 하이볼" | 확실 |
| 숏폼 원샷·폭탄주 장면 강조 | 음주 미화·권장 | 술잔은 정물로만, 마시는 장면 빼고 음식 위주 | 확실 |
| "대학 신입생 환영 이벤트" | 청소년 행사·미성년자 연상 | 이벤트 삭제. 성인 대상 메뉴 소개로 대체 | 확실 |
| "와인 택배 주문 DM 주세요" | 통신판매 제한(전통주 외) | 매장 방문·음식 배달과 함께만 안내 | 확실 |

## 4. 채널별 주의

- **블로그**: 메뉴·분위기 소개 중심. 술은 "있는 메뉴"로만 쓰고 마시자고 권하지 않는다. 경고문구 넣는 위치는 글 끝 고정 문단으로 둔다(필요 여부는 확인 필요).
- **카드뉴스**: "한잔해", "취하자" 같은 큰 글씨 카피 금지. 술 사진만 있는 장보다 안주 사진을 앞에 둔다.
- **숏폼**: 마시는 장면, 원샷, 취한 모습, 미성년자로 보이는 출연자 금지. 차·운전 장면과 술을 같이 보여 주지 않는다. 음악 가사도 음주 권장인지 본다.
- **인스타 협찬**: 인플루언서에게 맡기면 협찬 광고 레이블 + 연령 제한 설정을 요청한다.
- **문자·카톡**: 술 할인 문자는 `guides/compliance/ad-messaging.md` 같이 적용.
- 뒷광고·가짜 후기·손님 얼굴은 `guides/compliance/common.md` 참조.

## 5. 제재 수준

- 복지부장관이 **시정 요구 또는 광고 금지 명령**을 할 수 있다(제8조의2③).
- 명령을 따르지 않으면 **1년 이하 징역 또는 1천만원 이하 벌금**(제31조의2제1호).
- 위반 자체를 바로 처벌하는 조항은 없다. **명령 불이행을 처벌하는 구조**다.
- 플랫폼: Meta 협찬 콘텐츠 정책 위반 시 콘텐츠 삭제 등.

## 6. 확인 필요 (단정 금지)

1. 음식점 인스타 술 사진 게시물에 경고문구 표기가 실제로 요구되는지.
2. "소주 1병 서비스" 같은 술 서비스가 경품 표시 금지에 해당하는지.
3. 2025-03-18 개정 법률(경고그림 도입 등)의 시행 시점.
4. 유흥주점(청소년유해업소)의 광고 노출 제약 조문.

사장님 안내 예: "술 서비스 이벤트는 법 해석이 아직 분명하지 않아요. 안전하게 음식 서비스로 바꾼 문장을 드릴게요. 꼭 술로 하고 싶으시면 관할 보건소에 한 번 물어봐 주세요."
