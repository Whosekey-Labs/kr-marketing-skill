# 화장품 검수표 (`cosmetics.md`)

> 법률 자문이 아닙니다. 2026-11-17에 확인한 조문·공식 자료로 만든 점검표입니다. 최종 판단은 사장님(필요하면 담당 기관·전문가)이 합니다.

## 꼭 지킬 것 (요약)
- 화장품을 약처럼 말하지 않는다(아토피·여드름 치료, 재생, 탈모 방지 등).
- 기능성 심사를 받지 않았으면 미백·주름 개선·자외선 차단을 말하지 않는다.
- 의사·병원이 추천·개발했다는 표현, "최고·최상", 보톡스·필러 같은 시술 표현 금지.
- "천연·유기농"은 기준을 채웠을 때만. 효능 주장은 근거 자료가 있어야 한다.

아래 표는 걸렸을 때나 확인이 필요할 때 자세히 본다.

공통 사항(뒷광고 표시, AI 가상인물, 저작권, 개인정보)은 `guides/compliance/common.md` 참조.

## 1. 적용 대상

| 업종·상황 | 켤지 | 메모 |
|---|---|---|
| 화장품을 파는 미용실·피부샵·네일숍 | 켠다 | 화장품법은 "영업자 또는 판매자" 적용 |
| 스마트스토어·인스타 화장품 셀러 | 켠다 | 인터넷 광고 포함(시행규칙 별표5) |
| 수제 비누·화장품 공방 | 켠다 | |
| 시술에만 쓰고 팔지 않는 화장품 홍보 | 켠다 | 적용 여부 확인 필요. `medical-misleading.md`도 함께 |
| 의약품·의약외품 | 끈다 | `medical-device.md`의 약사법 부분 |

## 2. 금지·의무

| # | 규칙 | 근거(조문·고시) | 확실도 |
|---|---|---|---|
| 1 | 의약품으로 오인할 표시·광고 금지 | 화장품법 제13조①1호 | 확실 |
| 2 | 기능성화장품이 아닌데 기능성으로 오인, 또는 심사 결과와 다른 광고 금지 | 제13조①2호 | 확실 |
| 3 | 사실과 다르거나 소비자를 오인하게 할 광고 금지 | 제13조①4호 | 확실 |
| 4 | 의사·약사·의료기관이 추천·공인·개발·사용한다는 표시 금지 | 시행규칙 별표5 제2호 | 확실 |
| 5 | 배타적 "최고·최상" 금지 | 별표5 제2호 | 확실 |
| 6 | 경쟁상품 비교는 기준 명시. 다른 제품 비방 금지 | 별표5 제2호 | 확실 |
| 7 | 객관적으로 확인되지 않은 효능 광고 금지 | 별표5 제2호 | 확실 |
| 8 | 사실에 관한 광고는 실증해야 함. 요청 시 15일 안에 제출 | 제14조 | 확실 |
| 9 | 천연·유기농 표현은 식약처 고시 기준 충족 필요 | 식약처 지침(제13조①3호는 2025-01-31 삭제) | 확인 필요 |
| 10 | 지침 별표1 금지 표현(아래 목록) | 식약처 「화장품 표시·광고 관리 지침」 2024.5판 | 확인 필요(최신판 대조) |

**식약처 지침 별표1 금지 표현**(2024.5판):

| 분류 | 금지 표현 |
|---|---|
| 질병 | 아토피, 건선, 여드름(기능성 심사 표현 제외), 기미·주근깨, 항염, 항균, 살균, 해독, 소양증 |
| 피부 | 디톡스, 가려움 완화(보습으로 인한 일시적 완화 제외), 홍조 개선, 뾰루지 개선, 상처·흉터 제거, 셀룰라이트, 붓기, 다크서클, 콜라겐 증가 |
| 모발 | 발모, 탈모방지·치료, 속눈썹이 자란다 |
| 생리활성 | 혈액순환, 피부재생·세포재생 |
| 신체 개선 | 다이어트, 체중감량, 지방분해, V라인(연출 의미 병기 시 제외), 가슴 확대 |
| 의약품 연상 | 메디슨, 드럭, 코스메슈티컬, 치유 |
| 범위 밖 | 보톡스, 필러, 레이저·카복시 등 시술 표현, 명현현상, "부작용 전혀 없음", 무(無)스테로이드, "OO 의사가 개발한 화장품", "OO 병원 추천", 줄기세포 |
| 기능성 미심사 제품 | 미백·화이트닝·주름개선·자외선차단 |

## 3. 자주 걸리는 문장 → 고친 문장

| 원문 | 걸리는 이유 | 고친 문장 | 확실도 |
|---|---|---|---|
| "여드름 진정 앰플로 트러블 치료" | 질병 표현·의약품 오인 | "피부를 촉촉하게 가꿔 주는 앰플 [직접 입력: 제품 특징]" | 확실 |
| "두피 재생 탈모 케어 샴푸" | 재생·탈모 금지 표현 | "두피를 깨끗하게 씻어 주는 샴푸" (탈모 기능성 심사 제품이면 심사 문구 그대로) | 확실 |
| "피부과 원장님이 쓰는 코스메슈티컬" | 의사 사용 표시·의약품 연상 | "[직접 입력: 제품 이름과 성분]" | 확실 |
| "물광 필러 크림" | 시술 표현 | "물광 연출 크림" | 확인 필요 |
| "셀룰라이트 분해 바디오일" | 신체 개선·지방분해 | "바디 보습 오일" | 확실 |
| "아토피 아기도 OK" | 질병 표현 | "[직접 입력: 사용 연령·피부 자극 시험 결과가 있으면 그대로]" | 확실 |
| "업계 최고의 미백 크림" (미심사) | 최고 표현 + 기능성 오인 | 기능성 심사 제품이면 심사 문구만. 아니면 삭제 | 확실 |
| "부작용 전혀 없는 순한 크림" | 범위 밖 표현 | "사용 중 이상이 있으면 사용을 멈추고 상담해 주세요." | 확실 |
| "줄기세포 앰플" | 범위 밖 표현 | 삭제 | 확실 |

## 4. 채널별 주의

- 블로그: 사용 후기에 "트러블이 나았어요" 같은 질병 개선 경험을 쓰지 않는다.
- 카드뉴스: 전후사진으로 미백·주름 효과를 보여 주면 기능성 오인. 기능성 심사 여부를 먼저 확인.
- 숏폼(릴스·숏츠·클립): 자막·말 모두 점검. "재생", "치유"를 말로 하는 것도 광고다.
- 상세페이지: "실증할 수 있는 사실만" 쓴다. 시험 결과가 있으면 출처와 조건을 함께.

## 5. 제재 수준

| 위반 | 제재 | 근거 |
|---|---|---|
| 제13조 위반 | 1년 이하 징역 또는 1천만 원 이하 벌금(병과 가능) | 화장품법 제37조 |
| 별표5 가·나·카목(의약품 오인, 기능성 오인, 비방) | 판매·광고 업무정지 1차 3개월, 2차 6개월, 3차 9개월 | 시행규칙 별표7 |
| 별표5 다~차목 | 1차 2개월, 2차 4개월, 3차 6개월, 4차 12개월 | 시행규칙 별표7 |
| 실증자료 미제출 | 광고 중지명령 | 제14조 |

## 6. 확인 필요 (단정 금지)

1. 식약처 지침 최신판: 2024.5판을 확인함. 2025-01-21 개정 이력이 있어 대조 필요.
2. 판매하지 않고 시술에만 쓰는 화장품 홍보에 화장품법 제13조가 적용되는지.
3. "물광", "V라인" 같은 연출 표현은 연출 의미를 함께 쓸 때만 예외(지침 기준).

사장님 안내 예: "사장님, '재생'·'여드름' 같은 말은 화장품 광고에 쓸 수 없어서 바꿨어요. 이 제품이 기능성 심사를 받았다면 심사받은 문구를 알려 주세요."
