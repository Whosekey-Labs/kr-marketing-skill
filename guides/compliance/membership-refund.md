# 회원권·요금·환불 표시 검수표 (`membership-refund.md`)

> 법률 자문이 아닙니다. 2026-11-17에 확인한 조문·공식 자료로 만든 점검표입니다. 최종 판단은 사장님(필요하면 담당 기관·전문가)이 합니다.

## 꼭 지킬 것 (요약)
- 헬스·요가·필라테스 광고에 서비스 내용과 요금 체계를 쓴다.
- 같은 광고에 중도 해지 때 남은 기간 환불 기준을 쓴다.
- "4주 -8kg", "100% 감량 보장" 같은 수치는 증명 자료가 있을 때만.
- 회원 전후사진·후기는 실제 회원 것만, 대가를 줬으면 표시한다.
- 운동으로 질환이 낫는다고 말하지 않는다.

아래 표는 걸렸을 때나 확인이 필요할 때 자세히 본다.

## 1. 적용 대상

| 업종·상황 | 켤지 | 광고에 넣을 것 |
|---|---|---|
| 헬스장(체력단련장)·종합체육시설·수영장·체육교습업 | 켠다 | 요금체계 + 중도해지 환불기준 |
| 요가·필라테스 | 켠다 | 요금체계 + 중도해지 환불기준 |
| PT샵(체력단련장·체육교습업에 해당할 때) | 켠다 | 같음 |
| 피부관리·체형관리실 | 켠다 | 광고 필수항목은 없음. 요금·환불기준은 사업장 게시물·설명서·계약서 중 한 곳 |
| 상호·주소·전화 같은 기본정보만, 또는 이미지 광고만 | 제외 | 고시 적용 제외(Ⅲ.5.가) |
| 다이어트 효과 수치를 말할 때 | 켠다 | 실증 근거 |

- 고시는 방송 외 **모든 광고(인터넷 포함)**에 적용된다(Ⅲ.3.나). 블로그·인스타·숏폼·전단 모두.
- 공통 사항(뒷광고, 가상인물, 저작권, 개인정보, 가짜 후기, 리뷰 이벤트)은 `guides/compliance/common.md` 참조.

## 2. 금지·의무

| # | 규칙 | 근거 | 확실도 |
|---|---|---|---|
| 1 | 체육시설(헬스·요가·필라테스 등) 광고에 **제공 서비스 내용과 요금체계(기본요금 + 추가 비용)** 표시 | 표시광고법 제4조, 「중요한 표시·광고사항 고시」(공정위고시 제2025-9호) 체육시설 운영업종 | 확실 |
| 2 | 같은 광고에 **중도해지 시 잔여기간 환불기준** 표시 | 같은 고시 | 확실 |
| 3 | 사업장 게시물·등록신청서에는 보증보험 가입 여부·내용도(헬스·요가·필라테스) | 같은 고시 | 확실 |
| 4 | 피부·체형관리: 요금체계·환불기준을 사업장 게시물·설명서·계약서 중 한 곳에. 광고 필수항목은 없음 | 같은 고시(C-8 기준 Ⅳ.6.나) | 확실 |
| 5 | 고시 항목 번호(Ⅳ/Ⅴ 표기) | 자료마다 번호가 다름(Ⅳ.8.나·Ⅳ.6.나 또는 Ⅴ.8.나·Ⅴ.6.나) — 고시 원문으로 확인 | 확인 필요 |
| 6 | "4주 -8kg", "100% 감량 보장" 같은 효과·수치는 사업자가 **실증**해야 함 | 표시광고법 제3·5조 | 확실(개별 문구 판단은 확인 필요) |
| 7 | 회원 전후사진·후기는 실제 경험과 맞아야 하고, 대가를 줬으면 표시 | 추천·보증 심사지침(`common.md`) | 확실 |
| 8 | 운동시설이 질환 개선(오십견·디스크 등)을 내세우면 의료법 제56조① 위험 | `guides/compliance/medical-misleading.md` | 확인 필요 |
| 9 | 다이어트 식품을 함께 팔며 "체지방 감소" 등 표현 | `guides/compliance/food-origin.md`, `health-food.md` | 확실 |

**전후 사진 위험 등급**: 운동·미용의 전후 사진은 의료·문신처럼 "높음"이 아니다. 실제 회원의 실제 사진, 동의, 대가 표시만 지키면 된다. 과장된 보정이나 수치 보장은 6번으로 판단한다.

**광고 필수 표시 칸(헬스·요가·필라테스)**

```
[직접 입력: 상품명] 기본요금 [직접 입력]원 / 추가 비용 [직접 입력: 운동복·락커·등록비 등, 없으면 "없음"]
제공 서비스 [직접 입력: 이용 시간·횟수·포함 내용]
중도해지 환불기준 [직접 입력: 사장님이 쓰는 환불 규정 그대로]
```

- 금액·환불 규정은 사장님 자료 그대로. 에이전트가 만들지 않는다.

## 3. 자주 걸리는 문장 → 고친 문장

| 원문 | 걸리는 이유 | 고친 문장 | 확실도 |
|---|---|---|---|
| "PT 10회 특가! 가격은 DM으로" | 요금체계·환불기준 없음 | "PT 10회 [직접 입력]원 (추가 비용 [직접 입력]) / 중도해지 환불: [직접 입력]" | 확실 |
| "오늘만 회원권 50% 할인" | 기본요금·추가비용·환불기준 없음 | "회원권 정상가 [직접 입력]원 → [직접 입력]원, 기간 [직접 입력]" + 환불기준 | 확실 |
| "필라테스 1:1 월 9만원~" (추가 비용 숨김) | 요금체계(추가 비용) 누락 | "월 [직접 입력]원, 추가 비용 [직접 입력]" | 확실 |
| "환불 불가" (환불기준 대신) | 중도해지 환불기준 표시 의무 | 실제 환불 규정을 그대로 적는다 [직접 입력] | 확인 필요 |
| "한 달 만에 -10kg 보장, 실패 시 전액환불" | 실증 필요, 조건 누락 | 실제 회원 사례가 있으면 "[직접 입력: 회원 동의 받은 실제 기록], 결과는 사람마다 다릅니다" | 확실 |
| "회원님 실제 후기: 지방흡입 안 하고 뱃살 쏙" | 의료 오인, 대가 있으면 표시 필요 | "[직접 입력: 실제 후기 원문] (회원 동의, [대가 있으면 '수강료 할인 받음'])" | 확인 필요 |
| "허리 디스크 좋아지는 필라테스" | 질병명 + 개선 효과 단정(의료 오인 위험, medical-misleading 참고) | "허리 주변 근육을 쓰는 수업 [직접 입력]. 통증이 있으면 병원 진료를 먼저 받으세요." | 경고, 쓰지 않음 |
| "평생회원 특가" (환불 조건 없음) | 환불기준 누락 | 기간·환불기준을 함께 [직접 입력] | 확실 |

## 4. 채널별 주의

- **블로그**: 이벤트·가격 글 끝에 필수 표시 칸. 가격표 이미지에만 넣지 말고 본문 글자로도.
- **카드뉴스**: 가격 장 바로 다음 장(또는 같은 장)에 추가 비용·환불기준. 작은 글씨로 숨기지 않는다.
- **숏폼**: "가격은 DM" 금지. 설명란 첫 부분 또는 영상 끝 화면에 필수 표시.
- **플레이스·당근 소식**: 가격·할인이 나오면 같은 규칙. 기본정보·사진만 올리는 소식은 제외.
- **문자·카톡 회원 안내**: `guides/compliance/ad-messaging.md`.

## 5. 제재 수준

| 위반 | 제재 | 근거 |
|---|---|---|
| 중요정보(요금체계·환불기준) 미표시 | 과태료 1억원 이하, 임원·종업원 1천만원 이하 | 표시광고법 제20조②1호 |
| 실증자료 미제출 | 과태료 1억원 이하 | 표시광고법 제20조 |
| 효과 과장 등 부당광고 | 시정명령, 관련매출액 2% 이하 과징금(산정 곤란 시 5억원 이하), 2년 이하 징역 또는 1억5천만원 이하 벌금 | 제7·9·17조 |

## 6. 확인 필요 (단정 금지)

1. 중요정보고시 항목 번호(Ⅳ인지 Ⅴ인지). 내용(광고에 요금체계·환불기준)은 확실.
2. 개별 효과 문구·전후 사진이 과장인지는 사례별 판단.
3. PT샵·1인 스튜디오가 고시의 체육시설 업종(체력단련장·체육교습업 등)에 들어가는지 신고 업종 확인.

사장님 안내 예: "사장님, 헬스·필라테스 광고에는 요금과 중도해지 환불기준이 꼭 들어가야 해요(빠지면 과태료 대상). 지금 쓰시는 환불 규정을 사진이나 글로 주시면 그대로 넣을게요."
