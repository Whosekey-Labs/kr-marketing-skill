# 의료 오인(비의료인 업소) 검수표 (`medical-misleading.md`)

> 법률 자문이 아닙니다. 2026-11-17에 확인한 조문·공식 자료로 만든 점검표입니다. 최종 판단은 사장님(필요하면 담당 기관·전문가)이 합니다.

## 꼭 지킬 것 (요약)
- 의료기관이 아니면 치료·시술·진료 같은 의료 표현을 쓰지 않는다.
- 의료기기·약을 쓰거나 점빼기·문신 같은 의료행위를 광고하지 않는다.
- "재생·필링·여드름 관리" 같은 경계 표현은 확인 필요로 두고 고친 문장을 기본으로 쓴다.
- 필라테스·요가·운동의 '자세 교정 운동'은 막지 않는다(운동·자세교정 광고는 의료광고 아님, 대법원 2009도7455). 단 '디스크' 같은 질병명 + 교정·치료 효과 단정(예: "디스크 교정 필라테스")은 의료 오인 위험 — **[경고, 쓰지 않음]**(`guides/industries/10-fitness.md`와 같은 판정).
- 리뷰 이벤트·체험단 리뷰는 만들지 않는다.

아래 표는 걸렸을 때나 확인이 필요할 때 자세히 본다.

공통 사항(뒷광고 표시, AI 가상인물, 저작권, 개인정보)은 `guides/compliance/common.md` 참조.

핵심: 의료인이 아닌 업소는 의료광고 자체를 할 수 없다(의료법 제56조①). 광고 문구가 "의료기기·의약품을 썼다", "의료행위를 했다"는 증거가 되기도 한다.

## 2. 금지·의무

| # | 규칙 | 근거(조문·고시) | 확실도 |
|---|---|---|---|
| 1 | 의료인이 아니면 의료행위·의료기관·의료인 정보를 광고할 수 없음 | 의료법 제56조① | 확실 |
| 2 | 피부미용업은 의료기기·의약품을 쓰지 않는 피부상태분석·피부관리·제모·눈썹손질 | 공중위생관리법 제2조①5호 | 확실 |
| 3 | 미용업자는 의료기구·의약품을 쓰지 않는 순수한 화장·피부미용만 | 공중위생관리법 제4조④ | 확실 |
| 4 | 점빼기·귓볼뚫기·쌍꺼풀수술·문신·박피술 및 유사 의료행위 금지 | 공중위생관리법 시행규칙 별표4 제4호 | 확실 |
| 5 | 의료기기·의약품 사용 금지 | 같은 별표4 | 확실 |

| 7 | 공중위생관리법에는 '광고' 조항이 없음. 광고 내용은 의료법·표시광고법·화장품법·의료기기법으로 판단 | 공중위생관리법 현행본 | 확실 |
| 8 | "치료·재생·필링·여드름 관리" 같은 경계 표현이 의료광고인지. 광고 문구만으로 제56조① 유죄가 확정된 대법원 판례는 찾지 못함(처벌례는 실제 무면허 의료행위가 함께 있던 경우). 그래도 피부샵 시술 표현은 무면허 의료행위의 증거가 되므로 이 스킬은 차단 | 판례·복지부 해석, 공중위생관리법 시행규칙 별표4 | 확인 필요(차단은 이 스킬 기준) |
| 8-1 | 운동·자세교정 광고는 의료광고가 아니다. 의료행위 광고라는 점은 검사가 증명해야 함 | 대법원 2009도7455 | 확실 |
| 9 | 체험단 블로거가 병원을 자기 명의로 홍보하는 글도 비의료인 의료광고 | 의료법 제56조① | 확실 |

**쓰지 않는 단어**(이 업종 광고에서): 치료, 시술(의료 의미), 완치, 재생 치료, 박피, 필링(화학적), 레이저, MTS, PDT, 고주파 의료기기, 점·사마귀 제거, 지방 분해, 흉터 개선.
**대신 쓰는 말**: 관리, 케어, 진정(보습 의미), 정돈, 각질 관리, 왁싱, 스타일링.

## 3. 자주 걸리는 문장 → 고친 문장

| 원문 | 걸리는 이유 | 고친 문장 | 확실도 |
|---|---|---|---|
| "여드름 치료 전문 관리실" | 비의료인 의료광고(제56조①) | "트러블 피부 진정 관리 [직접 입력: 관리 이름]" | 확인 필요 |
| "압출+재생 치료로 흉터 개선" | 의료행위 표방 | "피부 결 정돈 관리. 흉터·질환은 피부과 상담을 권해드려요." | 확인 필요 |
| "MTS 니들 시술", "PDT 레이저 관리" | 의료기기 사용 자백(별표4) | 삭제. 실제 하는 관리만 쓴다 | 확실 |
| "아쿠아필링·화학적 필링(박피)" | 박피술 금지(별표4) | "각질 정돈 관리" | 확인 필요 |

| "고주파 의료기기 리프팅" | 의료기기 사용 | 삭제. 기기는 `medical-device.md`로 다시 확인 | 확실 |
| "레이저 제모" (왁싱숍) | 의료행위 오인 | "왁싱" | 확실 |
| "회원님 오십견 좋아진 후기" (필라테스·헬스) | [경고] 질환명 + 개선 효과는 의료행위 오인 소지(운동 광고 자체는 2009도7455로 허용) | "어깨를 편하게 움직이는 운동 [직접 입력: 수업 내용]. 통증·질환은 병원 진료를 먼저 받으세요." | 확인 필요 |

| "셀룰라이트 분해, 지방 녹이는 관리" | 의료행위성 표현 | "바디 라인 관리 [직접 입력: 관리 내용]" | 확인 필요 |
| "손발톱 무좀 치료" (네일) | 의약품·의료 오인 | "손발톱 상태가 걱정되시면 병원 진료를 권해드려요." | 확실 |
| "두피 재생 탈모 케어" (미용실) | 의료 오인(화장품 금지 표현과 겹침) | "두피 클렌징·보습 케어" | 확실 |

## 4. 채널별 주의

- 블로그: 관리 과정 글에 "치료", "시술"을 쓰지 않는다. 사용 기기 이름을 쓰기 전에 의료기기인지 확인한다.
- 카드뉴스: 전후사진은 "치료 효과"처럼 보이게 쓰지 않는다. 손님 얼굴은 동의 필요(common.md).
- 숏폼(릴스·숏츠·클립): 영상 속 기기·주사·니들 장면이 자백이 된다. 화면에 나오는 것도 점검한다.
- 플레이스 업종명·메뉴명: 메뉴 이름("여드름 치료 코스")도 광고 문구로 본다.
- 리뷰 이벤트·체험단 리뷰: 만들지 않는다(의료로 오인될 수 있는 업종, `common.md` 2-5). 체험단 블로거가 병원 시술을 홍보하는 글은 비의료인 의료광고(제56조①)라 따로 금지.

## 5. 제재 수준

| 위반 | 제재 | 근거 |
|---|---|---|
| 비의료인 의료광고 | 1년 이하 징역 또는 1천만 원 이하 벌금 | 의료법 제56조①, 제89조 |
| 무면허 의료행위 | 5년 이하 징역 또는 5천만 원 이하 벌금. 사람을 다치게 하면 7년 이하 징역 등 | 의료법 제27조①, 제87조의2 |
| 의약품·의료기기 사용, 점빼기·박피 등 | 영업정지 1차 2월, 2차 3월, 3차 영업장 폐쇄 | 공중위생관리법 시행규칙 별표7 |

## 6. 확인 필요 (단정 금지)

1. "필링", "여드름 관리", "트러블 케어" 같은 경계 표현이 의료광고·의료행위인지는 사안별 판단.
2. 어떤 피부관리 기기가 의료기기인지는 기기별 허가 여부로 갈린다(`medical-device.md`).
3. 반영구 시술 광고는 문신사법 시행(2027-10-29) 전까지 의료법 영역(`tattoo.md`).

사장님 안내 예: "사장님, '치료'라는 말은 병원만 쓸 수 있어서 '진정 관리'로 바꿨어요. 실제로 하시는 관리 이름을 알려 주시면 그대로 넣을게요."
