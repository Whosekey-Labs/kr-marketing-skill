# 담배·전자담배 검수표 (`tobacco.md`)

> 법률 자문이 아닙니다. 2026-11-17에 확인한 조문·공식 자료로 만든 점검표입니다. 최종 판단은 사장님(필요하면 담당 기관·전문가)이 합니다.

## 꼭 지킬 것 (요약)
- SNS·블로그·숏폼·전단으로 담배를 광고하지 않는다.
- 매장 안 광고물도 밖에서 보이면 안 된다.
- 흡연 권장, 여성·청소년 묘사, 건강 주장 금지.
- 인스타 협찬 콘텐츠에서 담배·전자담배는 금지 품목이다.

아래 표는 걸렸을 때나 확인이 필요할 때 자세히 본다.

## 1. 적용 대상

- 담배 지정소매인: 편의점, 담배 가게, 전자담배 판매점.
- 담배 제조자·수입판매업자와 그들을 대신해 광고하는 도매업자·지정소매인(국민건강증진법 제9조의4②).
- 편의점·마트가 담배 **외** 상품을 홍보하는 것은 이 파일 대상이 아니다. 단, 그 게시물에 담배가 보이면 이 파일을 켠다.

## 2. 금지·의무

담배 광고는 아래 4가지 방법**만** 허용된다(제9조의4①). **블로그·인스타·유튜브 같은 인터넷 광고는 허용 목록에 없다.**

| 허용 방법 | 조건 |
|---|---|
| 소매점 **내부** 광고물 | 외부에서 보이면 안 됨 |
| 잡지 광고 | 연 10회 이하, 여성·청소년 대상 잡지 제외 |
| 행사 후원 | 명칭만 |
| 국제선 항공기·여객선 등 | — |

| # | 규칙 | 근거(조문·고시) | 확실도 |
|---|---|---|---|
| 1 | SNS·블로그·숏폼·전단으로 담배 광고 금지(허용 목록에 없음) | 국민건강증진법 제9조의4① | 확실 |
| 2 | 매장 내부 광고물도 **밖에서 보이면** 안 됨 | 제9조의4①1호 | 확실 |
| 3 | 허용된 광고도 흡연 권장, 여성·청소년 묘사, 검증되지 않은 건강 주장 금지 | 제9조의4③ | 확실 |
| 4 | 가향 물질 표시 문구·그림 금지("멘솔", "과일향" 등을 표시로 강조) | 제9조의3 | 확실 |
| 5 | 액상형 전자담배(합성니코틴 등)가 법상 "담배"인지 | 담배사업법 정의·개정 여부 미확인 | 확인 필요 |
| 6 | 인스타 협찬(브랜디드 콘텐츠)에서 담배·전자담배는 **금지 품목** | Meta 브랜디드 콘텐츠 정책 | 확실 |

**에이전트 기본 동작**: 담배·전자담배 상품은 홍보 콘텐츠를 만들지 않는다. 사장님께 이유를 설명하고 다른 소재(매장 위치·영업시간·담배 외 상품)를 제안한다.

## 3. 자주 걸리는 문장 → 고친 문장

| 원문 | 걸리는 이유 | 고친 문장 | 확실도 |
|---|---|---|---|
| (전자담배 가게 릴스) "신상 액상 입고! 멘솔 쿨링감 미쳤다" | 인터넷 광고 + 가향 강조 | 만들지 않는다. 대신 "[직접 입력: 상호] [직접 입력: 영업시간] 영업 안내" | 확실(합성니코틴 해당 여부는 확인 필요) |
| (편의점 인스타) "○○ 신제품 담배 들어왔어요" | 인터넷 담배 광고 | 담배 언급 삭제. "[직접 입력: 담배 외 신상품] 들어왔어요" | 확실 |
| "이 전자담배는 덜 해로워요" | 검증되지 않은 건강 주장 | 삭제 | 확실 |
| 매장 유리창 밖으로 보이는 담배 포스터 | 외부 노출 | 매장 안쪽, 밖에서 안 보이는 곳으로 | 확실 |
| 매장 소개 영상 배경에 담배 진열대가 크게 잡힘 | 간접 광고 소지 | 담배 진열대가 안 나오게 다시 찍거나 흐리게 | 확인 필요 |
| "과일향 ○○ 재입고" | 가향 표시 | 삭제 | 확실 |

## 4. 채널별 주의

- **블로그**: 담배 상품 소개 글 금지. 매장 안내 글에서도 담배 상품명·사진 빼기.
- **카드뉴스**: 담배·액상·기기 사진을 쓰지 않는다.
- **숏폼(릴스·숏츠·클립)**: 매장 영상에 담배 진열대, 흡연 장면이 나오지 않게 한다.
- **플레이스·당근**: 상품 목록·소식에 담배를 올리지 않는다.
- **협찬**: 인플루언서 협찬 불가(Meta 금지 품목).
- 뒷광고·가짜 후기·손님 얼굴은 `guides/compliance/common.md` 참조.

## 5. 제재 수준

- 제9조의4를 위반한 광고: **1년 이하 징역 또는 1천만원 이하 벌금**(제31조의2제4호).
- 가향 물질 표시 위반: **과태료 500만원 이하**(제9조의3, 제34조).
- 플랫폼: Meta 정책 위반 시 콘텐츠 삭제 등.

## 6. 확인 필요 (단정 금지)

1. 합성니코틴 액상형 전자담배가 광고 규제 대상 "담배"인지(담배사업법 정의와 최근 개정 여부).
2. 매장 소개 영상에 담배 진열대가 배경으로 보이는 정도가 광고에 해당하는지.
3. 전자담배 기기(니코틴 없는 기기만)의 광고 가능 범위.

사장님 안내 예: "담배와 전자담배는 인터넷에 광고를 올리는 것 자체가 법으로 막혀 있어요. 대신 가게 위치나 다른 상품 소식으로 만들어 드릴게요."
