# 온라인 판매(전자상거래) 검수표 (`ecommerce.md`)

> 법률 자문이 아닙니다. 2026-11-17에 확인한 조문·공식 자료로 만든 점검표입니다. 최종 판단은 사장님(필요하면 담당 기관·전문가)이 합니다.

## 꼭 지킬 것 (요약)
- 주문받는 광고에 상호·대표자·주소·전화·통신판매업 신고번호를 쓴다.
- 가격·배송비·교환·환불 조건을 알린다. 필수 비용을 빼고 싼 가격만 보이지 않게 한다.
- 나쁜 후기를 지우거나 구매자 수를 부풀리지 않는다.
- 숙박은 청소비·인원 추가 같은 필수 요금을 포함한 가격을 쓴다.

아래 표는 걸렸을 때나 확인이 필요할 때 자세히 본다.

## 1. 적용 대상

| 업종·상황 | 켤지 | 메모 |
|---|---|---|
| 인스타 DM·카톡 주문, 블로그 마켓, 스마트스토어, 자사몰 | 켠다 | 비대면 판매 = 통신판매 |
| 반찬·베이커리 택배, 공방 온라인 판매, 온라인 클래스 | 켠다 | 식품이면 `food-origin.md`도 |
| 블로그·카페 공동구매 | 켠다 | + 대가 표시(`common.md`) |
| 숙박 예약 가격 광고 | 켠다 | 추가요금 숨긴 최저가 |
| 오프라인 매장 홍보만 | 끈다 | 통신판매가 아님 |

공통 사항(뒷광고, 가상인물, 저작권, 개인정보, 가짜 후기, 리뷰 이벤트)은 `guides/compliance/common.md` 참조.

## 2. 금지·의무

| # | 규칙 | 근거 | 확실도 |
|---|---|---|---|
| 1 | 통신판매업 신고(공정위 고시 기준 이하 소규모는 면제) | 전자상거래법 제12조 | 확실(면제 기준 수치는 확인 필요) |
| 2 | 주문받을 목적의 광고에 상호·대표자, 주소·전화·이메일, 통신판매업 신고번호 표시 | 제13조① | 확실 |
| 3 | 가격·배송·청약철회 등 거래조건 고지 | 제13조② | 확실 |
| 4 | 첫 화면에 필수 비용 일부만 보여주는 '쪼개기 가격' 등 다크패턴 금지(2025-02-14 시행) | 제21조의2 | 확실 |
| 5 | 불리한 후기 삭제, 고용·후원한 사람에게 거짓 유리한 후기 쓰게 하기 금지 | 제21조①1호, 소비자보호지침 예시 (5) | 확실 |
| 6 | 직원이 대량 구매 후 취소해 구매자 수 부풀리기 금지 | 소비자보호지침 예시 (8) | 확실 |

| 8 | 7번 의무는 **자사몰 직접 운영자에게 확실**. 오픈마켓 입점은 후기 기준을 누가 정하느냐로 갈림(플랫폼/입점사/둘 다) | 공정위 문답서 Q5·Q6 | 확실(입점 사례 판단은 확인 필요) |
| 9 | 네이버 블로그·카페에서 상거래·공동구매를 하면 블로그 홈에 사업자 정보(상호·대표자·주소·전화·이메일·사업자등록번호) 표시(사업자 정보 위젯) | 네이버 신고센터 「상거래 표시 의무 미준수」 | 확실 |
| 10 | 숙박: "1박 ○만원~"처럼 필수 추가요금(청소비·인원 추가 등)을 빼고 낮은 가격만 보이기 금지 | 표시광고법 제3조, 전자상거래법 제21조의2 | 확인 필요(적용 범위) |

**판매 글 필수 표시 칸(글 끝·프로필·설명란)**

```
상호 [직접 입력] | 대표자 [직접 입력] | 사업자등록번호 [직접 입력]
통신판매업 신고번호 [직접 입력] | 주소 [직접 입력] | 전화 [직접 입력] | 이메일 [직접 입력]
가격 [직접 입력: 총액] | 배송비 [직접 입력] | 교환·환불 [직접 입력: 청약철회 방법·기간]
```

## 3. 자주 걸리는 문장 → 고친 문장

| 원문 | 걸리는 이유 | 고친 문장 | 확실도 |
|---|---|---|---|
| "가격은 DM 주세요" (사업자 정보 없음) | 신원정보·거래조건 미표시 | "가격 [직접 입력]원, 배송비 [직접 입력]" + 필수 표시 칸 | 확실 |
| "9,900원!" (결제 때 필수 포장비 추가) | 쪼개기 가격 | "총 [직접 입력: 포장비 포함 금액]원" | 확실 |
| "리얼 후기 100개 돌파" (지인 부탁 후기 포함) | 거짓 후기로 소비자 유인 | 실제 구매 후기 수만, 지인·대가 후기는 빼거나 표시 | 확실 |
| "별점 1점 후기는 바로 지워요" | 불리한 후기 삭제 | 삭제 기준을 공개하고 그 기준대로만 | 확실 |
| "주문 폭주! 300명 구매" (직원 주문 포함) | 구매자 수 부풀리기 | 실제 수치 [직접 입력] 또는 삭제 | 확실 |
| "환불 불가" (청약철회 대상 상품) | 거래조건 고지·청약철회 | "교환·환불: [직접 입력: 법정 청약철회 기준에 맞춘 내용]" | 확인 필요 |
| "1박 2만원" (주말·인원 추가 요금 미기재) | 추가요금 숨긴 최저가 | "평일 1박 [직접 입력]원, 주말 [직접 입력]원, 인원 추가 [직접 입력]원" | 확인 필요 |
| 블로그 공동구매 글 (사업자 위젯 없음) | 상거래 표시 의무 | 사업자 정보 위젯 설정 후 게시 + 대가 표시 | 확실 |

## 4. 채널별 주의

- **블로그**: 판매·공동구매를 하면 사업자 정보 위젯을 먼저 켠다. 없으면 공정위 요청으로 블로그가 임시 제한될 수 있다. 협찬·제휴 링크가 들어간 글에는 '내돈내산' 배너가 붙지 않는다.
- **카드뉴스**: 가격 장에는 총액(필수 비용 포함). 마지막 장 또는 캡션에 필수 표시 칸.
- **숏폼**: "링크는 프로필에" 형태여도 연결된 판매 화면에 신원정보·거래조건이 있어야 한다. 화면에 가격을 띄우면 총액으로.
- **스마트스토어·자사몰 후기**: 자사몰이면 후기 운영 기준 4가지를 후기 첫 화면에 공개.
- **문자·카톡 판매 안내**: `guides/compliance/ad-messaging.md`.

## 5. 제재 수준

| 위반 | 제재 | 근거 |
|---|---|---|
| 신원정보 미표시·미신고 | 과태료 1천만원 이하 | 제45조④ |
| 신원·거래조건 거짓 정보 | 1천만원 이하 벌금 | 제43조 |
| 통신판매업 미신고 | 3천만원 이하 벌금 | 제42조 |
| 후기 운영 정보 미공개 | 과태료 1천만원 이하 | 제45조④8호 |
| 기만적 유인(가짜 후기 등) | 시정조치, 불이행 시 3년 이하 징역 또는 1억원 이하 벌금, 영업정지 대신 과징금 | 제32·40·34조 |
| 같은 행위의 표시광고법 위반 | `common.md` 제재 | 표시광고법 |

## 6. 확인 필요 (단정 금지)

1. 통신판매업 신고 면제 기준(공정위 고시)의 2026년 현행 수치.
2. 네이버 플레이스·배달앱처럼 플랫폼이 후기 기준을 정할 때 입점 가게에 제21조의4 의무가 남는지(사례별).
3. 숙박 플랫폼 가격 순차공개 금지의 적용 범위.

사장님 안내 예: "사장님, DM 주문을 받으시면 통신판매에 해당해서 게시물에 사업자 정보와 가격·배송·환불 안내가 들어가야 해요. 통신판매업 신고번호를 알려 주시면 넣어 둘게요."
