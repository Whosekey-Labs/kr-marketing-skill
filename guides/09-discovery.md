# 9. 이번 주 주제 찾기 (콘텐츠 발굴)

목표: "이번 주 뭐 올리지"를 **근거 있는 후보 3개 + 채널 배정**으로 바꾼다. 사장님 손은 3분, 에이전트 수집은 5분 안팎.
언제 연다: `guides/04-weekly.md` ① 표로 이번 주 바로 쓸 후보(사장님 소식·D-21 안 시즌·지난주 반응 변주·손님 질문·장부 '보관' 중 시기가 맞는 것)가 2개 미만이거나, 사장님이 주제 찾기를 직접 요청할 때. 연간 계획은 `guides/08-operations.md` 4).

근거 표기 `[10 …]`·`[10b …]`는 관리용 출처다(비공개 조사 기록). 작업 중에는 열지 않는다.

## 1) 원칙

- 중심은 **손님 말 + 가게에서 생긴 일 + 다가오는 시즌** [10 1-2], [10b 6-1].
- **검색 도구는 검색으로 들어오는 채널(블로그·유튜브)에만** 쓴다. 당근·인스타·스레드는 도구 없이 손님 말·가게 소식에서 출발 [10b 3-1].
- **검색 데이터는 업종에 따라 켜고 끈다** (7) 표) [10b 3-3].
- **시즌은 1~2개월 앞을 본다.** 쇼핑인사이트 '이번 주 순위'는 이미 지난 결과다. 다가올 시즌은 **작년 같은 시기 2~6주 뒤**에서 찾는다 [10 #4], [10b 2-3].
- **사기 직전 말이 넓은 말보다 낫다**('시·구+서비스+조건': 예약·야간·첫방문) [10 #6·#16].
- AI가 떠올린 후보는 수집한 근거로 확인한다. 근거가 없으면 '가게 소식형'으로만 [10 #3·#6].
- 한 주 3개는 **질문형 1 + 시즌형 1 + 가게 소식형 1**로 섞는다. **유형 섞기가 점수보다 먼저**다: 유형마다 점수가 가장 높은 1개씩 고른다. 맞는 유형이 없으면(예: 시즌 소재 없음) 남은 유형의 다음 점수로 채운다 [10 3-3].
- **채널 빈도가 유형 섞기보다 먼저**다: 프로필의 채널 빈도(예: 블로그 월 2회)를 넘는 후보는 다음 주로 '보관'하고 다음 후보를 올린다. 프로필에 없는 채널(예: 플레이스 미등록)은 배정하지 않는다.

## 2) 데이터 경로 (네이버 약관)

네이버 이용약관(2026-10-01)은 **양과 상관없이** "사전 허락 없이 자동화된 수단으로 … 특정 질의어로 검색"하는 것을 금지하고, 검색·자동완성·관련 검색어 주소의 robots.txt는 `Disallow: /`다 [10b 4-1·4-3]. 횟수를 줄여도 약관 문제는 그대로다 [10b 4-4].

| 경로 | 쓰는 것 |
|---|---|
| **안전** | 네이버 공식 API(키: 검색 API·데이터랩·검색광고, 발급은 `guides/00-start.md` 5-1)), 사장님이 보낸 링크·화면 캡처, 사장님 3문항, 내장 시즌 달력, 구석구석 축제. 사장님이 준 **특정 주소**(플레이스·블로그 글)는 네 브라우저로 열어도 된다 |
| 참고(비공식) | 구글 자동완성·유튜브 자동완성, 구글 트렌드(비공식 내부 주소, 자주 막힘(429)) |
| **동의 뒤에만** | **네이버에 검색어를 넣어 검색하는 모든 것**: 브라우저로 직접 검색하든 `--unofficial`(네이버 자동완성·관련 검색어·지식iN 화면·쇼핑인사이트 순위)이든 같다. 사장님께 아래 문장으로 묻고 동의받은 뒤, **이 가게 1곳 몫만, 사장님 PC에서, 주 1회**. 여러 가게 몫을 모아 부르지 않는다 |

순서: **키 먼저**(`guides/00-start.md` 5-1)) → 키를 거절했고 네이버 자료가 꼭 필요할 때만 아래 동의를 묻는다. 답은 프로필 '사장님과 정한 것'에 저장하고 매주 다시 묻지 않는다.
동의 묻기 (한 번): "네이버 검색을 제가 대신 해서 읽는 건 네이버 약관상 문제가 될 수 있어요. 네이버 열쇠(공식 키)를 받아 두면 이 걱정 없이 할 수 있어요. 열쇠 없이 이번만 사장님 가게 몫으로 조금 볼까요, 아니면 건너뛸까요?"

## 3) 매주 순서

| 단계 | 누가 | 할 일 | 시간 |
|---|---|---|---|
| ① 시즌 | 에이전트 | `mk.py season` (기본 8주) + 상권·관광지면 `festival --area "시도 시군"` | 1분 |
| ② 검색 수요 | 에이전트 | 7) 표에서 '켬'이거나 '약하게'인데 블로그 후보가 필요할 때만: `mk.py ideas -k "동네 업종" --wide 시구 --menu 대표메뉴` (+ 필요하면 `trend`) | 2분 |
| ③ 3문항 | 사장님 | 아래 3문항 | 3분 |
| ④ 고르기 | 에이전트 | 후보 10~15개 → 5) 관문 → 점수 → 지난 4주 장부와 겹치는 것 빼기 | 1분 |
| ⑤ 제안 | 에이전트 | 상위 3개 + 채널 + 근거 한 줄 + 만들 양 (8) 예시, 한 메시지) | 1분 |
| ⑥ 기록 | 에이전트 | 고른 번호로 `04-weekly` ②부터 제작. 장부에 기록 | — |

**사장님 3문항** (매주 같은 모양, 한 메시지로) [10 #10·#12·#15·#18]
```
이번 주 주제 고르려고 3가지만 여쭤볼게요. 한 줄씩이면 충분해요.
1. 이번 주 새로 생긴 것 있어요? (신메뉴, 들어온 재료, 바뀐 것, 행사)
2. 손님이 묻거나 한 말 중 기억나는 거 있어요? (전화·리뷰·계산할 때)
3. 지난주 올린 것 중 반응 좋았던 거요? (모르시면 "몰라"도 돼요. 제가 볼게요)
```
2번 답은 '손님 말'로 프로필에 쌓는다(닉네임 없이). 답이 없으면 수집한 것만으로 낸다.

## 4) 소스별 메모

| 소스 | 명령 | 읽는 법 |
|---|---|---|
| 시즌·기념일·절기 달력(내장) | `season` | D-14~21 안이면 예열. 음력 날짜는 확인된 해만 들어 있다(없으면 안내가 뜸) |
| 쇼핑인사이트 작년 같은 시기 2~6주 뒤 | 사장님 화면 캡처 (동의 뒤 `season --unofficial`) | 다가올 시즌 상품. 작년 반짝 유행은 올해도 통할지 따로 판단 [10b 2-3] |
| 구글 자동완성 (동네 → 시·구 → 업종만) | `ideas --wide` | 넓힌 단계가 찍힌다. 넓힐수록 우리 동네 손님 말이 아니다 [10b 2-2]. 자동완성은 '양'이 아니다 |
| 지식iN 질문 | `ideas` (키) | 전국 익명 질문. API는 날짜가 없어 열어서 최근 것만 |
| 구글 트렌드·데이터랩 추이 | `trend` | 키워드마다 따로 본 방향 + 같은 차트 크기 비교. '오름'은 관련 상위어부터 확인. '검색 적음·드묾'은 검색이 띄엄띄엄이라 방향을 못 본다는 뜻(같이 넣은 말보다 작다는 뜻일 수도) |
| 유튜브 자동완성 | `ideas` | 유튜브 영상 주제 |
| 지역 축제 | `festival` | 상권·관광지 가게만. 보조 소스 [10 1-2] |
| 리뷰 속 손님 말 | 사장님 3문항, 플레이스 캡처 | 가장 센 근거 |
| 경쟁·레퍼런스 잘된 게시물 | `search-blog`(키), `06-reference` 장부, 사장님 폰 탐색 탭 캡처 | 구조만 빌리기 [10 #1·#9·#11] |

인스타 해시태그·틱톡 크리에이티브센터·유튜브 인기 급상승은 자동 수집하지 않는다 [10 2-1]. 소스가 실패하면 건너뛰고 한 줄: "○○는 이번 주 못 가져왔어요. 나머지로 골랐어요."

## 5) 고르기: 관문 3개 → 점수 15점

**관문** (하나라도 걸리면 탈락·보관) [10b 3-2]: 우리 상품·목표와 무관(메뉴에 없는 상품 포함) / 시기가 지남 / 이번 주 안에 못 만듦(날짜·사실 미정 포함 → '보관').
- **법규**: 표현만 걸리면(예: "효과 최고") 표현을 바꿔 통과시킨다. 주제 자체가 의료 판단·효과 실증이 있어야 성립하면(예: "허리 2주 만에 덜 아파요", "혈당 안 올리는 빵") **탈락**시키고 사장님께 이유 한 줄. 병원·학원·건강·어린이 관련 후보는 채점 전에 그 업종 광고 규칙(`guides/compliance/`)부터 본다.

| 항목 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| **목표 연결 ×2** | 무관 | 업종 일반 정보 | 우리 상품과 연결 | 이번 달 목표에 바로 닿음: 신규=사기 직전 검색어, 재방문=단골 소식·혜택, 객단가=추가 메뉴·세트, 빈 시간=그 시간대 한정 메뉴·혜택 |
| **시기 (채널별)** | 지남 | 블로그: 이번 주 행사 / 당근·인스타: 4주+ 뒤 또는 상시 | 블로그: 상시 질문·2~4주 뒤 / 당근·인스타: 1~3주 뒤 | 블로그: 4~8주 뒤 시즌 / 당근·인스타: 이번 주 새 소식·행사 |
| **손님 언어** | 근거 없음 (사장님이 알린 가게 소식 자체는 0) | 전국 검색·지식iN | 우리 시·구·동네 검색에 등장 | 우리 가게 손님이 실제로 한 말(리뷰·DM·사장님이 전한 손님 말) |
| **만들기 쉬움** | (관문 탈락) | 새로 찍어야 함 | 사진·영상 이미 있음 | 오늘 바로 찍을 수 있음 |

- 합계 = 목표×2 + 시기 + 손님 언어 + 만들기 쉬움. 고르는 순서: 관문 → 채널 빈도 → **유형별 최고점 1개씩**(1) 원칙) → 동점 규칙.
- 동점이면 ① **만들기 쉬운 것**(현업 최상위 기준: "답하기 쉬운 것부터", "매일 할 수 있는가" [10 #10·#12]) ② 그래도 같으면 **힘줄 곳 채널** 후보.
- 키워드도구 '경쟁'은 광고주 경쟁이라 점수에 넣지 않는다. 블로그 경쟁은 상위 글 날짜(1~2년 지난 글이 상위면 기회)만 본다 [10b 3-2].
- **블로그 검색량 관문**(검색광고 키 있을 때만, 현업 경험치): 모바일 월 300 미만은 '검색용'이 아니라 '단골·SNS용'으로 돌린다. 사기 직전 말이면 50도 채택 [10 #2·#6].

## 6) 채널 배정 [10 1-3 규칙 10]

| 채널 | 맞는 주제 |
|---|---|
| 블로그 | 질문 답변, 검색 근거가 있는 주제, 4~8주 뒤 시즌 |
| 유튜브 | 유튜브 자동완성에 뜨는 주제 |
| 인스타·릴스 | 눈에 보이는 것(단면·과정·공간), 손님 반응 |
| 당근·플레이스 소식 | 지금 올 이유(이번 주 한정·새 소식·행사·시간대 혜택) |
| 스레드 | 사장님 이야기·동네 이야기 |

프로필의 **힘줄 곳**부터 배정하고, 안 할 곳에는 배정하지 않는다.

## 7) 업종별 차이 (검색 데이터 켜기·끄기) [10 3-4], [10b 3-3]

| 업종 | 검색 데이터(② 단계) | 주 소재 | 채널·빈도 |
|---|---|---|---|
| 비교·예약형(미용·학원·병원·정비·숙박) | **켬, 시·구 단위**('부천 미용실 첫방문') | 오늘 손님 1명, FAQ, 원장 이야기 | 블로그 질문형 + 인스타 주 2+. 병원·학원은 광고 규칙 먼저 |
| 음식점·카페·빵집 — 목적지형 | 켬, 시·구+메뉴(블로그용) | 시즌 메뉴, 지금 올 이유, 손님 반응 | 인스타·당근 자주, 블로그 주 1~2 |
| 음식점·카페·빵집 — 동네형 | **약하게** = 블로그 후보가 필요할 때만 ② 실행 | 손님 반응, 새로 나온 빵, 시즌 | 플레이스·당근 중심 |
| 동네 생활형(반찬·분식·세탁·편의) | **끔**. 시즌·손님 말·가게 소식만 | 오늘 반찬, 영업 소식 | 당근·플레이스 |
| 쇼핑몰·상품 | 켬, 키워드도구 관문 가장 엄격 | 상품 1개 × 손님 질문 3개, 시즌 선물 | 블로그·카드·릴스로 쪼개기 |
| 관광지 상권 | 축제·시즌 켬, 검색은 시·구 단위 | 손님 반응·새 서비스, 근처 축제 | 인스타 릴스 자주 |
| 매장 없는 사업(B2B·온라인) | 켬, 서비스 말(`--area ""`, 넓히기 없음), 축제 끔 | 고객이 묻는 문제, 작업 사례, 업계 소식 | 블로그·유튜브·스레드 |

표에 없는 업종은 `guides/industries/` 번호로 맞춘다: 비교·예약형 = 08 미용·네일, 09 피부·바디, 10 운동(필라테스·헬스), 11 어린이 학원, 12 성인 클래스, 13 병의원·약국, 14 반려동물, 17 생활 서비스, 18 자동차, 19 인테리어, 20 부동산, 21 전문직, 22a 사진·웨딩 / 음식점·카페 = 01·02·03·04 / 동네 생활형 = 05 동네 소매 / 쇼핑몰·상품 = 06·07 / 관광지 = 15·16 / 매장 없는 사업 = 22b·23·24·25 / 00 기타는 가장 가까운 줄. 채널·빈도는 프로필이 표보다 먼저다.

## 8) 사장님께 보여 주는 말 (예시, `04-weekly` ①처럼 만들 양까지 한 메시지로)

```
이번 주 주제 3개 골라 봤어요. 하실 번호를 말씀해 주세요(여러 개도 돼요). 고른 번호마다 하나씩 만들어요.
1. [당근·플레이스 소식 1개] 이번 주 무화과빵 마지막, 다음 주부터 단호박 식빵 평일에도
   왜: 사장님이 알려 주신 이번 주 소식이에요.
```
