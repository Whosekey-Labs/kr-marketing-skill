# 7. 우리 가게 색·글씨체 (디자인 키트 — 첫 콘텐츠를 만들 때 한 번 고정)

목표: 색·폰트·사진 톤·레이아웃을 **숫자로** 한 번 정해 브랜드 프로필의 '우리 가게 색·글씨체' 칸에 저장하고, 이후 모든 카드뉴스·숏폼·썸네일에 그대로 쓴다. 3단계 전략에서는 열지 않는다. **첫 카드뉴스·숏폼을 만들 때** 연다.
아래 수치는 **기본값**이다(대비 4.5:1과 폰트 라이선스는 지킨다).

## 1) 시안 2안 — 묻지 않고 만들어서 고르게 한다

"기존 디자인이 마음에 드세요?"를 따로 묻지 않는다. 첫 카드뉴스(또는 숏폼)를 **두 안으로 만들어** 보여 주고 번호로 고르게 한다(질문 수에 넣지 않는다).

| 안 | 만드는 법 |
|---|---|
| **1안(A) 레퍼런스안 (기본)** | 2)의 잘하는 곳 공통 문법 + 브랜드 성격 카드의 디자인 방향(`guides/03-strategy-brand.md` 표 + 프로필 '형용사 → 바뀐 칸'. 만들기 전에 갈림 점검이 프로필에 없으면 먼저 한다). 기존 로고 색은 쓰지 않는다 |
| **2안(B) 기존 색 살린 안** | 사장님 기존 색(로고·간판·홈페이지·인스타 프로필, 3) 색 뽑기)을 대표색으로, 레이아웃은 1안과 같은 문법 |
| 기존 색이 없을 때 | 2안을 "같은 성격 카드의 다른 스타일 후보"로 만든다(예: S09 대신 S03). 손글씨 간판 사진만 있으면 낮 사진에서 색을 뽑아 2안으로 쓴다(추정 표시) |

```
두 가지로 만들어 봤어요. 마음에 드는 쪽 번호만 알려 주세요.
1. 같은 업종에서 반응 좋은 게시물 방식으로 잡은 안
2. 사장님 가게 [간판·로고] 색을 살린 안
안 고르시면 1번으로 갈게요. 닮고 싶은 계정이 있으면 같이 알려 주세요.
```
- **중간부터 요청한 첫 결과물**(최소 프로필)은 1안만 만들고, 2안은 첫 정식 제작 때 "간판 색을 살린 안도 만들어 볼까요?"로 제안한다.
- **고르기 전 기본은 1안**이다. 답이 없으면 1안으로 저장하고, 나중에 "간판 색으로 바꿔줘"라고 하면 2안으로 바꾼다.
- 고른 결과를 프로필 '기존 디자인' 칸에 "1안 레퍼런스 / 2안 기존 색"으로 적는다. 2안이면 3)의 팔레트를 쓰고, 1안이면 기존 색은 프로필 사진·플레이스에만 남긴다.
- 사장님께는 A·B 대신 **1·2 번호**로 말한다("1번이요"로 답하게). `make/` 파일의 A안·B안은 각각 1안·2안이다.
- 두 안은 **같은 원고**로 만든다. 글이 달라지면 디자인을 비교할 수 없다.

### 사진이 아직 없을 때
- 표지는 **글자 카드 스타일**(S05 깔끔한 글자 카드, 동네형이면 S07 손글씨 메모도 가능)로 만들고, 이미지 생성이 있으면 그림 요소(`art`)를 얹는다(`guides/make/image-gen.md`). 목적지형도 사진 전에는 S05로 하되 성격 카드의 색·여백을 따른다. 사진 위 큰 제목(S02)·사진 그대로(S01)는 사진이 오기 전에는 쓰지 않는다(빈 사진 자리 위 글자는 대비 점검에서 떨어진다).
- 사진 자리는 `[사진 자리: …]` 안내로 두고, 시안은 "사진이 오면 표지를 사진형으로 바꿀 수 있어요"라고 함께 말한다.

### 브랜드 색이 너무 밝거나 쨍할 때 (글자가 안 읽힘)
- 대비를 먼저 잰다(4.5:1, 아래 3)). 밝은 색(파스텔·밝은 노랑·코랄·민트 등)이 배경 위 글자로 3:1이 안 되면 **글자색으로 쓰지 않는다.**
- 쓰는 법은 둘 중 하나: ① **면으로만** — 띠·강조 박스·배경 면에 쓰고 그 위 글자는 먹색 #1A1A1A ② **진한 변형** — 같은 색 계열을 어둡게 내려 4.5:1을 넘긴 색(예: 코랄 → 진한 코랄)을 강조 글자로 따로 둔다. 이름에 "진한 ○○ (변형)"을 붙이고 2안 설명에 "글자가 읽히게 간판 색을 조금 진하게 했어요"라고 말한다.
- 너무 진한 색(남색·검정에 가까운 색)이 배경이면 글자는 흰색으로 하고 같은 대비 규칙을 지킨다.

## 2) 기본값: 같은 업종 잘하는 곳의 공통 디자인 문법

1. 같은 업종(브랜드 성격 카드가 같은 쪽 우선)에서 반응 좋은 카드뉴스·숏폼 3~5개를 고른다(고르는 기준은 `guides/06-reference.md`, 이미 '참고한 잘된 게시물'에 있으면 그것).
2. 다섯 가지의 **공통점**만 한 줄씩 적는다: ① 글자 위계(제목·본문 크기 차이) ② 여백 ③ 사진 비중 ④ 글자 크기 ⑤ 색 쓰는 법(색 수·강조 위치).
3. 이 공통점 + 사장님이 고른 스타일 코드로 키트를 정한다. 색·사진·문장은 빌리지 않고 쓰는 방식만 빌린다.

## 3) 색 뽑기 (2안을 만들 때)

출처 우선순위: ① 브랜드 가이드·SVG 원본 색 번호(`fill="#…"`) ② 홈페이지·SNS 프로필의 로고 이미지(PNG) ③ 낮 자연광 정면 간판·메뉴판 사진(불 켜진 LED·네온 간판은 쓰지 않는다).
- 스크립트 모드: `python3 mk.py colors logo.png` → 대표색 후보와 헥스 값.
- 도구가 없으면 눈으로: 가장 넓은 색과 가장 눈에 띄는 색을 고르고, 면 안쪽 3~5군데의 가운데 값을 쓴다(가장자리·그림자·반사광 피하기).
- 사진에서 뽑은 값은 "추정"으로 적는다. 따로 묻지 않고 2안에 써서 보여 준다.

### 팔레트 (모든 경우 공통)
- **대표색 1~3개 + 중립색 2~3개**(흰 #FFFFFF, 미색, 먹색 #1A1A1A 등). 색마다 역할 이름("메인 배경", "강조")과 부르는 이름("간판 주황")을 붙인다.
- 배분 기본값: 중립(배경) 60 / 보조 30 / 강조 10. 강조색은 하나로 정해 모든 채널에서 같게 쓴다.
- 기존 색이 모두 진하거나 쨍하면 중립색을 따로 더한다. 색은 **손님과 전하고 싶은 분위기**(브랜드 성격 카드 ④) 기준으로 고른다.
- 키트가 정해지면 카드뉴스 `brand.colors`와 숏폼 `colors`·`font`에 **같은 값**을 넘긴다(렌더러·테마 기본색은 키트가 없을 때만). 같은 소재의 카드 표지와 숏폼 첫 장면을 나란히 놓고 맞춘 뒤 낸다(`guides/make/shortform.md` 6) '같은 브랜드 팔레트').

### 글자 대비 4.5:1
- 본문 글자와 배경은 **4.5:1 이상**, 큰 글자(18pt 이상, 굵으면 14pt 이상)는 **3:1 이상**. 4.49는 불합격. 어르신 손님이 많으면 큰 글자도 4.5:1.
- 스크립트 모드: `python3 mk.py contrast "#1A1A1A" "#F5EFE6"` → 대비 값과 통과 여부.
- 브라우저 모드(계산 못 할 때): 4.5 미만이 의심되면 글자는 **먹색(#1A1A1A) 또는 흰색**으로 하고, 대표색은 면·띠·강조 표시로만 쓴다.
- 통과한 글자·배경 조합만 키트에 적는다.

## 4) 폰트 2종

- 최대 2종: **제목용 1 + 본문용 1.** 제목은 브랜드 성격 카드(`guides/03-strategy.md` 4-1)에 따른다 — 기본은 굵은 고딕, 프리미엄·목적지형은 명조 제목 허용, 동네형 손글씨 메모(S07)는 손글씨 제목 허용. **본문은 모바일 가독성 때문에 고딕 중간 굵기로 고정**한다(얇은 명조·손글씨를 본문에 쓰지 않는다).
- 상업 이용이 확인된 무료 폰트(SIL OFL — 상업 이용·수정 가능, 폰트 파일만 따로 파는 것은 안 됨). 카드뉴스 도구가 받는 폰트와 같다(`python3 cardnews.py fonts`로 처음 한 번 받는다):

| 폰트 | 쓰는 곳 | 출처 |
|---|---|---|
| **Pretendard** (기본) | 고딕 제목 Bold·ExtraBold, 본문 Regular | https://github.com/orioncactus/pretendard |
| **고운바탕** | 명조 제목(프리미엄·목적지형, S09) | https://github.com/google/fonts/tree/main/ofl/gowunbatang |
| **나눔손글씨 펜** | 손글씨 제목·짧은 강조(S07). 본문 금지 | https://github.com/google/fonts/tree/main/ofl/nanumpenscript |
| G마켓 산스 | 굵고 둥근 제목(도구가 받지 않으므로 직접 설치했을 때만) | https://corp.gmarket.com/fonts/ |

- 이 밖의 폰트는 **그 폰트의 라이선스 원문을 열어 상업 이용을 확인한 뒤**에만 쓴다. 폰트 모음 사이트(예: 눈누)는 폰트마다 조건이 다르다.
- 사장님이 2안을 골랐고 이미 쓰는 폰트가 있으면, 라이선스를 확인하고 그대로 쓴다.

## 5) 사진 톤 규칙

- 톤을 한 줄로 정한다: 기본 4개(밝은 / 따뜻한 / 필름 느낌 / 미니멀) 중 하나 + 한 줄 설명(예: "자연광, 따뜻한 나무색, 필터 거의 없음").
- 브랜드 성격 카드의 '닮고 싶은 곳'이 있으면 그곳 사진 3장에서 **빛·색·구도**를 한 줄로 뽑아 덧붙인다(예, 목적지형: "옆에서 드는 빛, 강한 그림자, 대비 높게, 여백 넓은 구도"). 사진은 빌리지 않고 찍는 방식만 빌린다.
- 기본 기준: 720×720px 이상, 초점·밝기 확보, 과한 필터 금지, **실제 모습 그대로.**
- 사장님께 줄 촬영 요령(한 번만 보내고 프로필에 저장):
  - 카메라 격자와 HDR 켜기
  - 매장 전체는 0.5배 광각, 가슴(명치) 높이에서
  - 벽 모서리가 화면에서 '11'자로 곧게 서도록
  - 음식·제품은 화면을 꽉 채우고 초점 맞게
- 신메뉴 사진도 처음 사진들과 결(밝기·각도·배경)을 맞춘다.
- AI 이미지: 실제 매장·상품·사람처럼 보이는 AI 이미지는 쓰지 않는다. 누가 봐도 그림인 것(일러스트·캐릭터·사물 컷·질감 배경)은 **네 이미지 생성 기능으로 만들어** 카드뉴스·숏폼의 그림 요소로 쓴다(글자는 렌더러). 실제처럼 오해할 수 있으면 쓰지 않는다.
- **그림 스타일 문장**(이미지 생성이 있을 때): 2)의 레퍼런스 공통 문법에서 그림체·선·질감·색 수를 영어 한 문장으로 정해 키트에 저장하고, 모든 그림 프롬프트 맨 앞에 그대로 쓴다(예: "Warm hand-drawn gouache illustration, soft grainy paper texture, rounded shapes"). 색은 3)의 팔레트 헥스. 틀·예시·상한은 `guides/make/image-gen.md`.

## 6) 레이아웃 규칙 (숫자로)

카드뉴스 기본값(1080×1350, 자세한 것은 `guides/make/cardnews.md`):

| 항목 | 기본값 |
|---|---|
| 여백 | 좌우 72px, 위 80px, 아래 96px |
| 글자 크기 | 표지 제목은 렌더러가 폭에 맞춰 자동(약 124~168px), 장 제목 96~112px, 본문 40px 이상 |
| 표지 제목 | 12~19자, 2줄 |
| 색 | 주색 1 + 강조 1 + 무채색, 강조색은 한 장에 2곳까지 |
| 반복 요소 | 모든 장 같은 자리에 쪽번호(오른쪽 아래) |
| 로고·워터마크 | **넣지 않는다.** 가게 이름은 표지·마지막 장에 글자로만 쓴다. 로고는 프로필 사진·플레이스에만 |
| 사진 위 글자 | 아래쪽 어둡게 깔고 흰 글자. 얼굴·제품 위에 글자를 얹지 않는다 |

숏폼 기본값(1080×1920):
- 글자는 `guides/make/shortform.md`의 자막 안전 영역(**x 65~890, y 270~1250**) 안에만 둔다. 그 밖은 앱 버튼에 가린다.
- 핵심 문구는 가운데 조금 아래, 한 줄 2~3단어, 최대 2줄.
- 다른 플랫폼에 다시 올릴 수 있게 **워터마크 없는 원본**을 보관한다.

## 7) 스타일 고르기 (첫 결과물 때, 그 형식 하나만)

1. 그 형식을 **처음 만들 때**(프로필 '고른 스타일' 칸이 비어 있을 때) 그 형식의 `guides/styles/` 파일 1개만 연다. 블로그·카드뉴스·숏폼을 한꺼번에 고르게 하지 않는다.
2. 브랜드 성격 카드의 '디자인 방향'과 2)의 공통 문법으로 후보를 좁혀 1)의 2안에 쓴다. 사진이 없으면 1)의 '사진이 아직 없을 때'를 따른다.
3. 고른 **스타일 코드**를 프로필 '고른 스타일' 칸에 적는다. 코드는 `guides/styles/`에 적힌 그대로(문체 V1~V5, 카드뉴스 S01~S11, 숏폼 F01~F14·편집 P1~P7). 다음부터는 묻지 않는다.

## 8) 프로필에 저장할 형식

```
[우리 가게 색·글씨체]
기존 디자인: 1안 레퍼런스안 (사장님 11/18 "1번" / 답 없으면 기본)
공통 문법: 제목 크고 본문 짧게, 여백 넓게, 사진 7할, 강조색 1곳
색: 배경 미색 #F5EFE6 / 강조 올리브 #6B7A3A / 글자 먹색 #1A1A1A / 흰 #FFFFFF
통과 조합: 먹색 글자 + 미색 배경 (대비 [mk.py contrast 값]) / 흰 글자 + 올리브 면 = 큰 글자만
폰트: 제목 Pretendard Bold (성격 카드: 동네형) / 본문 Pretendard Regular
사진 톤: 따뜻한 — 자연광, 나무색, 필터 거의 없음
```
