# 브랜드 프로필 양식 (= 이 가게 전용 지침서)

사장님 구글 문서로 만든다(안 되면 텍스트로 주고 다음 대화에 붙여 달라고 안내). 결과물을 내기 직전에 매번 이 문서의 **말투·우리 가게 색·글씨체·금지 표현·내 요청사항**을 다시 본다.

작성 규칙:
- 칸은 **번호가 아니라 칸 이름**으로 가리킨다(예: "프로필 '금지 표현' 칸").
- 사장님이 보는 칸은 위에, 에이전트용 칸은 "마케터 메모" 아래에 둔다. 사장님이 보는 칸에는 쉬운 말만 쓴다(포지셔닝→우리 가게 한 줄 소개, 핵심/확장/제외→힘줄 곳/곁들일 곳/안 할 곳, 기준값→지금 숫자, 판정→결과 보기).
- 조사로 안 것은 출처 표시: `(조사 11/17)`, 사장님 답은 `(사장님)`, 모르는 숫자는 `(추정)`.
- 빈 값은 `[직접 입력: …]`. 지어내서 채우지 않는다.
- 서로 다른 사실(사장님 말끼리, 요청과 자료)이 부딪히면 확인 질문 1개를 하고, 답이 올 때까지 그 칸은 빈칸으로 둔다.
- 바뀌면 덮어쓰고 맨 아래 "변경 기록"에 한 줄 남긴다.

## 최소 프로필 (중간부터 요청할 때)

첫 대화에서 바로 결과물을 달라고 하면 전체 양식 대신 아래 5줄만 채우고 바로 만든다. 상황 질문은 생략하고 조사로 추정한다. **가게를 못 찾아도 등록 상태를 먼저 묻지 않는다** — 결과물 뒤 한 줄로 확인(`guides/01-research.md` 확인 메시지). 나머지 칸은 첫 결과를 낸 뒤 "다음엔 가게 조사부터 해서 4주 계획도 짜 드릴까요?"로 잇는다.
```
업종·업종 광고 규칙(규제 플래그): (조사·요청으로 판단, 건너뛰지 않음)
말투 한 줄: (기존 글이 있으면 그 말투, 없으면 업종 기본)
금지 표현: (업종 + 사장님이 말한 것 + 아래 기본 목록)
사실 자료: (사장님이 준 가격·시간·메뉴 등만. 없으면 [직접 입력: …])
디자인: 레퍼런스안(1안) 기본 — 이번엔 1안만. 시안 2안은 첫 정식 제작 때 제안
```
