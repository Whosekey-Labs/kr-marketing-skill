# 18 자동차·이륜차

정비소, 판금·도색, 세차·광택·셀프세차, 타이어, 부품, 렌터카, 오토바이 수리, 튜닝.
근거 표시: [공식] 법령 원문 / [실측] 세어 본 값 / [판단] 가설.
**주의:** 블로그·카드뉴스·숏폼 실측 표본에 이 업종이 없다. 4절 유형은 [판단]이다. 채널 순서는 실측(2026-11, 정비소 3곳)에서 대체로 맞았다.

## 1. 이 업종 손님이 우리를 찾는 상황

[판단] 가설. 1단계에서 확인한다.
- 경고등·이상 소리가 나서 "동네 + 정비소", "차종 + 증상"을 검색한다.
- 수입차·판금 수리를 맡길 곳을 사례 글로 비교한다.
- 타이어·엔진오일 교체 가격을 비교한다.
- 세차·광택은 결과 사진을 보고 고른다.
- 견적이 적정한지, 과잉 정비는 아닌지 걱정한다.

## 2. 맨 앞에 할 일

1. 플레이스 정비: 정비 항목, 가능 차종, 영업시간, 예약, 실제 작업장 사진.
2. **정비 사례 블로그를 직접 운영할지 정한다.** 상위 정비소는 자체 블로그를 꾸준히 썼다 [실측].
3. 가격은 항목별 범위와 조건(차종·부품)으로 정리한다[판단].
4. "정비 견적 고지"는 조문을 확인하지 못했다 → 사장님께 현재 견적서 발급 방식을 듣고 **확인 필요**로 둔다.
5. 경쟁 3~5곳의 리뷰 수, 블로그 30일 글 수를 센다.

## 3. 채널 등급 가설

| 등급 | 채널 | 근거 |
|---|---|---|
| 핵심 | 네이버 플레이스 | [실측] 표본 정비소 A·B·C(분당) 리뷰 수십~1천 건대 |
| 핵심 | 사장님 블로그(정비 사례, 직접 운영) | [실측] 정비소 A·B는 30일 약 10건, 정비소 C는 1건. 타이어 전문점 D 블로그 리뷰 수천 건 |
| 확장(수입차·판금 전문만) | 유튜브 | [실측] 구독 약 30만 명대 정비 채널 1곳은 예외, 대부분 공업사 채널은 5~500명 |
| 확장 | 숏폼(작업 과정) | [판단] 원본 블로그 사례를 짧게 바꿔 배포 |
| 확인 필요 | 당근 | [실측 못 함]. 출장 세차·출장 정비면 올린다(당근은 출장 업종에서 강했다) |

## 4. 콘텐츠 기둥과 주력 유형

> 같은 업종도 브랜드 성격 카드(`guides/03-strategy.md` 4-1)로 말투·디자인·채널이 갈린다. 이 절은 기본값일 뿐이다.

기둥(예): ① 정비·수리 사례 ② 증상별 정보·질문 ③ 가격·이용 안내 ④ 작업장·정비사 소개.

| 원본 | 추천 유형 [판단] | 이유 |
|---|---|---|
| 블로그 | B04 작업·시공 사례, B02 질문에 답하기(Q&A), B03 비교·선택 가이드, B10 가격·주문·이용 안내 | 실측 상위 정비소가 사례 글을 꾸준히 썼다 |
| 카드뉴스 | C06 정보·꿀팁(틀: 체크리스트 — 점검 항목), C08 전후·사례, C07 자주 묻는 질문 | `guides/styles/cardnews.md` 12유형 중 맞는 것 |
| 숏폼 | F01 작업 과정·ASMR, F02 비포·애프터(세차·광택·판금), F04 사장님 정보·Q&A 토크 | `guides/styles/shortform.md` 유형 중 맞는 것 |

- 사례 글 구조(B04): 차종·증상·입고일 → 점검 결과 → 작업 과정 사진 순서대로 → 교체 부품·가격 범위 → 문의·예약.
- 손님 차 번호판·얼굴은 가린다.
- 블로그 말투는 V1 전문가 칼럼형 또는 V3 담백한 안내형(`guides/styles/blog.md` 4절)부터 제안한다.

## 5. 사장님에게 받을 소재 목록

- 정비 항목별 가격 범위와 조건, 견적서 양식
- 이번 주 작업 차량 1대의 전·중·후 사진과 한 줄 설명(번호판 가림)
- 작업 장면 10초 세로 영상(손·공구·부품 위주)
- 가능 차종·전문 분야(사실만), 정비사 자격(있을 때만)
- 손님이 자주 묻는 질문 3개(음성 메모 가능)

## 7. 규제 플래그

켜는 플래그: **common**, **ad-messaging**. 해당할 때만: **ecommerce**(부품·용품 온라인 판매).

| 자주 걸리는 문장 | 왜 | 고친 문장 |
|---|---|---|
| "업계 최저가 엔진오일" | 비교 기준 없는 최저가(표시광고법 제3조 부당 비교) | "[차종] 엔진오일 교체 [직접 입력]원부터(오일 종류에 따라 달라요)" |
| "옆 정비소는 과잉 정비, 우리는 정직" | 근거 없는 비방 | "점검 결과를 사진으로 보여 드리고 작업 전에 견적을 확인받아요" |
| "새 차처럼 100% 복원" | 과장, 실증 책임 | 전후 사진(같은 각도) + "차 상태에 따라 결과가 다릅니다" |
| "순정 부품만 사용"(사실 아님) | 거짓 | 실제 쓰는 부품 종류를 사실대로 |
| 손님 후기 할인 대가 | 경제적 이해관계 표시 | 첫 부분에 "할인 제공" 표시 |

## 8. KPI

| 층 | 지표 |

## 9. 하지 않을 것

- 근거 없는 최저가·비방
- 남의 정비 사진·영상 쓰기, AI로 만든 수리 결과 사진
- 번호판·손님 얼굴 노출
- 소규모 정비소에 유튜브 롱폼부터 권하기(실측상 대부분 구독 5~500명)
