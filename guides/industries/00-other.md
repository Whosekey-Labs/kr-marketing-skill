# 00. 기타 (잘 모르겠음 / 해당 없음)

26개 카테고리 어디에도 딱 맞지 않을 때 연다. 점포 기준으로 약 1.8%가 여기에 온다(장례식장, 결혼정보, 주유소, 고시원 등. 실측 2026-11, 업종 분류 표본).
이 파일은 **가장 가까운 업종 파일을 골라 빌려 쓰는 방법**이다. 고른 뒤에는 그 업종 파일을 열고, 아래 4)의 "다른 점"만 덧붙인다.
기본 플래그: `common`(항상). 나머지는 3)에서 정한다. 문자·카톡을 보내면 `ad-messaging`.

## 2) 가까운 카테고리 고르기 (축 질문 5개)

`guides/industries/index.md` 3)의 질문 5개를 한 번에 하나씩 묻는다. 이미 조사로 답을 알면 묻지 않고 "이렇게 봤는데 맞나요?"로 확인만 받는다.

1. 어디서 사나: 가게에 와서 / 찾아가서 / 온라인 / 회사가 주문
2. 얼마나 자주: 주마다 / 달마다 / 1년에 몇 번 / 평생 몇 번
3. 한 번에 얼마
4. 누가 결정: 본인 / 부모님 / 회사 담당자
5. 결과가 사진에 잘 나오나

점수 매기기:
1. 답마다 index.md 표의 후보 번호에 1점씩 준다.
2. 점수가 높은 2개를 고른다. 같으면 **4번(결정자) → 1번(구매 장소)** 순서로 가른다. 결정자와 구매 장소가 채널 1순위를 가장 크게 바꾸기 때문이다(판단).
3. 사장님께 2개를 보여 주고 고르게 한다:
   > "사장님 가게는 딱 맞는 업종 칸이 없어서, 손님이 사는 방식이 가장 비슷한 두 곳을 골랐어요. ① ○○(이유 한 줄) ② ○○(이유 한 줄). 어느 쪽이 더 가깝나요?"
4. 고른 업종 파일을 열고 "가까운 업종 기준으로 준비했어요"라고 말한다.

## 3) 규제 플래그 따로 정하기

업종 파일의 기본 플래그를 그대로 믿지 않는다. 파는 것·하는 일로 다시 본다.

| 이런 걸 하면 | 켤 플래그 |
|---|---|
| 먹을 것을 팔거나 만든다 | `food-origin` (기능성 문구를 쓰면 `health-food`) |
| 술·담배를 판다 | `alcohol` / `tobacco` |
| 몸·피부·건강 효과를 말한다 | `medical-misleading` (의료기관이면 `medical`) |
| 화장품·의료기기를 판다 | `cosmetics` / `medical-device` |
| 가르치고 수강료를 받는다(등록 학원·교습소) | `academy` |
| 보험·대출·투자 상품을 소개한다 | `finance` |
| 온라인·DM으로 주문을 받는다 | `ecommerce` |
| 회원권·이용권을 미리 판다 | `membership-refund`(체육시설·피부관리 고시 대상인지 확인 필요) |
| 어린이가 주 손님인 식품 | `children` |
| 동물을 팔거나 진료한다 | `veterinary` |

어느 것에도 안 걸리면 `common`, `ad-messaging`만 켠다. 업종 고유 법규가 있을 것 같은데 `guides/compliance/`에 없으면 "확인 필요"로 적고 사장님께 소관 협회·관청 규정을 물어본다.

## 4) 빌린 업종과 다른 점 적기

> 같은 업종도 브랜드 성격 카드(`guides/03-strategy.md` 4-1)로 말투·디자인·채널이 갈린다. 이 절은 기본값일 뿐이다.

빌린 업종 파일을 그대로 쓰면 어긋나는 부분이 있다. 브랜드 프로필에 "업종 메모"로 3줄을 적는다.

1. **손님 상황**: 빌린 파일 1)의 표에서 맞지 않는 상황을 지우고, 우리 가게 리뷰·문의에서 본 상황으로 바꾼다.
2. **채널 순서**: 경쟁 3~5곳(같은 지역+같은 업종 검색)의 플레이스 리뷰 수, 블로그 30일 글 수, 인스타 팔로워, 당근 단골 수를 세서 빌린 파일의 3)을 덮어쓴다. 업종 파일의 채널 순서는 어차피 초기 가설이다. 같은 업종도 상권에 따라 순서가 뒤집혔다(실측 2026-11, 상권별 비교).
3. **시즌**: 빌린 파일의 시즌은 지우고, 지난해 매출·문의가 많았던 달을 사장님께 묻는다. 모르면 "가정"으로 둔다.

당근 순위는 업종이 아니라 **출장 여부·공동구매 여부**로 정한다(실측 2026-11, 업종별 당근 단골 수 비교). 출장을 가거나 단골에게 공동구매·예약 판매를 하면 당근을 확장 이상으로 올린다.

## 5) 마케팅 대상이 아닌 경우

아래는 이 스킬로 돕기 어렵다. 솔직하게 말하고, 할 수 있는 최소한만 제안한다.

| 경우 | 이유 | 말하는 법 |
|---|---|---|
| 부동산 임대·관리만 함 | 소비자 대상 마케팅 수요가 낮아 대상에서 뺐다(판단) | "임대 공실 안내 글 정도는 도와드릴 수 있어요" |
| 구내식당·위탁급식 | 기업 계약(B2B 위탁)이라 손님 대상 콘텐츠가 맞지 않는다 | `23-b2b.md`의 문의 경로만 빌려 쓴다 |
| 종합·요양병원 | 소상공인 범위 밖, 의료광고 심의 대상 | "병원 홍보팀·심의 절차가 먼저예요" |
| 청소년 수련시설 등 공공 운영 | 공공·단체 운영 | 운영 기관 지침 확인 |

## 7) 제보 권하기

기타로 온 가게는 업종 목록을 늘릴 근거가 된다. 일이 끝나면 한 번 권한다(`guides/feedback.md`):
> "사장님 업종이 목록에 없어서 가까운 업종으로 준비했어요. 다음 사람을 위해 업종 추가를 제보해도 될까요? 올리기 전에 내용을 먼저 보여 드릴게요."
