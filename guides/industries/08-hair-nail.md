# 08. 헤어·네일·속눈썹

미용실, 바버샵, 네일숍, 속눈썹, 왁싱. 반영구화장·눈썹문신은 `09-skin-body.md`로 간다.
기본 플래그: `common`. 해당하면 `cosmetics`(샴푸·앰플 등 화장품 판매), `medical-misleading`(두피·탈모 관리, 왁싱의 '제모' 표현). 문자·카톡을 보내면 `ad-messaging`.

## 1) 이 업종 손님이 우리를 찾는 상황 (JTBD)

| 상황 | 손님 속마음 | 손님이 확인하는 것 |
|---|---|---|
| 머리할 때가 됨 | "가까운 데서 실패 없이" | 스타일 사진, 가격, 예약 가능 시간 |
| 원하는 스타일이 있음 | "이 스타일 잘하는 디자이너" | 디자이너별 포트폴리오, 후기 |
| 손상·망한 머리 | "고쳐 줄 수 있는 곳" | 복구 사례, 상담 |
| 행사·기념일 전 | "그날 맞춰 예쁘게" | 예약, 시술 시간 |
| 이달의 네일 | "이번 달 디자인 뭐 있지" | 이달의 아트, 가격 |

## 2) 맨 앞에 할 일 (첫 단계)

이 업종의 게이트는 **플레이스·예약**이다.

1. **네이버 예약**: 디자이너별 시간, 시술 메뉴를 넣는다.
2. **가격표 범위**: 기장·손상도에 따른 추가 요금을 미리 적는다(가격 불만 예방).
3. **포트폴리오**: **직접 시술한 사진**으로 채운다. AI 이미지·남의 사진은 쓰지 않는다.
4. 노출 → 예약 → 방문 순서로 숫자를 본다.
5. 화장품을 팔거나 두피·탈모 관리를 하면 표현 검수를 먼저 한다.

## 5) 사장님에게 받을 소재

## 7) 규제 플래그와 자주 걸리는 문장

| 걸리는 문장 | 이유 | 고친 문장 |
|---|---|---|
| "두피 재생 탈모 케어 샴푸" | 화장품 의약품 오인(`cosmetics`) | "두피를 산뜻하게 씻어 주는 샴푸" |
| "속눈썹이 자라는 영양제" | 화장품 금지 표현(모발: 속눈썹이 자란다) | "속눈썹을 촉촉하게 가꿔 줘요" |
| "탈모 치료 두피 관리" | 의료 오인(`medical-misleading`) | "두피 스케일링·마사지 관리" |
| "레이저처럼 영구 제모" | 의료(레이저 제모)와 혼동 | "왁스로 하는 제모 관리" |
| "10분 만에 무조건 세팅펌" | 효과 단정·실증 필요 | 실제 시술 시간과 조건을 사실대로 |
| "다른 데서 망친 머리 우리가 살려요" | 타 업소 비하 소지 | "손상모 복구 사례를 보여 드릴게요" |
| AI로 만든 모델 사진에 표시 없음 | 가상인물 표시(`common`) | 직접 시술 사진만 |
| 협찬 추천인데 표시 없음 | 추천·보증 표시 | 제목·첫 부분에 받은 내용 표시 |

손님 얼굴은 게시 동의를 받는다. 미성년 손님은 법정대리인 동의가 필요하다. 유행 음원은 사업자 계정 사용 가능 여부를 확인한다.

## 9) 하지 않을 것

- AI 이미지·남의 시술 사진으로 포트폴리오 채우기.
- 동의 없는 손님 얼굴 게시, 미성년 손님 얼굴 노출.
- 판매 화장품에 효능·치료 단어.
- 다른 미용실 비하.
- 설명란·제목에 개인 전화번호 노출.
- 리뷰 대가 이벤트를 먼저 제안하기. 사장님이 원하면 네이버 허용 조건(실제 결제 영수증, 별점·내용 관여 금지)과 금지 행위(점수·표현 요구, 작성 화면 확인·대신 작성, 이벤트용 저가 영수증, 대행·리워드 앱 — 한 번만 걸려도 가게 리뷰 전체가 안 보일 수 있음, 네이버 공지 2026-01)를 알리고 진행한다(`guides/08-operations.md` 1절). 별점 조건·만족한 손님만 골라 부탁·지인 리뷰는 언제나 금지.
