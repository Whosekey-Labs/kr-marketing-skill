# 25. 1인 크리에이터·프리랜서·강사

유튜버·인플루언서, 강사·코치, 작가, 프리랜서 디자이너·개발자, 보험설계사·대출상담사. 상품이 **나 자신(사람)**이다. 매장을 연 공방 수업은 `12-adult-class.md`, 사무소를 둔 전문직은 `21-professional-office.md`.
기본 플래그: `common`. 설계사·대출상담사는 `finance`(필수), 등록 학원·교습소로 가르치면 `academy`, 협찬을 받으면 `common`의 추천·보증 표시가 핵심. 문자·카톡을 보내면 `ad-messaging`.

## 1) 이 업종 손님이 우리를 찾는 상황 (JTBD)

손님은 **이 사람이 믿을 만한가**를 본다. 글·영상으로 먼저 만나고 나서 연락한다. (아래는 판단 가설)

| 상황 | 손님 속마음 | 확인하는 것 |
|---|---|---|
| 회사·기관이 강사를 찾음 | "주제 맞고 실수 없는 강사" | 강의 주제·경력, 강의 현장 사진·영상, 강의안 |
| 개인이 배울 곳·코치를 찾음 | "나한테 맞는 사람인가" | 가르치는 방식, 수강생 이야기, 가격 |
| 보험·대출 상담이 필요 | "팔려고만 하지 않는 사람" | 쉬운 설명, 꾸준한 글, 연락처 |
| 디자인·개발 외주를 맡김 | "결과물 수준, 마감 지키나" | 포트폴리오, 진행 절차, 리뷰 |
| 브랜드가 협업할 크리에이터를 찾음 | "우리 고객과 맞는 채널" | 주제 일관성, 반응, 협업 사례 |

## 2) 맨 앞에 할 일 (첫 단계)

1. **갈래와 규정 확인**: 설계사·대출상담사는 **직접 광고가 원칙적으로 안 된다**(금융소비자보호법 시행령 제17조, 7절). 소속 회사(보험사·GA)의 광고 허용 범위와 준법감시인 심의 절차를 먼저 받는다·필수. 확인 전에는 상품 광고를 만들지 않는다.
1-1. **공통 단계 대신 쓸 질문**: 가게에 손님이 찾아오지 않으므로 '빈 시간·손님 한 분이 쓰는 돈' 대신 `23-b2b.md` 2)의 질문 4개(리드 경로, 영업 주기, 의사결정자, 계약 단가)를 쓴다. 개인 손님이 많으면 3번을 "누가 돈을 내나(본인·회사·부모)"로 바꾼다.
2. **한 줄 정체성**: 누구에게 무엇을 돕는 사람인지 한 문장. 모든 채널 소개란을 이 문장으로 맞춘다.
3. **연락 경로 하나**: 문의 폼·카톡 채널·이메일 중 하나로 모은다. 블로그·채널 소개에 같은 경로.
4. **포트폴리오·이력 정리**: 강의 이력, 작업물, 출연·기고. 공개 동의가 필요한 것(고객사 이름·수강생 얼굴)은 표시한다.
5. 같은 분야 3~5명의 블로그 30일 글 수, 유튜브 구독자, 중개 플랫폼 등록을 기록해 0)의 순서를 덮어쓴다.

## 7) 규제 플래그와 자주 걸리는 문장

| 걸리는 문장 | 이유 | 고친 문장 |
|---|---|---|
| (설계사) 개인 블로그·인스타에 "○○생명 신상품 비교해 드려요" | 판매대리·중개업자는 원칙적으로 금융상품 광고 금지, 직접판매업자가 허용할 때만(금소법 제22조, 시행령 제17조). 허용돼도 준법감시인 심의 | 상품 광고 없이 일반 정보 글만(예: "보험 가입 전 약관에서 볼 곳"). 상품 광고는 회사 심의 뒤에만. SNS 허용 범위는 감독규정 원문 미확인(확인 필요) |
| "하루 1,000원으로 암 진단비 5천만 원" | 보험료 일 단위 표시, 고액 보장만 강조(금소법 제22조④) | 쓰지 않는다 |
| "실비 갈아타면 무조건 이득" | 기존 계약 해지 불이익 안내 누락, 단정 | 쓰지 않는다 |
| 협찬 받은 리뷰 영상에 "#협찬"을 더보기 안에만 | 추천·보증 심사지침(제목·영상 안·첫 부분) | 영상 시작과 제목에 "유료 광고 포함", 인스타는 브랜디드 콘텐츠 표시 |
| "수강생 100% 합격", "3개월 만에 월 천" | 실증 책임(표시광고법 제5조), 등록 학원이면 과대 광고 행정처분(학원법 제17조①9호) | 실제 사례 하나를 기간·조건과 함께, 동의 받아서 |
| (등록 학원·교습소) 모집 글에 교습비·등록번호 없음 | 학원법 제15조③, 시행령 제16조의3(`academy`) | 교습비, 등록번호, 명칭, 교습과정 표시 |
| AI로 만든 "수강생"이 후기를 말하는 영상 | AI 가상인물 표시 + 경험 없는 후기(추천·보증 심사지침) | 실제 후기만 |
| 유명인 목소리·얼굴을 AI로 흉내 낸 홍보 | 퍼블리시티권(부정경쟁방지법 제2조1호 타목) | 쓰지 않는다 |

뉴스레터·문자·DM 홍보는 `ad-messaging`(사전 동의, 수신거부 표기). 남의 카페에 홍보 글 반복도 금지(정보통신망법 제50조의7).

## 9) 하지 않을 것

- (설계사·대출) 회사 허용·심의 없이 상품 광고.
- 수입·합격·성과를 보장하는 문구.
- 협찬 표시를 더보기·마지막 해시태그에 숨기기.
- 동의 없는 수강생·고객 얼굴·이름 공개.
- 주제 없이 매일 아무 글이나 올리기(네이버 공식 기준: 일관된 주제).
- 링크드인부터 시작하기(근거 없음).
