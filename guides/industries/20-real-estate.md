# 20. 부동산 중개

공인중개사 사무소(주거·상가·토지), 분양 대행. 임대·관리만 하는 곳은 마케팅 대상이 아니다(`00-other.md`).
기본 플래그: `common`, `real-estate`. 문자·카톡을 보내면 `ad-messaging`.

## 1) 이 업종 손님이 우리를 찾는 상황 (JTBD)

손님은 매물에서 출발한다. "이 동네에 이런 집 있나"를 찾다가 중개사를 만난다. 1단계 조사에서 문의 기록·검색어로 우리 사무소의 상황 3개를 고른다. (아래는 판단 가설)

| 상황 | 손님 속마음 | 손님이 확인하는 것 |
|---|---|---|
| 전·월세 집 구하기 | "예산 안에서 빨리, 사기 안 당하게" | 실제 매물 사진, 가격, 입주 가능일, 관리비 |
| 아파트 매매 | "이 단지 시세가 맞나" | 단지·평형 정보, 최근 거래, 동네 해설 |
| 상가 임차·창업 | "장사가 될 자리인가" | 상권 설명, 권리금·보증금, 면적, 주차 |
| 토지·전원주택 | "멀리 있어도 직접 보는 것처럼" | 현장 영상, 지목·면적, 길·주변 |
| 내 집 팔기·내놓기 | "믿고 맡길 사무소" | 이 동네 거래 경험, 사무소 정보, 응대 |

## 2) 맨 앞에 할 일 (첫 단계)

이 업종의 게이트는 **표시·광고 규정**이다. 매물 글 하나도 이것부터 맞춘다.

1. **사무소 필수 정보 확보(먼저 받는다·필수)**: 중개사무소 명칭·소재지·연락처(등록관청에 신고한 번호)·등록번호, 개업공인중개사 성명. 모든 광고에 들어간다(공인중개사법 시행령 제17조의2①).
2. **중개보조원 확인**: 보조원 이름·번호는 광고에 넣지 않는다. 연락처에 실장(보조원) 휴대폰을 쓰지 않는다.
3. **매물 정보 표 틀 만들기**: 인터넷 광고 필수 항목(소재지, 전용면적㎡, 단일가격, 종류, 거래형태, 총 층수, 사용승인일, 방향(기준 포함), 방 수, 욕실 수, 입주가능일, 주차대수, 관리비)을 칸으로 둔다. 빈칸이 있으면 올리지 않는다.
4. **매물 관리 규칙**: 계약 완료를 통보받으면 3일 안에 모든 채널에서 내린다. 사장님과 "계약되면 바로 알려 주기"를 약속한다.
5. **플레이스·네이버부동산** 정보가 사무소 정보와 같은지 본다. 네이버 '부동산 중개사 광고'(2025-11)는 사용 여부를 사장님께 확인한다(네이버 공지, 내용 확인 필요).

## 3) 채널 등급 가설

| 등급 | 채널 | 할 일 | 근거 |
|---|---|---|---|
| 핵심(도시) | 네이버 블로그(사장님) | 매물 소개, 시장·제도 해설 | 부동산 블로그 검색 상위 10위의 62%가 사업자 블로그(실측 2026-11, 네이버 블로그 검색 상위 10위). 월 발행 중앙값 9.2편 |
| 핵심(도시) | 네이버 플레이스·네이버부동산 | 사무소 정보, 매물 등록 | 실측(2026-11) 순서 "도시 아파트: 블로그 > 플레이스" |
| 핵심(토지·전원) | 유튜브 | 현장 영상 매물 투어 | 실측(2026-11) 순서 "토지·전원주택: 유튜브 > 블로그" |
| 확장 | 숏폼(쇼츠·릴스·클립) | 매물 투어 짧은 버전, 동네 정보 | 숏폼 표본 12편 중 F10 공간·매물 투어 4, F04 정보·Q&A 토크 4(실측 2026-11, 업종별 숏폼 표본) |
| 확장 | 인스타 카드뉴스 | 동네·제도 정보 | 개인 부동산 인플루언서의 캐릭터·노트형이 강하다. 중개사무소 글은 전단·뉴스형이라 무겁다(실측 2026-11) |
| 확장(시험) | 당근 | 동네 전·월세 매물 | 근거 없음. 경쟁 사무소가 쓰면 시험 |

갈래별 차이:
- **도시 아파트·원룸**: 블로그 > 플레이스·네이버부동산 > 숏폼.
- **토지·전원주택**: 유튜브 > 블로그. 영상 하나에 매물 정보 표를 설명란에 함께 둔다.
- **상가**: 블로그 매물 + 상권 해설. 조사 근거가 적다(가설).

## 4) 콘텐츠 기둥과 주력 유형

> 같은 업종도 브랜드 성격 카드(`guides/03-strategy.md` 4-1)로 말투·디자인·채널이 갈린다. 이 절은 기본값일 뿐이다.

기둥 예(판단): ① 실제 매물 ② 동네·단지 해설 ③ 계약·제도 정보(전세 사기 예방, 세금, 법 개정) ④ 중개사 사람·일하는 방식.

| 원본 | 주력 유형 (코드) | 메모 |
|---|---|---|
| 블로그 | B13 매물 소개, B01 정보 칼럼(시장·제도 해설), B02 질문에 답하기(Q&A, 계약 정보) | 매물 글의 83%가 매물 정보 표를 넣었다. 사진 17장 안팎(실측 2026-11). 문체 V1 또는 V3(V5 캐릭터 화자형은 권하지 않음). 스티커·이모티콘이 많은 편 |
| 카드뉴스 | C06 정보·꿀팁(번호 목록·체크리스트 틀, 주제 칩 '뉴스·제도'), C07 자주 묻는 질문, C10 우리 가게·사람 | 부동산 경향: 리스트 5, 뉴스·제도 3 / 스타일 S06 그림·캐릭터, S04 브랜드 색(실측 2026-11) |
| 숏폼 | F10 공간·매물·체험 투어, F04 사장님 정보·Q&A 토크, F11 밈·상황극·챌린지 | 부동산 숏폼 표본 12편: 4·4·2편(실측 2026-11) |

매물 글 구조(B13, `guides/styles/blog.md`): 인사·중개사 소개 → 매물 요약 → **매물 정보 표** → 사진(내부·외부·주변) → 입지·상권 → 사무소 정보·전화 + 지도.

## 5) 사장님에게 받을 소재

처음 한 번:
- [ ] 사무소 명칭·주소·신고 전화번호·등록번호·개업공인중개사 성명(먼저 받는다·필수)
- [ ] 사무소 외관·내부 사진, 사장님 사진(선택)
- [ ] 자주 받는 질문 5개, 이 동네 손님이 많이 찾는 매물 종류
매물마다:
- [ ] 매물 정보 표 13개 항목 전부, 위반건축물·미등기 여부
- [ ] **그 매물** 실제 사진(내부·외부·주변), 세로 영상 30초(현관→거실→방 순서)
- [ ] 의뢰인의 광고 동의, 계약 완료되면 바로 알려 주기

## 6) 시즌·월별 기회

연중 고정 달력 근거는 없다. 아래는 근거가 있는 일정만 쓴다.

| 시기 | 기회 |
|---|---|
| 우리 동네 새 아파트 입주·분양 공고 | 단지 해설, 입주 전후 전·월세 매물 |
| 세법·부동산 제도가 바뀔 때 | 시장·제도 해설 글(시행일·출처 링크 필수) |
| 학기 시작 전(대학가·학원가 상권) | 원룸·전·월세 매물 (지난해 문의 기록으로 확인, 없으면 "가정") |
| 명절 연휴 | 사무소 휴무·상담 가능일 공지 |

## 7) 규제 플래그와 자주 걸리는 문장

`guides/compliance/real-estate.md` 검수표를 매물 글·영상마다 돌린다. 블로그·유튜브·인스타·당근 모두 대상이다.

| 걸리는 문장 | 이유 | 고친 문장 |
|---|---|---|
| "역세권 3분!" | 역까지 거리를 도보가 아닌 직선거리로 표시(부당광고 고시) | "○○역 ○번 출구까지 도보 약 ○분(직접 걸어 잰 시간)" |
| "급매, 시세보다 1억 싸게" | 의뢰받은 가격과 다르거나 근거 없는 비교 | "매매가 ○억 ○천만 원(의뢰 가격)" 단일가격으로 |
| 다른 집 인테리어 사진·AI로 꾸민 방 사진 | 해당 매물이 아닌 사진 사용 금지 | 그 매물 실제 사진만. 실제 방처럼 보이는 AI 이미지는 쓰지 않는다(누가 봐도 그림인 일러스트만 장식으로) |
| 계약 끝난 매물 영상을 계속 둠 | 계약 완료 통보 후 3일 안에 삭제 의무 | 계약 알림 받으면 모든 채널에서 내림 |
| "문의: 김실장 010-…" | 중개보조원 정보·번호 표시 금지 | 등록관청에 신고된 사무소 번호와 개업공인중개사 성명 |
| 면적 "34평" 만 표기 | 인터넷 광고는 전용면적(㎡) 명시 | "전용 84.9㎡(공급 ○○㎡)" |
| 관리비 "저렴" | 월 10만 원 이상 정액이면 비목별 표시 | "관리비 월 ○○만 원(일반관리비 ○, 청소비 ○…)" |

제재: 부당 광고 과태료 500만 원 이하, 명시사항 누락 100만 원 이하, 개업공인중개사가 아닌 사람의 중개대상물 광고는 형사처벌(1년 이하 징역 또는 1천만 원 이하 벌금). 고시 2026-07-03 개정 내용은 원문 대조가 안 됐다(확인 필요).

## 8) KPI

| 층 | 지표 | 확인 위치 |
|---|---|---|
| 결과(월) | 계약 건수, 중개 보수 합계, 매물 접수(내놓기) 건수 | 사무소 장부 |
| 행동(주) | 매물 문의 전화·톡 수(채널별), 블로그·유튜브 유입 | 문의 기록, 블로그·유튜브 통계 |
| 실행(주) | 매물 글·영상 수, 명시사항 누락 0건, 계약 매물 3일 내 삭제율 | 직접 기록 |

- 문의마다 "어떤 글·영상 보고 연락하셨어요?"를 기록한다.
- 조회수가 높아도 문의로 안 이어지면 매물 정보 표·가격·응대를 먼저 본다.

## 9) 하지 않을 것

- 없는 매물·의뢰받지 않은 매물로 문의 받기(미끼 매물).
- 매물 정보 표 없는 매물 글.
- 중개보조원이 자기 이름으로 광고하게 하기.
- AI로 만든 집 사진을 매물 사진처럼 쓰기.
- "무조건 오른다", "투자 보장" 같은 단정. 시장 해설은 출처와 날짜를 붙인다.
- 같은 틀 매물 글을 문장만 바꿔 대량 발행하기(네이버 스팸 정책).
