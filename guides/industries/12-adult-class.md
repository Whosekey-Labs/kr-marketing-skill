# 12 성인·취미·자격 클래스

원데이 클래스, 공방 수업(도자기·향수·가죽 등), 직업훈련, 컴퓨터, 자격증·고시, 운전학원, 성인 외국어.
결정자는 수강생 본인이다(11 어린이 학원과 다른 점).
근거 표시: [공식] 법령 원문 / [실측] 세어 본 값 / [판단] 가설.

## 1. 이 업종 손님이 우리를 찾는 상황

[판단] 가설이다. 1단계에서 확인한다.
- 데이트·친구 모임·기념일에 할 거리를 찾는다("성수 도자기 원데이").
- 선물로 직접 만든 물건을 주고 싶다.
- 자격증·취업 준비로 과정을 비교한다(기간·비용·합격 지원).
- 인스타에서 작품 사진을 보고 예약 링크를 누른다.

갈래: **체험형**(원데이·공방)과 **과정형**(자격증·외국어·컴퓨터·운전). 과정형은 학원 등록 여부부터 확인한다.

## 2. 맨 앞에 할 일

1. **네이버 예약을 연다.** 실측 3곳 모두 네이버 예약을 썼고, 인스타 소개란 예약 링크도 네이버 예약이었다 [실측, 2026-11, 매장 3곳]. 클래스 종류·시간·정원·가격을 예약 상품으로 넣는다.
2. 등록 학원·교습소인지 확인한다. 등록돼 있으면 모집 광고에 교습비·등록번호·명칭·교습과정 표시 의무가 생긴다(학원법 제15조③) [공식].
3. 플레이스 대표 사진을 실제 작품·수업 장면으로 바꾼다.
4. 키트 택배·온라인 클래스를 팔면 통신판매 표시 사항을 점검한다(전자상거래법 제13조).

## 3. 채널 등급 가설

| 등급 | 채널 | 근거 |
|---|---|---|
| 핵심 | 네이버 플레이스 + 네이버 예약 | [실측] 표본 공방 3곳(성수 도자기 공방 A, 향수공방 B, 공방 C) 방문·블로그 리뷰 수십~약 1천. 3곳 모두 네이버 예약 |
| 핵심 | 인스타(작품·수업 장면) ≈ 블로그 | [실측] 인스타는 100명 안팎~2만 명대로 편차가 크다. 블로그와 비슷한 비중으로 둔다(실측 2026-11, 매장 3곳) |
| 확장 | 숏폼(릴스·클립·쇼츠) | [실측] 공방 숏폼은 작업 과정이 주력 |
| 확장 | 클래스 플랫폼(프립·탈잉 등) | [판단] 등록 여부·효과 미확인 |
| 확장 | 당근 | [판단] 미확인. 경쟁 클래스 단골 수로 판단 |

과정형(자격증·외국어 등)은 위 표본에 없다. 진단에서 경쟁 3~5곳을 세어 순서를 정한다.

## 4. 콘텐츠 기둥과 주력 유형

> 같은 업종도 브랜드 성격 카드(`guides/03-strategy.md` 4-1)로 말투·디자인·채널이 갈린다. 이 절은 기본값일 뿐이다.

기둥(예): ① 작품·수업 과정 ② 수강생 작품·이야기 ③ 클래스 안내(일정·가격·예약) ④ 사장님 이야기.

| 원본 | 1순위 | 2순위 | 3순위 | 근거 |
|---|---|---|---|---|
| 블로그 | B06 사장님 일기·비하인드 | B09 신메뉴·신상품·입고(새 클래스·작품) | B08 이벤트·공지·모집 / B05 고객 변화 이야기 | 실측(2026-11, 네이버 블로그 검색 상위 10위, 공방·꽃집) |
| 카드뉴스 | C04 공지(모집) | C11 공간 투어 | C10 우리 가게·사람 | [판단] 카드뉴스 표본에 성인 클래스 업체 없음. `guides/styles/cardnews.md` 12유형에서 고름 |
| 숏폼 | F01 작업 과정·ASMR | F09 손님 썰·에피소드 | F14 이벤트·신상 공지 | 실측(2026-11, 업종별 숏폼 표본): 공방 12편 중 5편이 작업 과정 |

- 블로그 말투: 공방은 해요체 주력 → 문체 V2 친근한 동네 사장형 또는 V4 장사 일기형(`guides/styles/blog.md` 4절).
- 과정형은 B01 정보 칼럼, B10 가격·주문·이용 안내(수강 절차)를 앞에 둔다[판단].
- B10 가격·주문·이용 안내 글 하나를 고정해 두고 예약 문의에 링크로 준다.

## 5. 사장님에게 받을 소재 목록

- 클래스별 시간·정원·가격·준비물·예약 방법
- 완성 작품 사진(정면·손에 든 모습), 수업 중 손 클로즈업 10초 세로 영상
- 수강생 작품 사진(수강생 동의, 얼굴은 동의한 것만)
- 공간 사진(작업대, 입구, 창가)
- 사장님이 이 일을 시작한 이야기 한 단락(음성 메모 가능)
- 등록 학원이면 등록증·교습비 표

## 7. 규제 플래그

켜는 플래그: **common**, **ad-messaging**. 해당할 때만: **academy**(등록 학원·교습소), **ecommerce**(키트 택배·온라인 클래스 판매).

| 자주 걸리는 문장 | 왜 | 고친 문장 |
|---|---|---|
| "자격증반 모집! 문의 DM"(등록 학원) | 교습비·등록번호·명칭·교습과정 없음(학원법 제15조③) [공식] | "○○컴퓨터학원(등록 제[직접 입력]호) ○○자격 과정, 교습비 [직접 입력]원" |
| "합격률 98%" | 근거 없는 수치는 표시광고법 거짓·과장, 실증 책임 | 증빙 있는 사실만, 기간·대상 명시 |
| "키트 판매합니다, 가격은 DM" | 통신판매 광고에 상호·대표자·연락처·신고번호, 가격·배송·청약철회 표시 필요(전자상거래법 제13조) | 사업자 정보와 가격·배송비·교환 조건을 함께 |
| "9,900원 원데이"(결제 때 재료비 추가) | 필수 비용 쪼개기(제21조의2 다크패턴) | 재료비 포함 총액을 처음부터 |
| 수강생 후기를 할인 대가로 받음 | 경제적 이해관계 표시(추천·보증 지침) | 첫 부분에 "수강료 할인 제공" |

## 8. KPI

| 층 | 지표 |
|---|---|
| 행동(핵심) | 네이버 예약 건수, 예약 페이지 유입, 저장 |
| 전환 | 문의 → 예약, 재수강률 |
| 평판 | 방문자 리뷰·블로그 리뷰 수 |
| 콘텐츠 | 인스타 저장·공유, 프로필 링크 클릭 |

## 9. 하지 않을 것

- 수강생 작품을 동의 없이 올리기, 남의 작품 사진 쓰기
- 재료비·추가비를 숨긴 최저가 광고
- 근거 없는 합격률·취업률
- AI로 만든 작품 사진을 실제 작품처럼 쓰기
