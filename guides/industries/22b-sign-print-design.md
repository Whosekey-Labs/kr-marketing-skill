# 22b. 간판·인쇄·디자인 제작

간판·현수막·실사 출력, 명함·전단·인쇄·복사, 시각·제품 디자인 사무소. 손님 대부분이 **다른 사장님(사업자)**이다. 사진관·웨딩은 `22a-photo-wedding.md`, 광고 대행·행사 대행은 `23-b2b.md`, 1인 프리랜서 디자이너는 `25-solo-brand.md`.
기본 플래그: `common`. 플래그 밖 확인: 옥외광고물(간판·현수막 허가·신고, 조문 미확인), 폰트 라이선스. 문자·카톡을 보내면 `ad-messaging`.

## 1) 이 업종 손님이 우리를 찾는 상황 (JTBD)

손님은 **가게 오픈·행사 날짜**에 쫓겨 검색한다. 비슷한 업종의 시공 사례를 보고 견적을 묻는다. 1단계 조사에서 문의 기록으로 상황 3개를 고른다. (아래는 판단 가설)

| 상황 | 손님 속마음 | 손님이 확인하는 것 |
|---|---|---|
| 새 가게 오픈 | "오픈 날짜 맞춰 간판·메뉴판·명함 한 번에" | 같은 업종 시공 사례, 제작 기간, 견적 범위 |
| 간판 교체·보수 | "낡은 간판 바꾸고 싶다, 허가는?" | 전후 사진, 허가 안내, 비용 |
| 행사·선거·이벤트 현수막 | "내일까지 필요" | 당일·익일 제작 여부, 가격표 |
| 명함·전단·스티커 인쇄 | "싸고 빠르게, 실수 없이" | 종이·수량별 가격, 주문 방법, 파일 규격 |
| 로고·브랜드 디자인 | "우리 가게다운 디자인" | 포트폴리오, 작업 과정, 수정 횟수 |

## 2) 맨 앞에 할 일 (첫 단계)

이 업종은 B2B에 가깝다. 게이트는 **사례 자산과 견적 경로**다(B2B는 문의 경로부터, `23-b2b.md`).

1. **문의 경로 정리**: 전화·카톡 채널·네이버 톡톡·견적 폼 중 받는 곳을 정하고, 견적에 필요한 것(크기, 수량, 설치 위치 사진, 희망 날짜)을 한 번에 받는 질문 목록을 만든다.
2. **시공·제작 사례 정리**: 지난 작업을 업종별(음식점·학원·병원 등)로 모은다. 고객 상호가 크게 보이는 작업은 게시 동의를 받는다.
3. **가격·주문 안내 고정 글**: 명함·현수막처럼 정찰 가격이 있는 품목은 가격표와 주문 순서를 한 글에 정리한다.
4. **폰트 라이선스 점검**: 작업에 쓰는 폰트가 상업용(인쇄·간판·로고)으로 허용되는지 확인한다.
5. 경쟁 3~5곳(지역+간판, 지역+현수막 검색)의 블로그 30일 글 수, 홈페이지 유무를 기록한다.

## 3) 채널 등급 가설

| 등급 | 채널 | 할 일 | 근거 |
|---|---|---|---|
| 핵심 | 네이버 블로그(사장님) | 시공·제작 사례 연재 | 간판 부천 현진사 플레이스 방문 22 / 블로그·카페 리뷰 820. 간판·인쇄는 블로그 시공 사례가 주력(실측 2026-11) |
| 핵심 | 홈페이지 + 네이버 검색(파워링크) | 견적 문의 받는 곳 | 실측(2026-11) 순서 2위 |
| 확장 | 네이버 플레이스 | 지도·전화 | 실측(2026-11) 순서 3위 |
| 확장 | 인스타그램 | 완성 사진 | 간판·인쇄 인스타는 1천 명 안팎, 최대 4,926(성원애드피아, 실측 2026-11) |
| 확장(시험) | 크몽 등 외주 플랫폼 | 로고·디자인 단품 | 가설, 등록 여부 미확인 |
| 확장(시험) | 당근 | 동네 가게 현수막·간판 | 근거 없음. 경쟁 업체가 쓰면 시험 |

갈래별 차이:
- **간판·현수막(시공형)**: 블로그 사례 > 검색·홈페이지 > 플레이스.
- **인쇄·복사(매장형)**: 플레이스 > 가격·주문 안내 글 > 블로그.
- **디자인 사무소**: 포트폴리오(블로그·인스타) > 외주 플랫폼. 근거가 적다(가설).

## 5) 사장님에게 받을 소재

처음 한 번:
- [ ] 지난 작업 10~20건: 전·후 사진, 업종, 크기·소재, 제작 기간 한 줄, 게시 동의 여부
- [ ] 작업장 사진(출력기·커팅·도장), 설치 현장 사진
- [ ] 품목별 가격표(정찰 품목만), 주문 순서, 파일 규격
- [ ] 쓰는 폰트 목록과 라이선스
매 작업마다: 설치 전 1장, 작업 중 1~2장, 완성 1장(낮·밤), 세로 영상 10초(설치·점등 장면).

## 6) 시즌·월별 기회

이 업종 시즌 근거 자료는 없다. 손님 업종의 시즌을 따라간다(가정, 지난해 주문 기록으로 확인).

| 시기 | 기회 (가정) |
|---|---|
| 학원 겨울특강·설명회 철(학원 검색은 10월부터 오름, 실무 관행) | 학원 현수막·전단 사례 |
| 연말·연초 | 달력·연하장·새해 현수막 |
| 선거 | 선거 현수막(선거법은 이 스킬에서 확인하지 못함 → 사장님 확인) |
| 상권에 새 상가 입주 | 오픈 패키지(간판+명함+전단) 사례 |

## 7) 규제 플래그와 자주 걸리는 문장

| 걸리는 문장 | 이유 | 고친 문장 |
|---|---|---|
| "허가 걱정 없는 간판" | 옥외광고물 허가·신고는 지역·크기별로 다름(조문 미확인) → 단정 금지 | "설치 위치별로 허가·신고가 필요한지 같이 확인해 드려요" |
| "업계 최저가", "지역 1위 간판" | 근거 없는 비교·1위(표시광고법 제3조·제5조) | 가격표와 제작 기간 사실만 |
| 고객 가게 간판 사진에 상호·전화 노출(동의 없음) | 고객사 정보 무단 사용 | 동의 받은 작업만, 아니면 상호를 가림 |
| 개인용 무료 폰트로 만든 시안을 포트폴리오로 | 폰트 파일 라이선스(저작권, 확실도 낮음) | 상업 허용 폰트로 다시 만들거나 출처·라이선스 확인 |
| 남이 만든 캐릭터·유명 브랜드 로고를 넣은 시안 | 저작권·퍼블리시티권 | 고객이 권리를 가진 자료만 |
| 손님 업체에 보내는 홍보 문자·메일 | `ad-messaging`: 사전 동의(거래 후 6개월 안 같은 종류만 예외), 문자는 21~08시 별도 동의 | 거래한 손님에게만, "(광고)"·수신거부 방법 표기 |

## 9) 하지 않을 것

- 남의 시공 사진·디자인을 포트폴리오로 쓰기.
- 허가 여부를 단정하는 문구.
- 라이선스 확인 안 한 폰트로 만든 결과물 게시.
- 같은 사진에 문장만 바꾼 사례 글 반복(네이버 스팸 정책).
- 동의 없는 영업 문자·메일 대량 발송.
