# 21. 세무·법무·노무 사무소 (전문직)

세무사, 회계사, 변호사, 법무사, 노무사, 행정사, 변리사.
기본 플래그: `common`, `legal-tax`. **직역마다 광고 조문이 다르다**(7절). 회계사·변리사 광고 규정은 확인하지 못했다 → "확인 필요"로 두고 `common` 기준으로 검수한다. 문자·카톡을 보내면 `ad-messaging`.

## 1) 이 업종 손님이 우리를 찾는 상황 (JTBD)

손님은 **문제가 생긴 순간** 검색한다. 질문 하나를 들고 와서 답을 읽다가 상담을 신청한다. 1단계 조사에서 상담 기록·검색어로 상황 3개를 고른다. (아래는 판단 가설)

| 상황 | 손님 속마음 | 손님이 확인하는 것 |
|---|---|---|
| 신고 기한이 다가옴(종합소득세·부가세) | "혼자 해도 되나, 맡기면 얼마" | 쉬운 설명, 업종별 경험, 수수료 안내 방식 |
| 창업·법인 설립 | "처음이라 뭘 해야 할지" | 절차 정리, 체크리스트 |
| 분쟁·사건(이혼·형사·임금체불·해고) | "급하다, 믿을 사람" | 비슷한 쟁점 설명, 사무소 정보, 응대 |
| 세무조사·통지서를 받음 | "이게 무슨 뜻이지" | 통지서별 Q&A |
| 등기·인허가 서류 | "빨리, 한 번에" | 절차·서류 목록, 기간 |

## 2) 맨 앞에 할 일 (첫 단계)

이 업종의 게이트는 **직역 광고 규정**이다. 첫 글 전에 한다.

1. **직역 확인**: 변호사·세무사·노무사·행정사·법무사·회계사·변리사 중 무엇인지, 법인인지. 7절의 해당 조문을 브랜드 프로필 "금지 표현"에 넣는다.
2. **이름·자격 표기 정리**: 사무소 정식 명칭, 자격 표기, 담당자 실명. 변호사는 **광고마다 광고책임변호사 성명**을 넣는다(변협 규정 제3조②).
3. **'전문' 표시 확인**: 변호사는 변협 전문분야 등록을 했을 때만 "○○ 전문"(규정 제9조①). "전문"을 쓰려면 등록증을 먼저 받는다·필수.
4. **AI 사용 확인(변호사)**: 변협 규정 제6조는 AI 활용 광고 시 사전 등록과 검토 변호사 이름 표시를 요구한다. 이 스킬로 만든 글이 여기에 해당하는지 사장님(변호사)께 확인받는다(확인 필요).
5. **블로그·플레이스 기본**: 상담 방법·주소·전화, 대표 사진(사무소·사람). 경쟁 3~5곳의 블로그 30일 글 수, 유튜브 구독자를 기록한다.

## 3) 채널 등급 가설

| 등급 | 채널 | 할 일 | 근거 |
|---|---|---|---|
| 핵심 | 네이버 블로그(사장님) | 정보 칼럼·Q&A 연재 | 세무·법률 블로그 검색 상위 10위의 **80%가 사업자 블로그**(실측 2026-11, 네이버 블로그 검색 상위 10위). 월 발행 중앙값 18.8편(대행·자동 발행일 수 있음) |
| 핵심 | 네이버 플레이스 | 사무소 정보·상담 연결 | 실측(2026-11) "1인 사무소: 블로그 > 플레이스" |
| 확장(키우는 곳) | 유튜브 | 쟁점 설명 영상 | 실측(2026-11) "키우는 사무소: 블로그 + 유튜브" |
| 확장 | 숏폼 | 짧은 Q&A, 일하는 하루 | 세무·법률 숏폼 표본 12편: F07 브이로그 3, F04 정보·Q&A 토크 3(실측 2026-11) |
| 확장 | 인스타 카드뉴스 | 제도·용어 정리 | 세무·법률 카드뉴스 실측(2026-11): 남색+인물 사진 신뢰형과 웹툰·단색 친근형으로 나뉨 |
| 제외(기본) | 당근 | 근거 없음 | — |

갈래별 차이:
- **1인 사무소**: 블로그 > 플레이스. 주 2~3편이라도 꾸준히가 먼저다.
- **키우는 사무소**: 블로그 + 유튜브. 원장 얼굴이 나오는 설명 영상이 중심.

## 4) 콘텐츠 기둥과 주력 유형

> 같은 업종도 브랜드 성격 카드(`guides/03-strategy.md` 4-1)로 말투·디자인·채널이 갈린다. 이 절은 기본값일 뿐이다.

기둥 예(판단): ① 신고·기한 일정 해설 ② 손님 질문 Q&A ③ 절차·선택 가이드 ④ 사람·사무소 이야기(신뢰).

| 원본 | 주력 유형 (코드) | 메모 |
|---|---|---|
| 블로그 | B01 정보 칼럼, B02 질문에 답하기(Q&A), B03 비교·선택 가이드 | 세무법률 표본 32편: 칼럼 15, Q&A 9, 가이드 4(실측 2026-11). 문체 V1 전문가 칼럼형(합니다체·이모티콘 없음·실명) |
| 카드뉴스 | C06 정보·꿀팁(주제 칩 '뉴스·제도'), C07 자주 묻는 질문, C10 우리 가게·사람 | `guides/styles/cardnews.md` 업종 기본 추천 |
| 숏폼 | F04 사장님 정보·Q&A 토크, F08 시간 자막 오픈 루틴(G7, F07 하루 브이로그는 그대로 만들지 않음), F06 N가지 리스트 | F09 손님 썰·에피소드는 의뢰인이 특정되면 안 된다(7절) |

Q&A 글 구조(B02, `guides/styles/blog.md`): 인사·자기소개 → "상담하다 보면 자주 듣는 질문" → 결론 먼저 → 인용구 소제목 → 경우별 설명(표) → 정리 → 상담 안내 + 지도.
주의: "지역+업종, 질문?" 같은 틀 제목은 대행사 템플릿으로 퍼져 있다. 네이버는 문장 일부만 바꾼 템플릿 대량 발행을 스팸으로 본다. 지역 키워드는 제목에 한 번만.

## 5) 사장님에게 받을 소재

처음 한 번:
- [ ] 자격증·등록증(전문분야 등록증 포함), 사무소 정식 명칭·주소·전화
- [ ] 사장님 사진(사무소, 상담 장면), 사무소 내부
- [ ] 이번 달 손님이 가장 많이 물은 질문 5개(신상은 빼고)
- [ ] 주로 맡는 업무 3개와 맡지 않는 업무
매주: 질문 1개에 대한 2분 음성 메모 → 그걸로 Q&A 글 1편. 법령·고시 링크가 있으면 함께.

## 6) 시즌·월별 기회

세무는 신고 일정이 곧 시즌이다. 날짜는 매년 국세청 공지로 다시 확인한다.

| 시기 | 기회 |
|---|---|
| 1월 | 부가가치세 확정신고(개인 일반과세자 2기), 연말정산 준비 |
| 3월 | 법인세 신고 |
| 5월 | 종합소득세 신고 — 개인사업자·프리랜서 질문이 몰림 |
| 7월 | 부가가치세 확정신고(1기) |
| 법·제도 개정 시행일 | 바뀐 점 해설(시행일·조문 링크 필수, 바뀌면 글 수정) |

법률·노무·행정은 고정 달력 근거가 없다. 법 개정 시행일과 상담 기록에서 반복되는 달을 쓴다.

## 7) 규제 플래그와 자주 걸리는 문장

직역별 조문(근거: 국가법령정보센터 law.go.kr 원문, 대한변호사협회 광고 규정. 자세한 검수는 `guides/compliance/legal-tax.md`):
- **변호사**: 변호사법 제23조 + 변협 광고 규칙·규정(승소율·결과 예측, 무료·염가 상담, 최고·유일, 미등록 '전문', 전관 강조, 범죄명 '○○변호사' 명칭, 광고가 아닌 척하는 광고 금지).
- **세무사**: 세무사법 **제12조의7**(2026-06-24 시행). 금지: 거짓 내용, 법적 근거 없는 자격·명칭, 과장·누락으로 오도, **업무 결과에 부당한 기대**, 다른 세무사 비방·비교, 품위 훼손(부정한 방법 제시 등), 대통령령으로 정하는 광고.
- **행정사**: 행정사법 제22조 5호(거짓·과장 광고).
- **노무사**: 공인노무사법 제27조②(노무사가 아닌 자가 노무 직무를 한다고 표시·광고 금지).
- **법무사**: 광고 조문 없음 → `common`. **회계사·변리사**: 확인 필요.

| 걸리는 문장 | 이유 | 고친 문장 |
|---|---|---|
| "음주운전 무혐의율 98%" | 승소율·결과 예측(변협 규칙 제4조④) | "음주운전 사건에서 확인하는 쟁점 3가지" |
| "세금 확실히 줄여 드립니다", "세무조사 무조건 막아드림" | 결과에 대한 부당한 기대(세무사법 제12조의7②4호) | "공제 항목을 빠짐없이 확인해 드려요" |
| "이혼전문변호사"(등록 없음) | 미등록 '전문' 표시 | "이혼 사건을 주로 맡고 있습니다" 또는 등록 후 표시 |
| "첫 상담 무료", "착수금 최저가" | 무료·염가 상담, 최저가 금지(변호사) | 상담 방법·절차만 안내 |
| "○○ 세무서 출신", "부장판사 출신" | 전관 강조 금지(변호사). 세무사는 연고 과시가 품위·오도 소지(확인 필요) | 경력은 사실만, 영향력 암시 없이 |
| "다른 사무소보다 수수료 절반" | 비교·비방(변호사법·세무사법 제12조의7②5호) | 우리 수수료 안내 방식만 |
| 의뢰인 사건을 알아볼 수 있게 쓴 사례 | 의뢰인 특정 금지(변협 규정 제4조 7호, 동의 시 예외) | 업종·금액·지역을 바꾸고 "가명·각색" 표시, 동의 받은 것만 |
| 대가를 준 후기 블로그 "덕분에 승소했어요" | 가장 광고, 결과 기대 | 쓰지 않는다 |

## 8) KPI

| 층 | 지표 | 확인 위치 |
|---|---|---|
| 결과(월) | 수임·기장 계약 건수, 상담→계약 비율 | 사무소 장부 |
| 행동(주) | 상담 신청(전화·톡·폼) 수와 경로, 블로그 유입 검색어 | 블로그 통계, 상담 기록 |
| 실행(주) | Q&A·칼럼 발행 수, 검수 통과율 | 직접 기록 |

- 상담마다 "어떤 글 보고 연락하셨어요?"를 기록한다. 많이 들어온 주제를 다음 달 주제로 키운다.

## 9) 하지 않을 것

- 결과·성공률·"확실히" 같은 표현.
- 대가를 준 후기, 사장님·직원이 손님인 척 쓰는 글.
- 법률 플랫폼 등 비변호사 연결 서비스 광고(변호사, 변협 규정 제5조②).
- 같은 틀 질문형 글 대량 발행, AI 요약 글 그대로 발행.
- 출처 없이 법 개정 내용 단정. 시행일·조문 링크를 붙이고, 바뀌면 고친다.
