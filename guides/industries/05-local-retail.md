# 05. 동네 생활·식품 소매

슈퍼, 편의점, 정육점, 과일·채소, 반찬가게, 수산, 건강식품점, 담배·전자담배, 무인점포(아이스크림·밀키트), 철물, 문구·서점. 독립서점처럼 인스타로 손님을 모으는 곳은 `06-specialty-store.md`가 더 가깝다.
기본 플래그: `common`, `food-origin`. 해당하면 `health-food`(건강식품점), `alcohol`(술 판매), `tobacco`(담배·편의점), `ecommerce`(택배·주문 판매). 문자·카톡을 보내면 `ad-messaging`.

**이 파일은 두 갈래다.** 먼저 묻는다: "단골에게 공동구매나 예약 판매를 하세요?"
- 예 → **공동구매형**(과일·반찬·수산 등)
- 아니요 → **매장형**(정육·슈퍼·철물·편의점 등)

## 1) 이 업종 손님이 우리를 찾는 상황 (JTBD)

| 상황 | 손님 속마음 | 손님이 확인하는 것 |
|---|---|---|
| 장보기 | "가깝고 싱싱하고 싼 곳" | 오늘 들어온 물건, 가격 |
| 제철 과일·특가 | "이번 주 좋은 게 뭐지" | 공동구매 공지, 수량, 픽업 시간 |
| 반찬·저녁거리 | "오늘 저녁 해결" | 오늘의 반찬, 마감 시간 |
| 명절·제사 준비 | "한 번에 미리 주문" | 예약 방법, 마감일 |
| 급한 물건 | "지금 문 연 곳" | 영업시간, 위치 |

## 2) 맨 앞에 할 일 (첫 단계)

1. 갈래를 정한다(위 질문).
2. **플레이스 정비**: 영업시간·휴무, 대표 상품 사진, 위치·주차. 매장형은 영수증 리뷰 요청 문구를 계산대에 둔다.
3. **연락처 동의 점검**: 단골 문자·단톡·카톡 채널을 쓰고 있으면 광고성 정보 수신 동의를 받았는지 확인한다(`ad-messaging`). 없으면 동의 문구부터 만든다.
4. **업태 확인**: 반찬·수제청을 직접 만들어 팔면 즉석판매제조가공업이라 식품 효능 예외가 없다. 담배를 팔면 담배 광고는 SNS에 올릴 수 없다.
5. 그다음 소식·콘텐츠.

## 4) 콘텐츠 기둥과 주력 유형

## 5) 사장님에게 받을 소재

- [ ] 매장 외관·진열대 전경
- [ ] 오늘 들어온 상품 사진(가격표가 보이게)
- [ ] 손질·포장 세로 영상 10초
- [ ] 공동구매: 품목, 수량, 가격, 주문 마감, 픽업 시간·장소
- [ ] 원산지 표시, 영업시간·휴무
- [ ] 수신 동의를 받은 연락처가 몇 명인지(명단 자체는 받지 않는다)

## 7) 규제 플래그와 자주 걸리는 문장

| 걸리는 문장 | 이유 | 고친 문장 |
|---|---|---|
| "당뇨에 좋은 여주 반찬" | 질병 효능(반찬가게는 예외 없음) | "여주를 살짝 데쳐 쌉쌀함을 줄였어요" |
| "도라지청, 기관지에 직빵" | 질병·신체기능 표현 | "국산 도라지로 직접 달인 청이에요" |
| "면역력 강화 생강청" | 기능성 오인 | "생강을 얇게 썰어 재웠어요" |
| "암 예방 프로폴리스"(건강식품점) | 건기식 인정 범위 밖, 자율심의 대상(`health-food`) | 심의받은 문구만 그대로 |
| "○○ 신제품 담배 들어왔어요" | 담배는 소매점 내부 광고만 허용(`tobacco`) | SNS·당근에 올리지 않기 |
| "맥주 4캔 사면 1캔 더" 게시물 | 주류 경품 표시(`alcohol`, 적용 여부 확인 필요) | 술 판촉 게시물은 확인 후 |
| 동의 없이 단골에게 "(광고)" 없는 특가 문자 | 정보통신망법 제50조 | 맨 앞 "(광고)", 전송자·연락처, 무료 수신거부, 10~20시 발송 |
| 원산지 없이 "한우 특가" | 원산지 표시 | "쇠고기: 국내산 한우" 표시 |

## 8) KPI

| 층 | 지표 |
|---|---|
| 결과(월) | 결제 건수·건당 금액, 공동구매 주문 수 |
| 행동(주) | 당근 단골 수·소식 반응, 카톡 채널 친구 수, 플레이스 새 리뷰 |
| 실행(주) | 소식 게시 수, 리뷰 답글률 |

## 9) 하지 않을 것

- 수신 동의 없는 단골 문자·카톡, 밤 9시~아침 8시 광고 발송.
- "혜택 알림 받기"라고만 쓰고 동의 받기(광고성 정보 수신 동의를 그대로 쓴다).
- 반찬·청·건강식품에 효능 단어 쓰기.
- 담배·전자담배를 SNS로 홍보하기.
- 매장형 가게에 당근부터 권하기(실측에서 단골 0).
- 카카오 유료 발송을 비용 계산 없이 권하기(친구 수 × 건당 단가를 먼저 보여 준다).
