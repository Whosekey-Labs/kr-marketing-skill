# 07. 온라인 판매·브랜드 상품

스마트스토어, 자사몰, 오픈마켓, 공방 제품, 수제 식품, 농수산 직판, 화장품·건기식 브랜드.
기본 플래그: `common`, **`ecommerce`**. 상품에 따라 `food-origin`(식품), `health-food`(건기식), `cosmetics`(화장품), `medical-device`(의료기기). 문자·카톡을 보내면 `ad-messaging`.

## 1) 이 업종 손님이 우리를 찾는 상황 (JTBD)

| 상황 | 손님 속마음 | 손님이 확인하는 것 |
|---|---|---|
| 필요한 물건 검색 | "이거 사도 후회 안 할까" | 상세페이지 첫 화면, 리뷰 수·내용, 가격·배송비 |
| 인스타·숏폼에서 우연히 | "예쁘다, 어디서 사지" | 프로필 링크, 가격 |
| 제철 농산물 | "산지에서 바로 싱싱하게" | 수확 소식, 발송일 |
| 선물 | "포장 되고 제때 오나" | 포장 사진, 도착일 |
| 재구매 | "그때 그 집" | 알림·소식, 단골 혜택 |

## 2) 맨 앞에 할 일 (첫 단계)

이 업종의 게이트는 **전환·추적**이다.

1. **권한**: 스토어 관리자·광고 계정을 사장님 계정으로 확인한다(비밀번호는 받지 않는다).
2. **추적 점검**: 유입 경로를 볼 수 있는지 확인한다(스토어 통계, 자사몰은 분석 도구 설치 여부).
3. **퍼널 이탈 지점**: 유입 → 상세 → 장바구니 → 결제 중 어디서 빠지는지 본다.
4. **손익분기 계산**: 마진으로 광고비 상한(손익분기 ROAS)을 계산한다.
5. **상세페이지 첫 화면·리뷰**: 리뷰가 적은 상태에서 광고를 크게 쓰면 손님이 상세에서 멈춘다(국내 실무 글).
6. **소액 테스트**: 리뷰 있는 상품 2~3개만 작게.
7. 법정 표시 점검: 사업자 정보·거래조건(제13조), 후기 운영 기준 공개(제21조의4).

## 3) 채널 등급 가설

| 등급 | 채널 | 할 일 | 근거 |
|---|---|---|---|
| 핵심 | 스토어 상세페이지·리뷰 | 첫 화면, 상품 사진, 리뷰 답글 | 가설 1순위, 쇼핑몰 실무 흐름 |
| 핵심 | 인스타·숏폼 | 상품 사용 장면, 포장·제작 과정 | 가설 2순위 |
| 확장 | 검색광고 | 손익분기 안에서 소액 | 가설 3순위, 실무 관행 |
| 확장 | 블로그 | 신상품, 사장 일기(농장), 가격 공지 | 온라인판매 블로그 검색 상위 사장님 글 38%(실측 2026-11, 네이버 블로그 검색 상위 10위) |
| 갈래 | 농수산 직판: 스마트스토어 + 밴드 + 카톡 | 수확 → 가격 공지 → 택배 시작 | 실측(2026-11, 농가 직판 사례) |

## 7) 규제 플래그와 자주 걸리는 문장

| 걸리는 문장 | 이유 | 고친 문장 |
|---|---|---|
| "가격은 DM 주세요" | 거래조건·신원 표시(제13조) | 가격·배송·청약철회 조건과 사업자 정보 |
| 첫 화면 "9,900원!" 후 결제 때 필수 포장비 | 쪼개기 가격, 다크패턴(제21조의2) | 필수 비용 포함 가격 표시 |
| 불리한 후기 숨기기, 직원 구매 후기 | 기만적 유인(제21조①1호) | 후기 운영 기준 공개(제21조의4) |
| "친환경 무농약 포도" | 인증 근거 필요(근거 없는 표시는 거짓·과장 광고, `common`) | 인증번호와 함께, 없으면 "농약을 줄여 키웠어요"도 사실일 때만 |
| "혈당 걱정 끝 수제청" | 수제 식품은 질병·기능성 표현 금지 | 재료·만드는 과정 문장 |
| "이 유산균 먹고 장이 편해졌어요" 릴스 | 건기식 미심의 + 체험기(`health-food`) | 심의받은 문구만 |
| "두피 재생 탈모 케어 샴푸" | 화장품 의약품 오인(`cosmetics`) | "두피를 산뜻하게 씻어 주는 샴푸" |
| 의료기기 효과 과장 | 의료기기법 제24조②(누구든지) | 허가받은 사용 목적 문구만 |
| 출석·경품 이벤트에 기간·당첨 조건 없음 | 거래조건 고지(판단) | 기간·대상·발표일 적기 |

## 8) KPI

| 층 | 지표 |
|---|---|
| 결과(월) | 매출, 주문 수, 객단가, 광고비 대비 매출(손익분기 ROAS와 비교) |
| 행동(주) | 상세페이지 유입, 장바구니·결제 전환율, 리뷰 수 |
| 실행(주) | 상품 등록·개선 수, 콘텐츠 게시 수, 문의 답변 시간 |

중단 기준(광고비 상한)은 시작 전에 정한다. 작은 규모의 좋은 숫자는 키우면 나빠진다고 가정한다.

## 9) 하지 않을 것

- 리뷰 20개도 없는 상태에서 큰 광고.
- 손익분기 계산 없이 광고비 늘리기, 여러 변수 동시에 바꾸기.
- 가짜 후기·AI 후기·직원 후기, 불리한 후기 삭제.
- 인증 없는 "친환경·무농약·천연" 표현, 효능 단어.
- 포장 영상에 손님 이름·주소·송장 노출.
- AI 모델 착용샷을 실제처럼 쓰기(가상인물 표시 없이).
