# 인스타그램 · 페이스북 페이지 · 스레드 연결 (Meta API)

## 0) 계정이 없으면 새로 열기 (있으면 건너뜀)
1. 만들기: 사장님 폰 인스타 앱에서 새 계정을 만들고(가게 전용 계정 권장) 바로 프로페셔널 계정(비즈니스)으로 바꾼다(화면 1). 로그인·인증은 사장님.
2. 프로필 채우기: 브랜드 프로필의 사실 자료로 가게 이름·대표 사진·소개 한 줄·주소·영업시간·연락처·링크를 넣는다. 없는 값은 지어내지 말고 사장님께 묻는다.
3. 첫 3개 게시물 계획: ① 가게 소개(누가·어디서·무엇을) ② 대표 상품·서비스 1개 ③ 가게 이야기 또는 오늘의 모습. 사장님 승인 뒤 하루 간격으로 올린다(하루 상한은 `guides/upload/index.md` 4-1).

## 요점
- 세 곳 모두 **무료 공식 API**가 있다. 사장님 본인 계정만 쓰면 앱 검수·비즈니스 인증이 필요 없다(Standard Access).
- **연결은 네가 브라우저로 대신 누른다. 사장님은 로그인·인증번호·"허용"만** 한다. 아래 화면 순서에서 **굵은 줄**만 사장님 일이다.
- **15분 규칙:** 연결을 시작한 시각을 적는다. 15분 안에 안 끝나거나, 같은 화면에서 두 번 막히면 멈추고 **B(비즈니스 스위트)** 로 간다. 연결은 다른 날 다시 해도 된다.
- 게시는 `tools/upload_api.py`. **`--live`가 없으면 시험 실행일 뿐 실제로 안 보낸다**(출력에 "DRY-RUN(실제로 안 보냄)"). 시험 결과를 성공으로 보고하지 않는다.
- 사장님께 오류를 받을 때는 늘 이렇게 말한다: **"오류 화면이 나오면 화면을 캡처해서 보내 주세요."** 주소 복사를 부탁하지 않는다.

## 먼저 알아 둘 것

| 항목 | 인스타그램 | 페이스북 페이지 | 스레드 |
|---|---|---|---|
| 계정 조건 | **프로페셔널 계정**. 개인 계정 불가 | 사장님이 관리자인 페이지 | 사장님을 앱의 **스레드 테스터**로 등록 |
| 릴스 mp4 | 연결 방식 A-1이면 **파일 그대로**(공개 주소 불필요). A-2면 공개 https 주소 | — | — |
| 사진 | **공개 https 주소** + **JPEG만**(두 방식 모두) | 파일 직접 업로드(공개 주소 불필요) | 공개 https 주소 |
| 캐러셀 | 최대 20장(비즈니스 스위트는 10장) → **10장 이하로 만든다** | — | 2~20장 |
| 예약 | API 예약 없음 → 비즈니스 스위트 | API 10분~30일 | **없음** → 승인 즉시 게시 |
| 하루 한도 | 문서에 100건·50건이 섞여 있음 → 50건 이하로 본다 | 릴스 24시간 30건 | 24시간 250건 |

## A. API 연결 (처음 한 번, 화면 순서대로)

**어느 방식?** 인스타가 페이스북 페이지에 연결돼 있거나 연결해도 되면 **A-1(권장)**. 페이지가 없고 만들기 싫으면 A-2.
- A-1(페이스북 로그인): 앱을 만든 사장님 페이스북 계정이 곧 앱 관리자라 **테스터 초대·수락이 없다.** 릴스를 **파일 그대로** 올릴 수 있다(Meta 원문: 이어 올리기는 "Only for apps that have implemented Facebook Login for Business").
- A-2(인스타그램 로그인): 페이지가 필요 없다. 대신 **인스타 테스터 초대 수락**이 있고, 릴스도 공개 주소가 필요하다.

### 화면 1 — 인스타 앱 (사장님 폰, 이미 돼 있으면 건너뜀)
- **사장님: 인스타 앱 → 프로필 → ☰ → 설정에서 "프로페셔널 계정으로 전환" → "비즈니스" 누르기.**
- A-1이면 같은 곳에서 페이스북 페이지 연결도 한다. 페이지가 없으면 네가 `facebook.com/pages/create`에서 가게 이름으로 만들고, **사장님은 페이스북 로그인만.**

### 화면 2 — 개발자 사이트 로그인 (네 브라우저)
1. 네가 `https://developers.facebook.com`을 연다.
2. **사장님: 페이스북 로그인.** 처음이면 개발자 등록이 나온다 → **사장님: 휴대폰으로 온 인증번호 입력.** 나머지 칸은 네가 채운다.

### 화면 3 — 앱 만들기 (네가 누름)
1. 앱 만들기 → 사용 사례에서 Instagram(콘텐츠 게시) 고르기 → 유형을 물으면 **Business**.
2. 앱 이름은 `가게이름-upload`. 연락 이메일은 사장님 이메일.
3. 메뉴 이름이 이 글과 다르면 그 화면을 캡처해 두고 가장 가까운 메뉴로 간다. 같은 화면에서 두 번 막히면 B로.

### 화면 4 — 열쇠(토큰) 받기
**A-1 (페이스북 로그인)**
1. 네가 `https://developers.facebook.com/tools/explorer`를 연다 → 방금 만든 앱 선택.
2. 권한 `instagram_basic`, `instagram_content_publish`, `pages_show_list`, `pages_read_engagement`를 넣고 토큰 만들기(Generate Access Token).
3. 창이 뜨면 → **사장님: "계속" → 가게 페이지와 인스타 계정에 체크 → "허용"(또는 "저장") 누르기.**
4. 네가 `https://developers.facebook.com/tools/debug/accesstoken`에 그 토큰을 넣고 장기 토큰으로 늘린다(Extend Access Token, 약 60일).
5. 탐색기에서 `me/accounts?fields=instagram_business_account`를 조회해 인스타 계정 ID를 받는다.
6. 금고에 `IG_ACCESS_TOKEN`, `IG_USER_ID`, `IG_HOST=graph.facebook.com`.

**A-2 (인스타그램 로그인)**
1. 앱 대시보드 → Instagram → Instagram 로그인 API 설정. 역할에 사장님 인스타 계정을 **Instagram 테스터**로 추가.
2. **사장님: 초대 "수락" 누르기.** 수락 위치는 공식 도움말로 확인하지 못했다(**확인 필요**). 흔히 알려진 곳: 인스타 앱 → 설정 → 웹사이트 권한 → 앱 및 웹사이트 → 테스터 초대. 컴퓨터면 instagram.com 로그인 → 설정의 같은 메뉴.
   > "인스타에 '테스터 초대'가 와 있을 거예요. 설정 → 웹사이트 권한 → 앱 및 웹사이트 → 테스터 초대에서 [수락]을 눌러 주세요. 메뉴가 안 보이면 그 화면을 캡처해서 보내 주세요."
3. 토큰 만들기(권한 `instagram_business_basic`, `instagram_business_content_publish`) → **사장님: 인스타 로그인 → "허용".**
4. 장기 토큰(60일)과 인스타 계정 ID를 금고에 `IG_ACCESS_TOKEN`, `IG_USER_ID`로.

### 화면 5 — 스레드 (같은 앱, 쓸 때만)
1. 같은 앱에 Threads 사용 사례 추가 → 사장님 스레드 계정을 **Threads 테스터**로 추가.
2. **사장님: 초대 "수락".** 스레드 쪽 메뉴 위치는 **확인 필요**. 못 찾으면 화면 캡처를 받아 찾는다.
3. 권한 `threads_basic`, `threads_content_publish`로 토큰 → 금고에 `THREADS_ACCESS_TOKEN`, `THREADS_USER_ID`.

### 화면 6 — 페이스북 페이지 (페이지가 있을 때만)
- 권한 `pages_manage_posts`, `pages_read_engagement`로 사용자 토큰 → 장기 페이지 토큰(만료 날짜 없음) → `FB_PAGE_TOKEN`, `FB_PAGE_ID`.

### 토큰 보관과 새로 고침
- 토큰은 **비밀번호와 같다.** 채팅·문서·브랜드 프로필에 쓰지 않는다. 네 금고에 두고 실행할 때 환경 변수로 넘긴다.
- 브랜드 프로필에는 **만료일만**(예: "인스타 연결 만료: 2027-01-15") 적고 7일 전에 새로 고친다.
  - A-2: `IG_ACCESS_TOKEN=… python3 upload_api.py ig-refresh --live` (**`--live`가 없으면 안 된다**).
  - A-1: `ig-refresh`는 인스타 로그인 토큰 전용이다. 화면 4(A-1)의 2~4를 다시 한다(사장님은 "허용"만).
- 사장님께: "인스타 연결은 두 달마다 새로 이어 줘야 해요. 날짜는 제가 챙길게요."

### 시험 게시 (꼭 한다)
1. 사장님 승인을 받고 1건만 올린다.
2. **로그아웃 상태(또는 다른 계정)로** 보이는지 확인한다. 개발 모드 게시물은 역할 사용자만 볼 수 있다는 일반 규칙이 있고, Business 유형 앱에 해당하는지는 원문으로 확정되지 않았다.
3. 안 보이면 시험 게시물을 지우고 B로 간다.

## 올릴 때

### 릴스 (공개 주소 없이)
- A-1: `IG_HOST=graph.facebook.com IG_ACCESS_TOKEN=… IG_USER_ID=… python3 upload_api.py instagram-reel --file reel.mp4 --caption "…"` → 시험 출력 확인 → 승인 뒤 `--live`.
  - 이어 올리기(`upload_type=resumable` → `rupload.facebook.com`으로 파일 전송)는 Meta 공식 콘텐츠 게시 문서의 방법이다. 파일을 어디에도 공개하지 않는다.
- A-2: 이어 올리기를 쓸 수 없다(원문상 페이스북 로그인 전용). `--video-url`에 공개 주소가 있으면 그것으로, 없으면 B로.

### 사진·캐러셀
- 공식 문서: 사진은 "게시 시점에 공개 서버에" 있어야 하고 JPEG만 된다. 사진에는 이어 올리기가 없다(동영상만).
- 공식적으로 가능한 방법은 하나다: **누구나 열 수 있는 https 파일 주소**에 JPEG를 둔다.
  1. 네가 쓸 수 있는 공개 파일 기능에 올린다. 클라우드 "공유 링크"처럼 미리보기 화면이 뜨는 주소는 안 된다. 주소를 열었을 때 **사진 파일 자체**가 나와야 한다.
  2. 로그아웃 브라우저에서 열어 사진이 바로 보이는지 확인한다.
  3. `instagram-image` / `instagram-carousel --image-url …`로 게시. 끝나면 공개 파일은 지운다.
- 이 수단이 없으면 **B로**. 페이스북 페이지는 `fb-photo --file`로 파일을 바로 올린다(공개 주소 불필요).

## B. 대체 경로: Meta 비즈니스 스위트 (사장님 로그인 브라우저에서 네가 올리기·예약)

언제: 15분 안에 API 연결이 안 끝났을 때, 막혔을 때, 사진을 둘 공개 주소가 없을 때, 시험 게시가 남에게 안 보일 때.
근거: Meta 약관에서 게시 자동화를 이름으로 금지하는 조항은 확인되지 않았다(인스타 약관은 자동화된 "계정 생성·정보 접근·수집"을 금지. `05b` M14). 그래도 `guides/upload/index.md` 4절처럼 사람 속도로 한다.

1. 네 브라우저로 `https://business.facebook.com`을 연다.
2. **사장님: 페이스북 로그인** (인증번호가 나오면 **사장님이 입력**). 캡차·"새 기기" 확인이 뜨면 즉시 멈추고 사장님께 넘긴다.
3. 게시물 만들기(릴스면 릴스 만들기)를 누른다.
4. 올릴 곳에서 인스타 계정(페이지가 있으면 페이지도)을 고른다.
5. 사진(인스타 **10장까지**) 또는 릴스 mp4를 첨부하고 순서를 확인한다.
6. 승인받은 문구를 입력한다(한 글자씩).
7. 예약을 고르고 날짜·시간을 정한다(페이스북 페이지 20분~29일. 인스타 예약 범위는 원문 없음).
8. 미리보기를 캡처해 사장님께 보낸다 → 승인 방식대로 [예약](또는 [게시])을 누른다.
9. 예약 목록 화면을 캡처해 보고한다. 사장님은 비즈니스 스위트 앱의 플래너에서 확인·취소할 수 있다.
10. 스레드: 예약이 없다. 비즈니스 스위트 **데스크톱**에서 인스타 글을 스레드에 교차 게시하거나, `https://www.threads.com`에서 승인 시점에 바로 올린다.

메뉴 이름은 원문으로 확인하지 못했다. 화면 이름이 다르면 캡처를 남기고 가장 가까운 메뉴로 진행한다.
