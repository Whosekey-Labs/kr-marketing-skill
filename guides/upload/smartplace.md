# 스마트플레이스 새소식 올리기

## 0) 계정이 없으면 새로 열기 (있으면 건너뜀)
1. 만들기: 사장님이 스마트플레이스(smartplace.naver.com)에서 업체 등록을 신청한다(사업자 정보·확인 서류는 사장님). 네가 화면 순서를 안내하고, 등록 승인 전에는 새소식을 올릴 수 없다.
2. 프로필 채우기: 브랜드 프로필의 사실 자료로 가게 이름·소개 한 줄·주소·영업시간·연락처·링크를 블록으로 만들어 주고, 사장님이 앱에서 붙여넣는다(대표 사진은 파일로). 없는 값은 지어내지 말고 사장님께 묻는다.
3. 첫 3개 게시물 계획: ① 가게 소개(누가·어디서·무엇을) ② 대표 상품·서비스 1개 ③ 가게 이야기 또는 오늘의 모습. 사장님 승인 뒤 하루 간격으로 올린다(하루 상한은 `guides/upload/index.md` 4-1).

- 공식 게시 API: **없음.**
- 경로: **붙여넣기 묶음 → 사장님이 폰 스마트플레이스 앱에서 등록. 이것 하나뿐이다.** 너는 스마트플레이스에 로그인·작성·등록하지 않는다(리뷰 답글도 초안만 준다). 이유와 사장님께 할 말은 `guides/upload/index.md` 1)·3).
- 소식·답글 자동화 제재 후기는 찾지 못했지만, 네이버 약관이 같다. 매크로로 가짜 후기를 쓴 대행 조직과 의뢰한 사장님이 송치된 일(2026-07)도 있고, 조작 리뷰가 1번이라도 확인되면 등록된 리뷰 전체가 안 보이게 된다(네이버 공식 방침). 리뷰를 사거나 대신 써 주는 제안은 받지 않는다.
- 내용 만드는 법은 `guides/make/local-posts.md`.
- 하루 1건까지(공통 수치는 `guides/upload/index.md` 4-1 표).

## 먼저 알아 둘 것

| 사실 | 그래서 |
|---|---|
| 새소식은 PC·모바일 모두 작성 가능 | 사장님 폰 앱으로 한다 |
| **예약 게시 기능이 원문에 없다** | 올릴 날 아침에 묶음을 보낸다 |
| **병원 업종은 새소식 기능이 없다** | 병의원이면 이 경로를 쓰지 않는다. 사장님께 그렇게 알린다 |
| 동영상도 첨부할 수 있다 | 숏폼 원본을 함께 올려도 된다 |
| 공지로 설정하면 최대 5개, 노출은 최대 45일 | 오래 걸어 둘 공지(휴무·이벤트)만 공지로 |

## B. 붙여넣기 묶음

1. 파일: `사진1_…jpg` 순서 이름(또는 짧은 영상). 공유 폴더로 보낸다(`guides/upload/index.md` 6)).
2. 블록: 0 순서표 / 1 본문(3~4줄 맨 텍스트) / 공지로 걸지 여부 한 줄.
3. 블록 0에 넣을 사장님 단계:
   1. 폴더 열기 → 사진 폰에 저장
   2. 스마트플레이스 앱 → 내 업체 → 새소식 → 쓰기
   3. 사진 번호 순서대로 선택
   4. 본문에 블록 1 붙여넣기
   5. (오래 걸어 둘 휴무·이벤트만) 공지 켜기 → 등록
4. 병원 업종은 새소식 기능이 없다. 그렇게 알리고 이 묶음을 만들지 않는다.
5. 메뉴가 안 보인다고 하면 화면 캡처를 받아 맞춘다.

## 아직 확인 안 된 것
- 앱 새소식 작성 화면에 예약 옵션이 있는지.
- 사진만 따로 올리는 메뉴 이름.
