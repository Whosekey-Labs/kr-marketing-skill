# 유튜브(쇼츠) 연결

## 0) 계정이 없으면 새로 열기 (있으면 건너뜀)
1. 만들기: 사장님 구글 계정으로 유튜브에 들어가 채널을 만든다(채널 이름은 가게 이름). 로그인은 사장님.
2. 프로필 채우기: 브랜드 프로필의 사실 자료로 가게 이름·대표 사진·소개 한 줄·주소·영업시간·연락처·링크를 넣는다. 없는 값은 지어내지 말고 사장님께 묻는다.
3. 첫 3개 게시물 계획: ① 가게 소개(누가·어디서·무엇을) ② 대표 상품·서비스 1개 ③ 가게 이야기 또는 오늘의 모습. 사장님 승인 뒤 하루 간격으로 올린다(하루 상한은 `guides/upload/index.md` 4-1).

- **무료 공식 API**(YouTube Data API v3). 요금이 없고 쿼터만 있다: 업로드(`videos.insert`) **하루 100회**, 태평양 시간 자정에 초기화. 사장님 1명이면 충분하다.
- 2026-11-02부터 검증 안 된 프로젝트로 올린 영상도 **비공개로 고정되지 않는다**. 그래도 이 스킬은 첫 업로드를 **비공개**로 올리고 사장님이 확인한 뒤 공개한다(아래 "첫 업로드").
- 유튜브 약관은 자동화 수단(봇 등)으로 서비스에 접근하는 것을 금지한다. 공식 API는 허용된 방법이므로 **스튜디오를 브라우저로 조작하는 것보다 API가 안전하다.**
- 연결은 **네가 브라우저로 대신 누른다. 사장님은 구글 로그인과 "허용"만** 한다. 아래에서 **굵은 줄**만 사장님 일이다. 처음 20~30분.
- **15분 규칙:** 시작 시각을 적고, 15분 안에 안 끝나거나 같은 화면에서 두 번 막히면 멈추고 B(유튜브 스튜디오)나 C(사장님 폰)로 간다.
- 사장님께 오류를 받을 때: **"오류 화면이 나오면 화면을 캡처해서 보내 주세요."** 주소 복사를 부탁하지 않는다.
- 업로드는 `tools/upload_api.py youtube`. **기본이 비공개(private)** 다.

## A. API 연결 (처음 한 번, 화면 순서대로)

### 화면 1 — 구글 클라우드 로그인 (네 브라우저)
1. 네가 `https://console.cloud.google.com`을 연다.
2. **사장님: 유튜브 채널이 있는 구글 계정으로 로그인** (휴대폰 확인이 뜨면 **사장님이 폰에서 "예"**).
3. 약관 동의 창이 뜨면 네가 국가(대한민국)를 고르고 동의를 누른다. 사장님께 한 줄로 알린다: "구글 개발자 도구 약관에 동의하고 진행할게요(무료예요)."

### 화면 2 — 프로젝트와 API (네가 누름)
1. 새 프로젝트: 이름 `가게이름-upload`.
2. API 라이브러리 → **YouTube Data API v3** → 사용 설정.

### 화면 3 — 동의 화면(Google 인증 플랫폼) (네가 누름)
1. 앱 이름(가게 이름), 사용자 지원 이메일·개발자 연락처(사장님 이메일), 대상 **외부**.
2. 데이터 액세스(범위)에 `youtube.upload` 추가. "민감한 범위" 표시가 나와도 그대로 진행.
3. **대상(Audience) 화면에서 게시 상태를 "In production(프로덕션)"으로 바꾼다** → [앱 게시] → 확인 창 [확인]. 이건 **네가 누른다**(사장님 일이 아니다).
   - "Testing(테스트)"으로 두면 로그인 정보(refresh token)가 **7일 뒤 만료**되어 매주 다시 해야 한다.
   - 검증 없이 프로덕션이면 신규 사용자 100명 상한이 생기지만 사장님 1명이라 상관없다. 검증(심사) 신청은 하지 않는다.
   - 메뉴 이름은 콘솔 개편으로 바뀔 수 있다. 다르면 화면을 캡처해 두고 "게시 상태(Publishing status)"를 찾는다.

### 화면 4 — OAuth 클라이언트 (네가 누름)
1. 클라이언트 → 만들기 → 애플리케이션 유형 **데스크톱 앱**.
2. 클라이언트 ID·비밀값을 바로 금고에 넣는다(`YT_CLIENT_ID`, `YT_CLIENT_SECRET`).

### 화면 5 — 사장님 허용 (`youtube-auth`)
1. 인증 주소를 만든다: `YT_CLIENT_ID=… python3 upload_api.py youtube-auth`.
2. **네 브라우저**(사장님이 화면 1에서 로그인한 그 브라우저)에서 연다. 사장님 폰·컴퓨터로 보내지 않는다.
3. 사장님께 먼저 말한다: "'확인되지 않은 앱'이라는 경고가 나올 거예요. 사장님 가게용으로 방금 만든 앱이라 그래요."
4. **사장님: 계정 고르기 → [고급] → "(앱 이름)(으)로 이동" → [계속]/[허용] 누르기.**
5. 허용 뒤 "사이트에 연결할 수 없음"이 뜨면 **정상**이다. 주소창이 `http://localhost/?code=…`로 바뀌어 있다. **이 주소는 네가 네 브라우저에서 직접 읽는다.** 사장님께 복사를 부탁하지 않는다.
6. 몇 분 안에 교환한다: `YT_CLIENT_ID=… YT_CLIENT_SECRET=… python3 upload_api.py youtube-auth --code 'http://localhost/?code=…'` → refresh token.
7. 실패하면(코드는 한 번만, 몇 분 안에만 유효) 1번부터 다시. 다른 오류 화면이면 캡처를 남기고 사장님께 "잠깐 확인할게요"라고만 말한다.
- 네 브라우저에 사장님이 로그인할 수 없을 때만: 주소를 사장님께 보내고 "허용까지 누른 뒤 나온 화면을 캡처해서 보내 주세요(주소창이 보이게)"라고 한다. 캡처에서 `code=` 글자가 잘려 안 보이면 이 방법은 쓰지 않고 B로 간다.

### 화면 6 — 보관
- `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN`은 네 금고에만. 채팅·문서·브랜드 프로필에 쓰지 않는다. 비밀번호는 받지 않는다(유튜브 개발자 정책).

## 첫 업로드: 반드시 비공개 → 사장님 확인 → 공개
1. 사장님 승인 뒤 60초 이하 세로 영상 1개를 **비공개**로 올린다(기본값):
   `YT_CLIENT_ID=… YT_CLIENT_SECRET=… YT_REFRESH_TOKEN=… python3 upload_api.py youtube --file short.mp4 --title "…" --live`
2. 사장님께: "유튜브에 비공개로 올려 뒀어요. 유튜브 앱 → 내 페이지 → 동영상에서 보시고 괜찮으면 '공개'로 바꿔 주세요. 이상하면 화면을 캡처해서 보내 주세요." (앱 메뉴 이름은 **확인 필요**. 못 찾으시면 캡처를 받아 그 화면 기준으로 다시 알려 준다.)
3. 사장님이 공개로 바꾼 뒤 쇼츠로 분류됐는지 본다(쇼츠: 최대 3분, 정사각형이나 세로. 길이 기준은 `guides/upload/index.md` 4-1).
4. 첫 영상이 확인된 뒤부터는 승인된 영상을 예약으로 올린다(아래). 바로 공개가 필요할 때만 `--privacy public`을 명시한다.

## 올릴 때마다
- 제목 100자 이내. 해시태그는 3개까지만 제목 옆에 보인다.
- 예약: `privacyStatus=private` + `publishAt`(한 번도 공개된 적 없는 영상만). 지난 시각을 넣으면 바로 공개된다. 최대 예약 기간은 원문에 없다.
  예: `python3 upload_api.py youtube --file short.mp4 --title "…" --privacy private --publish-at 2026-11-20T01:00:00Z --live` (시각은 세계 표준시, 한국 시각 −9시간)
- 쇼츠 맞춤 썸네일 업로드도 API로 된다(2026-11-03부터).
- 상업 음원은 넣지 않는다. 1분 넘는 쇼츠는 Content ID에 걸리면 전 세계 차단될 수 있다.

## 막히는 곳

| 상황 | 할 일 |
|---|---|
| 일주일 뒤 업로드가 인증 오류 | 동의 화면이 Testing인지 확인 → 화면 3에서 In production으로 바꾸고 화면 5(`youtube-auth`)를 다시 |
| 쿼터 초과 | 다음 날(태평양 시간 자정 뒤) 다시 |
| 올린 영상이 비공개 | 기본값이 비공개다(정상). 예약을 걸었으면 `publishAt` 시각을 확인한다 |
| `youtube.upload`가 민감 범위로 표시됨 | 그대로 진행(개인용은 경고 통과 가능) |
| 연결 실패·사장님이 원치 않음 | B로 |

## B. 대안: 유튜브 스튜디오 웹 (네 브라우저)
- 언제: 15분 안에 연결이 안 끝났거나 막혔을 때.
1. `https://studio.youtube.com` → 로그인은 사장님.
2. 오른쪽 위 **[만들기] → [동영상 업로드]** → 3분 이하 세로 mp4.
3. 세부정보 입력.
4. 공개 상태에서 **[예약]** → 날짜·시간·시간대 → **[예약]**.
5. 캡처로 보고. 약관상 자동화 위험이 있으므로 사장님께 한 줄로 알린다: "공식 연결이 안 돼서 유튜브 화면으로 직접 올릴게요. 유튜브 약관은 프로그램으로 대신 누르는 것을 금지하고 있어서, 원하시면 영상 파일을 보내 드리고 직접 올리셔도 돼요."

## C. 사장님이 폰에서 직접
1. mp4와 제목·설명을 사장님 폰으로 보낸다(`guides/upload/index.md` 6절 블록 방식).
2. 사장님: 유튜브 앱 → [+] → 동영상 고르기 → 제목·설명 붙여넣기 → 공개 범위 선택 → 업로드.
