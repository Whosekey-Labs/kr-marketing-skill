# 틱톡 올리기

## 0) 계정이 없으면 새로 열기 (있으면 건너뜀)
1. 만들기: 사장님 폰 틱톡 앱에서 계정을 만든다. 로그인·인증은 사장님.
2. 프로필 채우기: 브랜드 프로필의 사실 자료로 가게 이름·소개 한 줄·주소·영업시간·연락처·링크를 블록으로 만들어 주고, 사장님이 앱에서 붙여넣는다(대표 사진은 파일로). 없는 값은 지어내지 말고 사장님께 묻는다.
3. 첫 3개 게시물 계획: ① 가게 소개(누가·어디서·무엇을) ② 대표 상품·서비스 1개 ③ 가게 이야기 또는 오늘의 모습. 사장님 승인 뒤 하루 간격으로 올린다(하루 상한은 `guides/upload/index.md` 4-1).

- 공식 API는 있지만 **사장님이 쓸 수 있는 경로가 없다.** 심사 전 앱으로 올린 게시물은 비공개로 고정되고, 심사는 개인용 앱을 받지 않는다. 틱톡 지침이 바로 이 용도("내가 관리하는 계정에 올리는 도구")를 불가 예로 든다. 초안함 업로드도 같은 심사가 필요하다.
- 경로: **붙여넣기 묶음 → 사장님이 폰 틱톡 앱에서 게시.** 너는 틱톡(TikTok Studio 웹 포함)에 로그인·업로드·예약하지 않는다. 틱톡 약관은 "서비스와 상호작용하기 위하여 자동화된 스크립트를 이용하는 것"을, 커뮤니티 가이드라인은 자동화 도구를 금지한다. 비공식 자동 업로드에서 캡차 차단과 "자동으로 올린 영상만 조회수 0" 보고가 2024~2026년에 반복됐다. 사장님께 할 말은 `guides/upload/index.md` 3).
- 선택지: 사장님이 **틱톡 공식 API 심사를 받은 외부 예약 도구**를 이미 쓰고 있으면 거기서 예약해도 된다. 너는 그 도구에 넣을 영상·설명만 준다. 새 도구를 고르거나 추천하지 않는다(근거 자료에 확인한 도구 이름이 없다).
- 하루 1~2개(공통 수치는 `guides/upload/index.md` 4-1 표). 남의 영상을 재사용하지 않는다. 올릴 때 VPN을 끄고 가게 근처 휴대폰 네트워크로 올리라고 안내한다.

## 먼저 알아 둘 것

| 사실 | 그래서 |
|---|---|
| 영상 규격 | 1080×1920 원본 mp4, 90초 이하 |
| 다른 플랫폼 워터마크 영상은 불이익 | 원본 mp4만 |
| 사진 게시물 최대 35장 | 사진도 `사진1_…jpg` 순서 이름으로 보낸다 |
| 음원 | 틱톡 상업용 음원(CML)에서 사장님이 고른다 |

## B. 붙여넣기 묶음 (사장님 폰)

1. 파일: `영상1_…mp4` 하나. 공유 폴더로 보낸다(`guides/upload/index.md` 6)).
2. 블록: 0 순서표 / 1 설명(맨 텍스트) / 2 해시태그 5개 이하 한 줄.
3. 블록 0에 넣을 사장님 단계:
   1. 폴더 열기 → 영상 폰에 저장(와이파이 VPN은 끄기)
   2. 틱톡 앱 → + → 영상 선택
   3. 음악을 넣으려면 앱 안 상업용 음악에서 고르기(선택)
   4. 설명 칸에 블록 1, 이어서 블록 2 붙여넣기
   5. AI로 만든 장면이 있으면 AI 표시 켜기 → 게시
   6. 올라간 영상 주소 보내 주기
4. 캡차·보안 확인은 사장님 폰에서 뜨는 것이므로 사장님이 직접 푼다. 너는 우회 방법을 안내하지 않는다.
