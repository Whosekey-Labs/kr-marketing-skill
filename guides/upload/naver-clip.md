# 네이버 클립 올리기

## 0) 계정이 없으면 새로 열기 (있으면 건너뜀)
1. 만들기: 사장님 네이버 아이디로 클립 앱 또는 클립 크리에이터 PC 웹에 들어가 채널을 연다(메뉴 이름은 화면에서 확인). 로그인은 사장님.
2. 프로필 채우기: 브랜드 프로필의 사실 자료로 가게 이름·소개 한 줄·주소·영업시간·연락처·링크를 블록으로 만들어 주고, 사장님이 앱에서 붙여넣는다(대표 사진은 파일로). 없는 값은 지어내지 말고 사장님께 묻는다.
3. 첫 3개 게시물 계획: ① 가게 소개(누가·어디서·무엇을) ② 대표 상품·서비스 1개 ③ 가게 이야기 또는 오늘의 모습. 사장님 승인 뒤 하루 간격으로 올린다(하루 상한은 `guides/upload/index.md` 4-1).

- 공식 게시 API: **없음**(공개된 업로드 API 안내가 없다).
- 경로: **붙여넣기 묶음 → 사장님이 폰 클립 앱에서 등록. 이것 하나뿐이다.** 너는 클립 크리에이터 PC 웹에 로그인·업로드·예약하지 않는다. 이유와 사장님께 할 말은 `guides/upload/index.md` 1)·3).
- 클립 자동 업로드 제재 후기는 찾지 못했다. 그래도 네이버 약관과 게시물 운영정책이 같고, **클립은 경고 3회면 영구 정지**라 블로그와 같게 다룬다.
- 하루 1건까지(공통 수치는 `guides/upload/index.md` 4-1 표). 같은 영상 틀을 매번 반복하지 않는다.

## 먼저 알아 둘 것 (틀리기 쉬운 곳)

| 사실 | 그래서 |
|---|---|
| PC 웹에는 **편집 기능이 없다** | 자막·자르기·음악은 다 끝낸 mp4를 올린다 |
| **PC 웹 임시저장과 모바일 앱 임시저장은 연동되지 않는다** | PC에 초안을 올려 두고 사장님이 폰에서 마무리하는 흐름은 안 된다. PC 초안은 30일 보관 |
| 사진 여러 장짜리 클립 게시물(최대 20장)은 **모바일 앱에서만** 만든다 | 카드뉴스형 클립도 같은 묶음으로 된다 |
| AI로 만들거나 바꾼 콘텐츠는 **"AI 활용" 설정을 ON** 해야 한다 | 업로드 때마다 확인. 빠뜨리면 안 된다 |
| 다른 플랫폼 워터마크가 보이는 영상은 자체 제작으로 인정되지 않는다 | 틱톡·릴스에서 내려받은 파일 금지. 원본 mp4만 |
| 설명 최대 3,000자, 해시태그 최대 5개 | 해시태그 5개 이하 |
| 외부 링크는 안 되지만 **'콘텐츠 링크'로 네이버 블로그 글을 연결**할 수 있다 | 원본 블로그 글 주소를 블록으로 준다 |
| 음원은 클립 에디터 제공 음원만 권리 처리됨 | 상업 음원을 넣어 만들지 않는다 |

## B. 붙여넣기 묶음 (사장님 폰 클립 앱)

1. 파일: `영상1_밤크림브리오슈.mp4`(또는 사진 20장 이하, `사진1_…jpg` 순서 이름). 공유 폴더로 보낸다(`guides/upload/index.md` 6)).
2. 블록: 0 순서표 / 1 설명(맨 텍스트, 첫 줄에 지역·장소 키워드) / 2 해시태그 5개 이하 한 줄 / 3 연결할 블로그 글 주소(있으면).
3. 블록 0에 넣을 사장님 단계:
   1. 폴더 열기 → 영상(사진) 폰에 저장
   2. 클립 앱 → 만들기 → 영상(사진 번호 순서대로) 선택
   3. 설명 칸에 블록 1, 해시태그 칸에 블록 2 붙여넣기
   4. 콘텐츠 링크에 블록 3 붙여넣기(있으면)
   5. **AI 활용 켜기**(AI로 만들거나 바꾼 부분이 있으면) → 등록
   6. 올라간 클립 주소 보내 주기
4. 하루가 지나도 답이 없으면 한 번만 묻는다. 버튼 이름이 다르다고 하면 화면 캡처를 받아 맞춘다.

## 참고
- 손님이 자기 클립에 MY플레이스 리뷰를 연결하는 기능은 손님 쪽 기능이다. 사장님은 "손님 숏폼 리뷰 유도" 정도로만 쓴다.
