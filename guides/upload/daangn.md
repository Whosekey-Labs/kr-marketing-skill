# 당근 비즈프로필 올리기 (소식·스토리)

## 0) 계정이 없으면 새로 열기 (있으면 건너뜀)
1. 만들기: 사장님 당근 앱에서 비즈프로필을 만든다(메뉴 이름은 화면에서 확인). 본인인증·사업자 정보는 사장님.
2. 프로필 채우기: 브랜드 프로필의 사실 자료로 가게 이름·대표 사진·소개 한 줄·주소·영업시간·연락처·링크를 넣는다. 없는 값은 지어내지 말고 사장님께 묻는다.
3. 첫 3개 게시물 계획: ① 가게 소개(누가·어디서·무엇을) ② 대표 상품·서비스 1개 ③ 가게 이야기 또는 오늘의 모습. 사장님 승인 뒤 하루 간격으로 올린다(하루 상한은 `guides/upload/index.md` 4-1).

- 공식 게시 API: **없음.** 당근 공식 FAQ: "비즈프로필 소식을 올리는 API는 제공하지 않아요." 공개 API는 광고용(OpenAPI)뿐이다.
- 경로: 네 브라우저(PC 웹, 업무계정) 또는 붙여넣기 묶음(사장님 폰 당근 앱).
- 당근 약관의 자동화 조항은 확인하지 못했다. 그래도 하루 1건(`guides/upload/index.md` 4-1), 사람 속도로 한다.
- 소식 내용 만드는 법은 `guides/make/local-posts.md`. 소식은 무료로 동네에 노출된다.

## 먼저 알아 둘 것

| 사실 | 그래서 |
|---|---|
| **업무계정**(구글·네이버·카카오·이메일 로그인)은 PC에서 쓴다 | 사장님이 업무계정을 연결해 두면 휴대폰 번호 로그인 없이 브라우저로 작업할 수 있다 |
| 소식 에디터 두 종류: **[사진+글 혼합]**(사진 20장, 영상 1개·1분·200MB) / **[사진 모아보기]**(사진 10장) | 영상은 [사진+글 혼합]에서만 |
| **예약 게시 기능이 원문에 없다** | 승인받은 시각에 바로 게시 |
| **당근 스토리**: 5~60초 영상, 설명 1,000자, 가까운 이웃에게 먼저 노출 | 숏폼을 60초 이하로 자른 버전을 올릴 수 있다. PC 업로드 가능 여부는 미확인 → 폰 묶음 |
| 운영자 초대: 운영자는 소식 작성·수정 가능 | 사장님 계정 대신 운영자 계정을 쓰는 방법도 있다(아래) |
| 당근 광고 MCP(조회만) | 광고 성과를 볼 때만 쓴다. 게시는 안 된다 |

## A. 브라우저로 올리기 (소식)

### 처음 한 번
1. 사장님께: "당근 비즈프로필에 구글·네이버·카카오 같은 업무계정을 연결해 두시면 제가 PC에서 소식을 올릴 수 있어요."
2. 네 브라우저로 당근 비즈프로필 PC 웹을 연다(주소는 사장님 비즈프로필 앱의 PC 안내나 검색으로 확인). 로그인은 사장님.
3. (선택) 운영자 초대: **[비즈프로필] → [설정] → [운영자 관리] → [운영자 추가+]**.

### 올릴 때마다
1. 비즈프로필 홈 → **[소식]**.
2. 새 소식을 연다(PC의 새 소식 버튼 이름은 원문 미확인 — 화면에서 찾는다).
3. 에디터를 고른다: 영상이 있으면 **[사진+글 혼합]**, 사진만이면 둘 중 하나. PC에서 바꾸려면 소식 상단 **[에디터 변경]**.
4. 사진·영상 첨부, 본문을 한 글자씩 입력.
5. 미리보기 캡처를 사장님께 보낸다.
6. 승인 방식대로 게시한다.
7. 캡처로 보고한다.
- 고칠 때: **[비즈프로필] → 소식 목록에서 선택 → 우측 [⋮] → [수정]**.

### 막히는 곳

| 상황 | 할 일 |
|---|---|
| 휴대폰 번호로만 로그인되는 계정 | 업무계정 연결을 부탁하거나 B로 |
| 인증·보안 확인 | 멈추고 사장님께 넘긴다 |
| 영상이 1분 넘음 | 1분 이하로 잘라 다시 만든다 |

## B. 붙여넣기 묶음 (소식·스토리)
1. 묶음: 사진 번호 순서(또는 60초 이하 mp4), 본문(맨 텍스트), 에디터 종류.
2. 사장님 폰으로 보낸다.
3. 안내: "당근 앱 → 비즈프로필 홈 → [소식](스토리는 [스토리])에서 사진을 고르고 본문을 붙여넣은 뒤 올려 주세요."
