# 카카오톡 채널 올리기 (소식·메시지)

## 0) 계정이 없으면 새로 열기 (있으면 건너뜀)
1. 만들기: 사장님 카카오 계정으로 카카오톡 채널 관리자센터(center-pf.kakao.com)에서 채널을 연다. 로그인·인증은 사장님. 채널 이름은 가게 이름으로.
2. 프로필 채우기: 브랜드 프로필의 사실 자료로 가게 이름·대표 사진·소개 한 줄·주소·영업시간·연락처·링크를 넣는다. 없는 값은 지어내지 말고 사장님께 묻는다.
3. 첫 3개 게시물 계획: ① 가게 소개(누가·어디서·무엇을) ② 대표 상품·서비스 1개 ③ 가게 이야기 또는 오늘의 모습. 사장님 승인 뒤 하루 간격으로 올린다(하루 상한은 `guides/upload/index.md` 4-1).

- 공식 API: 소식·메시지 **발송 API 없음.** 카카오 개발자 채널 API는 채널 추가·1:1 채팅·고객파일·관계 관리만 한다.
- 경로: **소식**은 네 브라우저(관리자센터)로 **예약 발행**까지. **메시지**는 유료라 너는 초안만, 발송은 사장님.
- 카카오 운영정책에는 게시 자동화를 이름으로 금지하는 조항이 없다. 다만 "동일한 내용을 … 여러 개별 서비스에 반복적으로 등록하는 행위"는 금지다 → 같은 글을 여러 번 올리지 않는다.
- 소식·메시지 내용은 `guides/make/local-posts.md`.

## 소식과 메시지의 차이

| | 소식 | 메시지 |
|---|---|---|
| 어디에 | 채널 홈(친구가 들어와서 봄) | 친구의 카톡 대화방으로 감 |
| 돈 | 유료 문구 없음 | **유료.** 건당 일반 15원·타겟 20원(VAT 별도) |
| 예약 | 예약 발행 | 예약 발송 |
| 너의 역할 | 작성 → 예약까지 | **초안만.** 발송·예약은 사장님 |
| 법 | — | 광고성이면 정보통신망법 제50조(사전 동의, "(광고)" 표시 등) |

## A. 소식 올리기 (브라우저)

### 처음 한 번
1. 네 브라우저로 카카오톡 채널 관리자센터를 연다(검색어 "카카오톡 채널 관리자센터", 카카오비즈니스 공식 사이트 주소인지 확인).
2. 카카오 계정 로그인은 사장님이 직접 한다(2단계 인증은 폰에서 승인).
3. 채널이 여러 개면 어느 채널인지 확인한다.

### 올릴 때마다
1. 관리자센터 **[소식]**에서 새 소식을 작성한다.
2. 사진 첨부, 본문을 한 글자씩 입력한다.
3. **예약 발행을 켜고** 날짜와 시간을 고른다(최대 기간은 원문 없음).
4. 미리보기 캡처를 사장님께 보낸다.
5. 승인 방식대로 저장한다.
6. 목록의 **[예약]** 탭에서 걸렸는지 확인한다([발행]·[예약]·[임시저장] 탭이 있다).
7. 캡처로 보고한다.

### 막히는 곳

| 상황 | 할 일 |
|---|---|
| 카카오 로그인 인증 | 멈추고 사장님께 넘긴다 |
| 예약 시각을 바꾸고 싶다 | [예약] 탭에서 그 소식을 열어 고친다 |

## B. 메시지 (초안만)

1. 메시지 초안을 만든다(`guides/make/local-posts.md`의 재방문 메시지 점검 4가지를 통과해야 한다).
2. 비용을 먼저 보여 준다: "친구 [직접 입력: 친구 수]명 × 15원 = 약 ○원(VAT 별도)이에요."
3. 사장님께: "관리자센터 [메시지 보내기]에서 이 초안을 붙여넣고, 바로 보내거나 예약해 주세요. 돈이 드는 일이라 제가 누르지 않을게요."
4. 발송 횟수는 월 1~2회를 권한다.
5. 참고: 연 매출 10억 원 이하 사업자는 사업자번호당 30만 원 상당 메시지 비용을 한 번 지원받을 수 있다(무상캐시, 유효 1년). 조건은 카카오비즈니스 안내에서 사장님이 확인한다.

## C. 사장님 폰
- 관리자 앱에서 소식을 직접 올리거나, 네가 걸어 둔 예약을 확인·취소할 수 있다.
