# 3. 전략: 목표 → 진단 → 플레이스 먼저 → 포지셔닝 → 브랜드 성격 → 채널 등급 → 첫 4주

목표: 1·2단계 결과로 이번 달 계획을 세우고 브랜드 프로필 문서에 저장한다. 캘린더를 만드는 게 전략이 아니다. **어디가 막혔는지 고르고, 할 것과 안 할 것을 정하는 것**이 전략이다.
이 단계까지가 **준비(첫 주 1회)**다. 이후는 생산 루프(매주 `guides/04-weekly.md`), 운영 루프(상시 `guides/08-operations.md`), 측정(월 1회 `guides/05-monthly.md`)으로 돈다.

## 1) 목표: 사업 숫자로 거꾸로 세우기

1. 매출을 세 칸으로 나눈다: **손님 수 × 방문 횟수 × 객단가**. 약한 칸은 2단계 답으로 고른다: **3)목표 답이 있으면 그것을 우선** → 없으면 1)이 '거의 처음'이면 재방문이 약함, '거의 단골'이면 신규가 약함, '반반·모름'이면 신규 → 3)이 ④ 빈 시간이면 그 시간대.
   - 매장 없는 사업(B2B·SaaS·온라인·1인 브랜드, 업종 파일 07·23·24·25)은 **노출 × 신청 비율 × 계약 비율 × 계약 금액**으로 나누고, 2단계 대체 답(문의 경로·지난 4주 상담 문의 수·한 건 금액·결정자)으로 약한 칸을 고른다.

| 약한 칸 | 신호 | 맞는 목표 예 |
|---|---|---|
| 손님 수(신규) | 처음 오는 손님이 적다, 검색에 안 뜬다 | 플레이스 유입·길찾기 늘리기 |
| 방문 횟수(재방문) | 단골이 적다, 한 번 오고 안 온다 | 알림받기 고객·쿠폰 회수 늘리기 |
| 객단가 | 손님은 있는데 한 번에 적게 쓴다 | 세트·추가 메뉴 비중 늘리기 |
| 빈 시간 | 특정 시간대만 비어 있다 | **그 시간에 오면 좋은 이유**(갓 나온 시간·그 시간 한정 구성)로 그 시간대 건수 늘리기 |

**1-1) 손님이 지금 올 이유 (목표마다 1개, 콘텐츠보다 먼저)**
목표를 정하면 바로 "손님이 왜 **지금** 와야 하나"를 1개 고른다. 종류: 새로움(신메뉴·새 서비스) / 한정(수량·기간·요일) / 시즌(D-14~21 행사·날씨) / 문제 해결(손님이 겪는 불편을 푸는 것) / 이벤트(사장님이 정한 혜택) / 사람 이야기(만드는 사람·오늘 있었던 일). **사실 근거가 있는 것만** 고르고 사장님께 사실 1개로 확인한다("오후 3시에 두 번째로 구우세요?").
- '지금 올 이유'는 **목표 행동(방문·예약·문의)의 이유**다. 매장 없는 업종은 "지금 **문의할** 이유"로 읽는다. 콘텐츠를 '볼' 이유(새 소식)만 있고 목표 행동의 이유가 없으면 통과가 아니다.
- 이유가 사실로 없으면 콘텐츠보다 **이유 만들기 제안**을 먼저 보낸다. 사장님이 이번 주 바로 할 수 있는 작은 것 1개: 작은 오퍼(오후 한정 2개 구성), 한정(하루 20개), 시간 소식(갓 나온 시간 알림). 혜택·할인은 사장님이 정하고 조건을 지킨다(`guides/08-operations.md` 3)).
- "남는다·재고가 많다·안 팔린다"는 손님 글에 쓰지 않는다. 빈 시간은 "비어서"가 아니라 "그때 오면 좋은 이유"로 쓴다.

| 카드 유형 | 이유 예 (사실 확인 뒤) |
|---|---|
| 동네형 (빵집·식당) | "오후 3시, 깜파뉴 두 번째로 나와요" — 갓 나온 시간 |
| 목적지형 (디저트·공방) | "겨울 타르트 12/1 출시, 하루 30개" — 새로움 + 한정 |
| 전문형 (세무·병의원·학원) | "5월 종합소득세, 놓치기 쉬운 공제 3가지" — 시즌 + 문제 해결 |
| B2B형 (외주·SaaS) | "리뷰 답글, 사장님 확인 뒤에만 올라가요" — 손님이 걱정하는 문제 해결 / "이번 달 공개한 무료 지침, 세팅이 어려우면 무료 진단 15분" — 새로움 + 지금 문의할 이유(진단 시간은 사장님이 정한 것만) |

2. **이번 달 목표는 1~2개.** 각 목표에 기준값(지금)·목표값·날짜를 붙인다(예: "평일 점심 길찾기 수, 지금 주 [직접 입력] → 4주 뒤 [목표]"). "블로그 10개" 같은 작업량은 목표가 아니다.
3. **숫자가 없으면 막지 않는다.** 첫 달 목표를 "기준값 만들기"로 둔다: 지난 4주 포스 건수·객단가(없으면 추정 범위), 플레이스 통계 캡처, 첫 방문 손님 "어떻게 알고 오셨어요?" 기록, 경쟁 3곳 리뷰·사진 수.
4. 기준값이 없을 때는 **되돌릴 수 있는 일부터** 한다(플레이스 정비, 사진 교체). 가격 인하·상호 변경·큰 광고비는 기준값이 생긴 뒤로 미룬다.

## 2) 진단 점수표 (항목당 0~2점)

1단계 조사 결과로 채운다. 0 = 없음·틀림, 1 = 있지만 부족, 2 = 잘됨.
| 영역 | 항목 |
|---|---|
| 플레이스 | 기본 정보 정확 / 대표 사진(첫 장이 대표 메뉴·결과물) / 메뉴·가격 / 소개글 / 예약·쿠폰·알림받기 / 부가정보 |
| 리뷰 | 리뷰 수(경쟁 대비) / 최근 30일 리뷰 / 답글률 / 별점 공개·평균 |
| 검색 | `지역+업종`, `지역+상황`, `지역+대표 메뉴` 검색어 노출 |
| 콘텐츠 | 채널별 최근 30일 게시 / 쓸 수 있는 사진·영상 재고 |
| 본질 | 리뷰 속 반복 불만(맛·응대·위생·가격) — 있으면 0점, 콘텐츠보다 먼저 알린다 |

## 3) 플레이스 먼저 고치기 (첫 성과 — 인터뷰 전에 보낸다)

로컬 가게는 콘텐츠보다 플레이스·리뷰 정비가 먼저다. **1단계 확인 메시지에 사장님이 답하면 바로**(2단계 질문보다 먼저) 이 3가지를 보낸다. 플레이스 정비에는 숫자 답이 필요 없다.

1. 점수표의 플레이스 항목 중 0점을 고른다. 순서: 틀린 정보 → 대표 사진·메뉴 가격 → 소개글 → 알림받기·쿠폰 → 부가정보.
2. 고칠 문구·사진 순서를 만들어 준다. 저장은 사장님이 하거나, 연결돼 있으면 `guides/upload/smartplace.md`대로. 업종 게이트(병의원 광고 심의, 학원 교습비 표시)가 있으면 먼저.
3. 가게를 못 찾았으면 1번은 확인 메시지 답대로(`guides/01-research.md` 1)): 등록 안 함 → "플레이스 등록" / 등록됐는데 위치 확인 못 함 → "스마트플레이스에서 등록된 이름·주소 확인" / 모름 → "등록 여부 확인"(확인 전 새 등록 금지). 오픈 준비(④)는 3번에 "가격표 확정"을 넣는다(업종이 요금·환불 표시를 요구하면 그 기준까지). 조사에서 못 본 사실(메뉴 이름 등)로 문구를 만들지 않는다.
4. **매장 없는 사업**은 플레이스 대신 **홈페이지·문의 경로·플랫폼(크몽 등) 상품 페이지에서 고칠 3가지**를 보낸다. 순서: 문의 방법이 안 보임 → 첫 화면에 '누구의 무슨 문제를 푸는지' 없음 → 가격·사례 없음.

```
이번 주에 먼저 고칠 3가지예요. (5분이면 돼요)
1. 메뉴 가격 넣기 — 아래 표 그대로 붙여 넣으시면 돼요
2. 대표 사진 첫 장을 크루아상 단면 사진으로 바꾸기
3. 알림받기 켜기 — 단골에게 소식을 보낼 수 있어요
이걸 하시는 동안 몇 가지만 여쭤볼게요.
```

## 4) 포지셔닝 한 문장 + 증거 3개

공식: **"[누구]가 [어떤 상황]일 때 찾는, [대안]과 달리 [증거 있는 차별점]인 [업종]"**
- 재료: 단골이 하는 소개(2단계), 손님 말 상위 10개(1단계 5), 경쟁이 비워 둔 자리(1단계 4의 '최근 30일 주제 / 안 다루는 주제'). 목적지형이면 '목적지 경쟁'(다른 상권 같은 카테고리)과도 비교한다.
- 증거 3개: ① 사진으로 보여 줄 수 있는 것 ② 숫자로 말할 수 있는 것 ③ 손님 말(리뷰)로 인용할 수 있는 것. 증거가 없는 차별점은 쓰지 않는다.

## 4-1) 브랜드 성격 카드 (말투·디자인·채널·성과 숫자의 출발점)

다섯 칸을 정한다. 조사·리뷰로 채우고, ⑤는 2단계 6) 답을 쓴다(6)을 갈래 질문으로 바꿨으면 시안 고를 때 받은 답, 없으면 비워 둔다).
① 상권: 동네형(근처 사람이 자주) / 목적지형(일부러 찾아옴) / 혼합 · ② 가격 위치: 저가 / 중간 / 프리미엄 · ③ 손님 관계: 자주 오는 단골 / 가끔 오는 경험
④ 분위기 형용사 3개: 사장님 말 + 리뷰 말에서 (예: 따뜻한·소박한·정직한) · ⑤ 닮고 싶은 곳 2곳 / 닮기 싫은 곳 1곳 (업종 무관)

이 카드로 문체 V·카드 스타일 S·숏폼 느낌·사진 톤·제목 공식·색·채널·성과 숫자를 정한다. **표는 `guides/03-strategy-brand.md`**(동네형/목적지형/전문형/B2B형 기본값, 형용사별로 바뀌는 칸, 같은 업종 두 가게 예). **업종 파일 기본값보다 이 카드가 우선한다.**

- **갈림 점검(첫 제작 전):** `guides/03-strategy-brand.md`를 열고 프로필에 화자·제목 공식·카드뉴스 스타일·숏폼 느낌·사진 톤·색 방향·제목 글씨를 적는다. **형용사 3개마다 "형용사 → 바뀐 칸" 한 줄**을 함께 적는다(예: "정직한 → 가격·수량 숫자 그대로, 꾸밈 단어 0개"). 바꾼 칸이 없는 형용사가 있거나 업종 기본값과 같은 칸이 3개 이상이면 성격 카드를 다시 보고 고친다. 근거는 성격 카드 칸이다(사장님 말·리뷰). 근거 없이 "개성"을 지어내지 않는다.
- ⑤ '닮고 싶은 곳'은 색·글씨체와 레퍼런스 첫 후보로, '닮기 싫은 곳'은 프로필 '금지 표현' 칸에 피할 스타일로 적는다. 비어 있으면 성격 카드 열의 기본값을 쓴다.
- 이 카드는 레퍼런스를 빌릴 때 "우리와 맞나"를 거르는 기준이다(`guides/06-reference.md`).

## 5) 채널 등급 (핵심 / 확장 / 제외)

1. 업종 파일의 채널 순서를 **가설**로 가져오고, 브랜드 성격 카드의 채널로 고친다.
2. 경쟁 3~5곳의 실측(1단계 4)으로 덮어쓴다.
3. 아래 표로 등급을 매긴다. 처음에는 **핵심 1~2개**로 시작하고, 되는 게 확인되면 넓힌다.

| 판단 | 핵심 | 확장 | 제외 |
|---|---|---|---|
| 경쟁 상위 3곳 중 그 채널을 활발히 쓰는 곳 | 2곳 이상 | 1곳 | 0곳 |
| 우리 손님이 그 채널에서 찾나 (업종 파일·리뷰 근거) | 예 | 일부 | 아니오 |
| 사장님 소재로 꾸준히 채울 수 있나 (2단계 답) | 예 | 바꿔서 가능 | 아니오 |
| 하는 일 | 원본을 공들여 만든다 | 원본을 플랫폼에 맞게 바꿔 올린다 | 이유를 한 줄로 말한다 |

- 세 줄의 답이 엇갈리면 **가장 낮은 등급**으로 한다(예: 핵심·핵심·제외 → 제외). 사장님께 말할 때는 핵심/확장/제외를 **힘줄 곳 / 곁들일 곳 / 안 할 곳**으로 말한다.
- 손님 후기가 검색 상위를 차지하는 업종(음식점·베이커리·숙박·반려동물)은 블로그를 "사장님 글"이 아니라 **"손님 후기 유도"** 채널로 본다(방법: `guides/08-operations.md` 6)). 사장님 블로그를 쓰더라도 처음에 솔직히 말한다: 큰 '지역+업종' 검색어 상위는 손님 후기·체험단 글이 대부분이라(2026-11 실측 8개 검색어 1·2위에 사장님 글 0편), 사장님 블로그는 메뉴명·상황·질문 같은 세부 검색어와 지도(플레이스) 연결을 노린다.
- 단, 플레이스는 방문형 가게면 등급과 상관없이 항상 관리한다.

## 5-1) 광고 (선택, 소액)

- 예산은 첫 월간 회고(`guides/05-monthly.md`) 때 묻는다. 그때까지는 없음으로 본다. **없으면** 프로필에 "광고 없이 4주 기준값부터"라고 적고 넘어간다.
- 있으면: 리뷰와 게시물 반응이 어느 정도 쌓인 뒤, **이미 반응이 좋았던 게시물 1개만** 작게 홍보한다. 새 소재로 광고하지 않는다.
- 동네형은 반경 지역 광고(당근 지역 광고·네이버 플레이스 광고), 목적지형은 인스타 게시물 홍보(관심사).
  시작 전에 기간과 1명당 비용 상한을 정한다. 판정은 `guides/05-monthly.md` 2)의 광고 규칙. 병의원은 의료 검수표를 먼저 본다.

## 6) 콘텐츠 기둥 3~4개

손님이 우리를 찾는 상황(누구와, 언제, 왜)에서 고른다. 비율 기본값(근거 약함, 바꿔도 됨): 정보·발견 40 / 신뢰·증거 30 / 사람·이야기 20 / 혜택 10. 예(카페): ① 시그니처 메뉴 이야기 ② 상황 제안(비 오는 날, 혼자 작업) ③ 만드는 과정·재료 ④ 손님 반응·소식. 목적지형이면 ① 시즌 한정 ② 오늘 웨이팅·품절 ③ 공간·디테일 ④ 만드는 사람.

## 7) 첫 4주 계획

- **사장님 시간은 주 1~2시간, 촬영은 주 1회 10~30분**을 넘지 않게 짠다. 캘린더는 **80%만** 채운다.
- **첫 게시는 1~2주 안에** 한다. 주마다 **빠뜨려도 되는 최소 버전**을 붙인다(예: "바쁘면 플레이스 소식 1개만").

| 주 | 준비·운영 | 생산(핵심 채널) |
|---|---|---|
| 1 | 플레이스 3가지 정비, 리뷰 답글 기준, 연간 달력 초안 | 첫 소재 1개 → 원본 1~3종 |
| 2 | 리뷰 답글 시작, 알림받기·쿠폰, 매장 안 후기 장치(08 6)) | 소재 1개 → 원본 3종 + 확장 버전 |
| 3 | 시즌 D-14~21 예열 확인 | 소재 1개 |
| 4 | 월 캡처 받기 → `guides/05-monthly.md` | 소재 1개, 다음 4주 제안 |

## 8) 성과 숫자 3단

- **결과**(월 1회): 신규 손님 수·예약·문의·매출(사장님이 알려 준 범위만)
- **행동**(월 1회 캡처): 플레이스 유입·길찾기·전화·저장·예약, 블로그 검색 유입, 인스타 저장·공유. 게시물 반응은 2~3일 뒤(`guides/04-weekly.md` ⑩)
- **실행**(매주, 에이전트가 기록): 게시 수, 리뷰 답글률, 새 리뷰 수
- 우선할 숫자는 브랜드 성격 카드의 '성과 숫자' 칸. 매주는 사장님께 **"이번 주 손님 반응 한 줄"**만 받는다.

## 9) 실험 1개 설계 (판정은 월간 회고에서)

**기준값이 없으면 실험은 2달째에 시작한다.** 첫 달은 4번(출처 추적)만 켜고 기준값을 쌓는다(①·④ 갈래는 거의 이 경우다).
1. 가장 약한 숫자 하나와 **바꿀 것 한 가지**를 고른다. 한 번에 하나만.
2. 기간을 시작 전에 정하고 중간에 끝내지 않는다. 기본 **전 4주 vs 후 4주**, 최소 2주 vs 2주, 월~일 꽉 찬 주 단위.
3. 기준선 두 개: 직전 4주 평균 + 요일 맞춘 지난해 같은 주(있으면). 공휴일·날씨·동네 행사·배달앱 할인 주는 표시한다.
4. 출처 추적을 처음부터 켠다: 채널별 쿠폰 코드, 첫 방문 손님 "어떻게 알고 오셨어요?" 날짜별 체크, 쿠폰 회수율·메뉴별 판매 비중, 길찾기·전화 수.
5. 작은 문구 수정은 실험하지 않는다. 큰 변화만. 판정 문턱은 `guides/05-monthly.md` 2).

## 10) 하지 않을 것 (프로필에 적는다)

- 리워드 트래픽, 좋아요·팔로워 구매, 리뷰 대행·리워드 앱, 지인 리뷰로 덮기
- 대가를 주는 리뷰 이벤트를 먼저 제안하기(사장님이 원할 때만 `guides/08-operations.md` 1)의 조건과 함께. 병의원은 체험·이벤트 후기가 치료경험담이라 하지 않는다 — `guides/compliance/medical.md`)
- 처음부터 비싼 `지역+맛집` 노리기, 운영 못 하는 기능 켜 두기(답 못 하는 톡톡), 목적 없는 전체 할인
- 채널을 한꺼번에 여러 개 벌이기, "상위노출 보장"·"한 달 안에 두 배" 약속
