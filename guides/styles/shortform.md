# 숏폼 고르기: 갤러리 9장 · 편집 느낌 3개 (내부 유형 F01~F14 · 재료 분류 P1~P7)

사장님·가게 공식 계정의 쇼츠 188편 + 릴스 15편(16개 업종)과 네이버 클립 84편(10개 업종)을 직접 보고 나눈 것이다(2026-11 수집·재분류). 사장님께는 **2절 갤러리 9장과 5절 편집 느낌 3개만** 보여 준다. F 코드와 P 코드는 에이전트 내부용이다.

## 1) 내부 유형 14개 (사장님께 코드를 말하지 않는다)

- **조립**: 사장님 사진·짧은 클립에 자막만 얹어 만들 수 있는 정도. 쉬움 = 사진·클립 몇 개 / 보통 = 과정·하루를 직접 찍어야 함 / 어려움 = 얼굴 출연·연기 필요.
- **성과 신호**: 같은 채널 안에서 비교한 방향만 적는다. 표본이 채널 상위 영상에 치우쳐 있어서 **"몇 배" 같은 숫자는 쓰지 않는다**(사장님께도 말하지 않는다).

## 3) 고르는 순서: 목적 → 가진 재료 → 카드

1. 목적을 묻는다: "이번 영상으로 뭘 알리고 싶으세요? ① 새 소식 ② 가게 자랑 ③ 믿음 주기 ④ 재미"
2. 재료를 묻는다: "지금 가진 사진이나 영상이 뭐가 있으세요? 없으면 찍을 것을 알려 드릴게요."
3. 아래 표로 카드 2~3장으로 좁혀 보여 주고 하나 고르게 한다. 답이 없으면 1번 후보로 만든다.

| 목적 | 사진만 있음 | 클립도 있음 | 얼굴 괜찮음 |
|---|---|---|---|
| ① 새 소식 | G3·G4 + 알릴 소식 | G1 + 알릴 소식 | G6 + 알릴 소식 |
| ② 가게 자랑 | G3, G4, G2 | G1, G7 | G9 |
| ③ 믿음 주기 | G5, G2 | G1(설명 켬) | G6, G8 |
| ④ 재미 | G7(사진형) | G7 | G9, G8 |

## 5) 편집 느낌 3개 (사장님께 보여 주는 것)

| 사장님께 하는 말 | 자막 | 장면 길이 | 소리 | 장면표 설정(HyperFrames 템플릿은 `guides/make/shortform-hyperframes.md` 2절: 잔잔하게 = `showcase`·`before-after`, 정보 = `info-card`, 빠르게 = `time-routine`. 아래 키는 장면표 JSON·대체 `tools/shortform.py`) |
|---|---|---|---|---|
| 잔잔하게 | 큰 제목 하나(또는 없음), 사진이 화면 전체 | 클립 2~3초, 사진 3~3.5초 | 잔잔한 음악(현장 소리는 내용일 때만) | `layout: "full"`, `caption_style: "outline"`, 1번 장면은 사진 없는 `hook` 글자 카드 또는 사진 + `caption` 한 줄, `zoom: "in"`, `transition: "fadeblack"`·`"smoothleft"` |
| 정보 또박또박 | 위 띠 제목 고정 + 상자 자막, 핵심어 강조 | 클립 1.5~3초, 사진 2.5~3초 | 사장님 목소리 또는 AI 목소리 | `layout: "info"`, `theme: "info"`, `fixed_title` + 장면마다 `caption`(상자), 핵심어 `*강조*` 한 곳 |
| 빠르고 신나게 | 짧은 꼬리표(시각·이름표) + 외곽선 자막 | 클립 0.7~1.5초, 사진 2~2.5초 | 박자 있는 음악(올릴 때 앱에서) | `layout: "full"`, 장면 `title`에 꼬리표(`"07:10"` 등), `caption_style: "outline"`, `transition: "cut"`·`"slideleft"` |

기본값: G5·G6은 '정보 또박또박', G7·G9는 '빠르고 신나게', 나머지는 '잔잔하게'. 색은 사장님 홈페이지·간판 색이 아니라 잘하는 숏폼의 문법에서 온다: `theme: "info"`(검정 띠 + 노랑 강조, 정보 숏폼 문법), `theme: "warm"`(크림·갈색, 가게 브이로그). 시안은 늘 2안: 1안 레퍼런스안(고르기 전 기본), 2안은 기존 가게 색을 `highlight_color`로 강조색에 얹은 안(기존 색이 없으면 같은 성격 카드의 다른 스타일). 사장님께는 "1번/2번, 번호만 알려 주세요"(`guides/make/shortform.md` 3절, `guides/07-design-kit.md` 1)). 밝은 색이면 강조 글자는 같은 계열 진한 색. 고른 느낌·theme·강조색은 브랜드 프로필 디자인 키트에 적어 두고 다음에도 쓴다. 키트(우리 가게 색)가 정해진 뒤에는 theme 기본색 대신 그 색을 `colors`로 넘겨 같은 소재 카드뉴스와 같은 팔레트·글꼴로 맞춘다(`guides/make/shortform.md` 6) '같은 브랜드 팔레트').

**재료 분류 P1~P7 (내부용, 사장님께 묻지 않는다)**: 올린 사진·영상에 누가 나오고 누가 말하는지 보고 에이전트가 정한다.

| 코드 | 재료 | 맞는 카드 |
|---|---|---|
| P1 | 사장님 얼굴 + 말 | G6, G8 |
| P2 | 손만 + 음악·현장 소리 | G1, G3 |
| P3 | 손님·직원(동의) + 음악 | G7, G4, G2 |
| P4 | 사장님 얼굴 + 말 없음(상황 자막) | G9 |
| P5 | 사람 없음 + 음악 (**사진만 있을 때 기본**) | G3, G4, G2 |
| P6 | 손 + 사장님 설명 목소리 | G1(설명 켬) |
| P7 | **사람 없음 + 목소리**(사장님 녹음 또는 AI 목소리) | G5, G8(사진형), G2 |

- P7은 사진만으로 정보를 전하는 기본 조립형이다. AI 목소리는 써도 되지만 AI 인물을 만들거나 AI 목소리로 "써 봤어요" 같은 경험담을 말하게 하지 않는다.

| 전문직 | G6·G8 | 실명·개인정보 가림, 결과 보장 금지 |
| 얼굴·아이 | G3·G4·G7·G9 | 손님·원생 얼굴은 동의 확인. 아이는 기본으로 가림 |
| 남의 방송·영상 | G9 | 예능·방송 장면을 가져다 쓰지 않는다 |
| 음악 | G7·G9·G3 | 앱의 상업용 음원만(`guides/make/shortform.md` 8절) |

## 7) 0~3초 훅 (틀만 빌리고 말은 우리 것으로)

화면 첫 글자는 **두 줄, 줄마다 8~12자**, 강조는 한 곳. 첫 1초 안에 화면 글자가 보이게 한다. **첫 3초**(틱톡 광고 도움말: 핵심은 첫 3초, 훅은 6초 안)에 무엇에 관한 영상인지와 가장 강한 장면을 보여 준다. 첫 장면은 움직임이 가장 큰 컷 또는 결과물이다(업종별 첫 장면: `guides/make/shot-lists.md`). 훅 문구는 뒤에서 위쪽 고정 제목 1줄로 끝까지 남긴다. 컷 길이는 박자 기준 0.7~3초(`guides/make/shortform.md` 5절).

| 쓰는 훅 | 예 | 쓰지 않는 훅 |
|---|---|---|
| 결과 먼저 | 0초에 완성품·결과 화면 | 기능 설명 "~하면 ~해 줘요" |
| 경고 | "~ 그냥 하면 안 돼요" | "97%가 모르는", "비밀" |
| 숫자 질문 | "~ 팔면 얼마 남을까?" | "~라면 꼭 보세요" |
| 놀람 질문 | "~가 있다고?" | 근거 없는 숫자(숫자 뒤엔 바로 근거 장면) |
| 내부자 시점 | "N년 차 ~가 보는 ~" | |
