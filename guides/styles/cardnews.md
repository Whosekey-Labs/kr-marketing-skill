# 카드뉴스 유형·스타일 목록

사장님께 고르게 할 때 이 파일만 연다. 만드는 절차는 `guides/make/cardnews.md`.
**유형(C) = 무엇을 알리나(목적)**, **스타일(S) = 어떻게 보이나(디자인)**. 유형 1개 + 스타일(표지 1, 본문 1)을 고른다.

## 1. 고르게 하는 법

1. 업종 추천 유형(아래 3절) 3~4개만 보여 준다. 12개를 다 보여 주지 않는다.
2. 디자인은 갈래 견본(`gallery/cardnews/A.png`·`B.png`·`C.png`)을 보여 주고 고르게 한다.
3. 표지는 이미지 생성(또는 사진)으로 힘을 주고, 본문은 같은 갈래 템플릿으로 찍어 낸다(레퍼런스 14/25곳이 표지·본문 틀을 다르게 씀).
4. 디자인 기본은 사장님 홈페이지·로고 색이 아니라 **같은 업종에서 반응 좋은 카드뉴스 3~5개의 디자인 문법**(위계·여백·사진 비중·글자 크기·색 쓰는 법)과 고른 스타일을 합친 것이다(`guides/make/cardnews.md` 1)·3)). 첫 회에는 시안 2안을 늘 만든다: 1안 레퍼런스안(고르기 전 기본) / 2안 기존 색 살린 안(기존 색이 없으면 같은 성격 카드의 다른 스타일). 사장님께는 "1번/2번, 번호만 알려 주세요"로 묻는다(`guides/07-design-kit.md` 1)). 사진이 없으면 갈래 A를 쓰지 않고 B(그림) 또는 C로 한다. 밝은 브랜드 색은 면으로만, 강조 글자는 같은 계열 진한 색.
5. 고른 것은 브랜드 프로필 "카드뉴스 스타일" 칸에 `갈래 B / 시리즈 '○○ 꿀팁' / 캐릭터 시트 art/char.png`처럼 저장한다. 다음부터는 묻지 않는다.

사장님께 하는 말 예시:
> "이번 신메뉴는 '신메뉴 출시' 틀로 5장 만들게요. 디자인은 이 중에 골라 주세요. 표지는 사진 크게(2번), 안쪽은 글자 카드(5번)를 많이 써요."

**C06 정보·꿀팁 안의 레이아웃 5종** (원고 JSON에서 이렇게 씀):

| 레이아웃 | 쓰는 때 | 원고 칸 |
|---|---|---|
| 설명형 | 한 가지를 문단으로 설명 | `heading` + `text` + 숫자 앵커(`anchor` number) |
| 번호 리스트 | "○가지" | `items` (번호 자동, `icon`·`cards`로 바꿀 수 있음) |
| 체크리스트 | 자가진단·준비물·저장용 요약 | `items` + `"checklist": true`(흰 카드 기본) |
| 단계 | 1→2→3 순서 | `anchor` flow, 또는 장마다 `kicker: "STEP 1"` + `heading` + `text` |
| 비교 | A vs B, X·O | `anchor` vs, 또는 `compare` |
| 표·시간 | 짝 정보, 시간대 | `anchor` table / timeline |

칸 자세한 설명은 `guides/make/cardnews-spec.md`. 장마다 레이아웃·앵커를 바꾼다(같은 틀 연속은 렌더 점검에 걸린다).

공통 규칙: 업체 글은 마지막 장을 **행동 1개**로 끝낸다(예약·방문·저장 중 하나 + 지역명). 그 바로 앞에는 **저장용 요약 장**(체크리스트 3~4줄)을 둔다(정보형 C05·C06·C07은 꼭). 메뉴 소개처럼 사진으로 끝나는 글도 마지막에 영업시간·위치 1장을 더한다. 장마다 숫자나 예를 하나 넣는다.

주의 업종: 의료 전후사진은 기본값 '권하지 않음'. 복지부 가이드라인 Q3 5조건+사전심의를 갖출 때만 가능하고, AI 생성·보정은 금지(`guides/compliance/medical.md`). 피부관리실(비의료)의 전후·효과 표현도 의료 오인 위험이 있어 `guides/compliance/` 확인. 후기는 손님 동의를 받은 실제 후기만 쓴다(공정위 추천·보증 심사지침).

## 4. 디자인 갈래 (HTML 템플릿 기본, `templates/cardnews-html/`)

잘하는 계정 25곳(조사 C3)은 거의 세 갈래로 묶인다. **갈래 = 테마 1개**(`theme`: A·B·C)이고, 장마다 레이아웃(리스트·VS·Q&A·숫자·체크리스트·단계·사진·마지막 장)을 바꾼다. 견본: `gallery/cardnews/A.png`·`B.png`·`C.png`(표지), `C01.png`~`C07.png`(유형별 표지+본문 2장).

| 갈래 | 이름 | 이렇게 생김 | 표지 | 잘 맞는 곳 | 닮은 계정(C3) |
|---|---|---|---|---|---|
| **A** | 실사진 + 하단 큰 글씨 | 사진 꽉 채움 + 아래 검정 그라데이션 + 흰 굵은 제목 2~3줄. 본문은 흰 모눈 바탕 + 연한 띠 소제목 | 사장님 실제 사진(+ 이미지 생성 편집으로 글자) | 카페·빵집·미용·필라테스·숙박(사진이 있는 가게) | dogsnature, monthly_bakery, franchise_radar |
| **B** | 캐릭터 일러스트 + 큰 제목 | 크림 바탕, 핵심어만 빨강, 같은 캐릭터가 장마다 말풍선으로 말함, 아래 결론 상자·브랜드 띠 | 이미지 생성(캐릭터 + 레터링) | 정보형 전문가(노무·세무·교육), 사진 없는 동네 가게, 이벤트 | jungyul_labor, dontori_fire, doran_doran |
| **C** | 미니멀 매거진 | 검정 바탕, 흰 제목, 형광 연두 1색, 알약 라벨·짧은 강조선, 세로 세리프 로고 글자 | 장면 사진 1장 + 제목, 또는 글자만 | 업계 깊은 정보, 공지, FAQ, 고급 매장 | dental_onepage, alchada3355, 41designstudio |

- 사진이 없으면 A를 쓰지 않는다(사진 자리를 AI 실사로 채우지 않는다). B는 그림이 없어도 글자만으로 된다(`gallery/cardnews/C03.png`).
- 공통 틀(세 갈래 모두): 왼쪽 위 시리즈 라벨 + 회차, 오른쪽 위 쪽번호, 아래 계정 이름 띠, 강조색 1개, 한 장 한 가지.
- 로고 그림·워터마크는 넣지 않는다. 가게 이름은 라벨·아래 띠의 글자로만.

**예전 스타일 코드(S01~S11)**는 Pillow 대체 경로(`tools/cardnews.py`)에서만 쓴다. 견본은 `gallery/cardnews/pillow/S01.png` 등. 대응: A ≈ S02·S03·S09, B ≈ S05·S06·S07, C ≈ S05 dark.

## 5. 근거 (조사 요약)

- 인스타 캐러셀 3,366건 수집, 200건 시각 분류(업체 계정 104건), 블라인드 재분류 60건 일치율 유형 77%·스타일 80%. 정보 계열과 사진 계열의 경계가 흔들려서 목적 기준 12개로 묶었다.
- 업체가 가장 많이 올린 목적은 신메뉴 출시(업체 프로필 캡션 17%)와 시즌 한정(13%)이다.
- 업체 계정 스타일 상위: 사진 위 텍스트 21%, 브랜드 색 16%, 실사진 15%, 일러스트 10%.
- 폰트(200건): 고딕 볼드 107, 장식체 31, 고딕 보통 29, 손글씨 17, 세리프 10, 둥근 6 → 기본은 Pretendard 볼드.
- 표지 제목 중앙값 15자(12~19자), 본문 한 장 중앙값 75~80자(40~120자), 장수 중앙값 7장(업체 6장), 10장 이하가 90%.
