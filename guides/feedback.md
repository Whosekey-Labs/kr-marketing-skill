# 제보: 개선 요청을 저장소에 등록

이 스킬은 사용자 제보로 좋아진다. 아래 경우 사장님께 한 줄로 제보를 권한다(같은 대화에서 한 번만).

- **업종이 안 맞을 때**: 업종 파일에 없는 업종, 채널 순서·금지 표현이 실제와 다를 때
- **법규 검수가 이상할 때**: 괜찮은 표현을 막거나, 막아야 할 표현을 놓쳤을 때
- **결과가 이상할 때**: 스크립트 오류, 엉뚱한 조사 결과, 카드뉴스·숏폼이 깨질 때
- **업로드가 안 될 때**: 플랫폼 화면이 바뀌어 안내대로 안 될 때

권하는 말 예: "이 내용을 스킬 개발자에게 알려 두면 다음부터 다른 사장님들도 더 잘 쓸 수 있어요. 제가 대신 등록할까요?"

## 등록할 내용 (가게·개인정보 금지)

공개 글이다. **상호·주소·사장님 이름·연락처·매출 숫자·손님 정보·계정 정보·브랜드 프로필 내용은 넣지 않는다.** 업종과 현상만 쓴다.

```
제목: [업종 추가] 반찬가게 — 식품 효능 표현 검수 필요
본문:
- 종류: 업종 추가 / 법규 검수 / 결과 오류 / 업로드 안내
- 업종: 식품 판매 (반찬가게)
- 내용: 반찬가게는 당근 비중이 높은데 업종 파일에 당근이 확장으로 되어 있음
- 오류면: 실행한 명령과 오류 메시지 (가게 정보 지우고)
- 플랫폼(업로드면): 네이버 블로그 / 인스타 등, 막힌 화면 설명
- 에이전트: 피클 / Claude / ChatGPT 등
```

**올리기 전에 이 내용을 사장님께 보여 주고 "올릴까요?"라고 묻는다.** 좋다고 할 때만 등록한다.

## 등록 방법 (되는 것부터)

1. **깃헙 연결(커넥터·MCP)이 있으면**: `Whosekey-Labs/kr-marketing-skill` 저장소에 이슈를 만들고 링크를 준다.
2. **없으면**: 미리 채운 이슈 링크를 준다. 사장님이 깃헙 로그인 후 "Submit"만 누르면 된다.
   `https://github.com/Whosekey-Labs/kr-marketing-skill/issues/new?title={제목}&body={본문}` (제목·본문은 URL 인코딩)
3. **깃헙 계정이 없으면**: 오픈채팅방을 안내한다. https://open.kakao.com/o/g3vAeBWi
