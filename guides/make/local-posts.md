# 짧은 소식 · 리뷰 답글 · 쿠폰 공지

플레이스 새소식, 당근 소식, 카카오 채널 소식, 리뷰 답글, 쿠폰·이벤트 공지를 만든다. 올리는 법은 `guides/upload/`의 플랫폼 파일. 법규 검수(`guides/compliance/`)는 그대로 거친다.

## 0) 공통 규칙
1. 가격·기간·수량·영업시간은 사장님 자료로만. 없으면 `[직접 입력: 예) 11/30까지]`.
2. 같은 문장을 세 곳에 그대로 붙이지 않는다. 소재는 같아도 첫 줄과 길이를 바꾼다(카카오 운영정책은 같은 내용 반복 등록을 금지한다).
3. 할인 소식은 세 번에 한 번 이하. 나머지는 가게 이야기(오늘 들어온 재료, 준비 과정, 단골 질문 답).
4. 사진은 사장님이 찍은 실제 사진. 실제 매장·상품·사람처럼 보이는 AI 이미지는 쓰지 않는다. 누가 봐도 그림(일러스트·아이콘·패턴 배경)은 장식용으로만 된다. 로고 그림·워터마크는 넣지 않는다.
5. 브랜드 프로필이 없으면 최소 프로필(업종·규제 플래그·말투 한 줄·금지 표현·사실 자료)만 만들고 바로 제작한다(`guides/00-start.md` 중간 요청 규칙).
6. 사장님 대상 글에서 쓰지 않는 표현은 `guides/compliance/common.md`의 '반감 부르는 표현'.

## 1) 플랫폼별 소식 틀

| 플랫폼 | 사진 | 글 | 틀 |
|---|---|---|---|
| 스마트플레이스 새소식 | 1~3장(동영상 가능) | **3~4줄** | 1줄 무엇이 새로운지 → 1줄 왜 좋은지(사실) → 1줄 언제·얼마 → 1줄 행동(예약·방문) |
| 당근 소식 | [사진+글 혼합] 20장·영상 1개(1분) / [사진 모아보기] 10장 | 5~8줄 | 동네 말투. "○○동 이웃님들" 시작 → 이야기 → 정보 → 행동 |
| 카카오 채널 소식 | 1~5장 | 3~6줄 | 친구(이미 아는 손님)에게. 재방문 이유를 준다 |

예시 (플레이스, 빵집):
```
이번 주부터 단호박 크림빵이 나와요.
아침 7시에 굽기 시작해 10시쯤 첫 판이 나옵니다.
가격 [직접 입력: 3,800원], 하루 [직접 입력: 30개]만 구워요.
전화 예약하시면 따로 빼 둘게요.
```

- 플레이스 공지 설정은 최대 5개, 최대 45일. 휴무·연휴 영업 안내는 공지로 건다.
- 병원은 플레이스 새소식 기능이 없다.

## 2) 리뷰 답글

### 갈래 나누기 (먼저 판단)

| 리뷰 | 할 일 | 원칙 |
|---|---|---|
| 칭찬 | 공개 답글 | 손님이 말한 구체적인 것 하나를 받아 준다. 복붙 금지. 손님 이름·주문 내역 등 개인정보 언급 금지 |
| 맛·양·서비스 불만 | 공개 답글 | 공감 → 사실 확인(단정 금지) → 할 조치. 조치는 실제로 한다. 같은 불만이 반복되면 콘텐츠보다 그 문제를 먼저 사장님께 알린다 |
| 허위·욕설·개인정보·반복 게시(악성) | 신고 + 짧은 사실 답글(선택) | 싸우지 않는다. 신고: **스마트플레이스 → 권리침해 신고 → 권리보호센터** |
| 위생·안전(이물·식중독 등) | **마케팅으로 다루지 않는다** | 사장님께 즉시 알림. 증빙 보관, 식품위생법 제46조 행정 보고가 먼저. 확인된 사실만 짧게 |

### 지킬 것
- 네이버 플레이스 사업주 답글은 **리뷰 1개당 1개**다. 한 번에 정확히 쓴다.
- 답글로 욕설·괴롭힘·작성자 신상 추정은 금지(업체 제재 사유).
- 리뷰 쓴 손님에게 **따로 연락해 삭제를 부탁하지 않는다**(네이버 금지).
- "리뷰 삭제 대행", "좋은 리뷰로 덮기", 지인 리뷰는 쓰지 않는다.
- 맛·양에 대한 주관적 불만은 내리기 어렵다(2026-02 배달 플랫폼 분쟁조정협의회 권고: 주관적 평가는 임시조치 대상에서 제외). 신고보다 답글로 대응한다.
- 신고하면 약 24시간 안에 처리되고 30일 동안 게시가 중단된다. 작성자가 이의를 내면 다시 올라올 수 있다.
- 네이버에도 답글 초안 기능(베타)이 있다. 네 답글은 **이 가게의 사실과 말투**를 담아야 의미가 있다.
- 논란이 커지면 사과문 초안까지만 쓰고 게시는 사장님이 확인한다. 법적 다툼 소지가 보이면 "전문가 상담을 권해요"라고 말한다.

### 예시
칭찬:
```
크루아상 결 사진까지 남겨 주셔서 감사해요. 버터를 바꾸고 처음 받은 칭찬이라 주방에서 다 같이 봤어요. 다음엔 아침 첫 판 나오는 10시쯤 오시면 더 바삭할 거예요.
```
불만(양):
```
양이 적게 느끼셨다니 죄송합니다. 그날 주문 내역을 확인해 보고, 같은 메뉴 담는 기준을 다시 맞추겠습니다. 다음 방문 때 말씀 주시면 직접 챙기겠습니다.
```
악성(허위 의심, 신고 후):
```
저희 기록으로는 말씀하신 날짜에 해당 주문이 확인되지 않습니다. 확인할 수 있는 정보를 매장으로 알려 주시면 바로 살펴보겠습니다.
```

### 주간 리뷰 루프 (`guides/04-weekly.md`에 넣는 상시 일)
1. 이틀에 한 번(최소 주 1회) 새 리뷰를 모은다(사장님 캡처 또는 네 브라우저로 플레이스 리뷰 화면).
2. 위 표로 갈래를 나누고 답글 초안을 만든다. 불만·악성은 당일 사장님께 먼저 알린다.
3. 사장님이 고친 답글은 말투 예시로 브랜드 프로필에 쌓는다.
4. 주간 보고에 한 줄: "새 리뷰 ○개, 답글 ○개, 반복 불만: '맵다' 2건."
5. 같은 불만이 2주 연속이면 "콘텐츠보다 먼저 고칠 것"으로 올린다.

## 3) 리뷰 이벤트 문구 (기본으로 제안하지 않는다)

대가를 주는 리뷰 이벤트는 **먼저 권하지 않는다.** 조건을 지켰는지 증명할 책임이 가게에 있고, 직원 한마디("별 5개 부탁드려요")로도 위반이 된다. 사장님이 먼저 원할 때만 아래를 알리고, 확인을 받은 뒤 만든다.

| 플랫폼 | 대가 주는 리뷰 이벤트 | 조건 |
|---|---|---|
| 네이버 플레이스 | 조건부로 가능 | 허용 조건: 실제 결제 영수증만 / 리뷰 내용·별점에 관여하지 않음 |
| 구글 | 금지 | 대가 제공, 만족한 손님만 골라 부탁하기 모두 금지 |
| 병의원·의료로 오인될 업종 | **금지** | 병의원 이벤트·체험단 리뷰는 치료경험담이라 "광고" 표시해도 금지(의료법 제56조②2호). 의료 오인 업종은 후기에 치료·개선이 섞일 위험. 사장님이 원해도 만들지 않는다 |

- 네이버 금지 행위: 별점·표현 요구, 작성 화면 확인·대신 작성(촬영), 이벤트용 저가 영수증, 대행사·리워드 앱. **한 번만 걸려도 업체 리뷰 전체가 안 보이게 될 수 있다**(네이버 스마트플레이스 공지 957, 2026-01).
- 단순히 리뷰를 부탁하는 것은 괜찮다.
- 직원에게 줄 한 줄: `리뷰는 부탁만 하고, 별점·내용은 말하지 않아요. 쓰는 화면도 보지 않아요.`
- 문구 예(허용 조건을 지킨 것만): `영수증 리뷰를 남겨 주시면 다음 방문 때 음료 1잔 드려요. 별점·내용은 자유예요.`
- 자세한 근거는 `guides/compliance/common.md`의 리뷰 이벤트 항목.

## 4) 쿠폰·이벤트 공지

1. 만들기 전에 세 가지를 사장님과 정한다: **목적 1개**(신규 / 재방문 / 객단가 / 빈 시간대), **건당 남는 돈**(원가·수수료·할인액), **끝난 뒤 계획**.
2. 기본은 증정·세트·다음 방문 쿠폰. 전체 할인은 기간·대상 한정일 때만.
3. 네이버 플레이스 쿠폰은 전체·알림받기·마케팅 수신 손님 대상으로 발행한다. 재방문 목적이면 알림받기 손님 대상이 맞다.
4. 공지에 꼭 넣을 것: 기간, 대상, 사용 조건, 중복 여부. 모르면 `[직접 입력]`.

## 5) 재방문 메시지 (카톡 채널 메시지·문자)

쿠폰 발급·소멸 안내도 **광고성 정보**다(KISA 안내서 2026). 보내기 전 네 가지를 자동 점검한다:
1. 맨 앞 `(광고)`
2. 보내는 사람 이름·연락처
3. 무료 수신거부 방법
4. 보내는 시각 10~20시(21시~08시는 별도 동의 필요. 카카오 브랜드 메시지는 20:50까지)

- 받는 사람은 **광고성 정보 수신에 사전 동의**한 사람만. 동의 문구는 "광고성 정보 수신 동의"를 그대로 쓴다("혜택 알림 받기"만으로는 안 된다).
- 순서: 네이버 알림받기·쿠폰(무료) → 카카오 채널 메시지(유료, 월 1~2회, 비용 먼저 보여 주기).
- 발송은 사장님이 한다(`guides/upload/kakao-channel.md`).
