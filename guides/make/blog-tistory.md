# 티스토리 재작성 (다음·구글 검색용)

네이버 블로그 원본을 바탕으로 티스토리(또는 워드프레스)용 **새 글**을 쓴다. 복사본이 아니다. 티스토리는 다음·구글 검색에서 손님을 데려오는 용도다. 채널 등급이 '확장'일 때만 한다. 브랜드 프로필이 없으면 최소 프로필(업종·규제 플래그·말투 한 줄·금지 표현·사실 자료)만 만들고 바로 제작한다(`guides/00-start.md` 중간 요청 규칙).

## 1) 시작 조건 (셋 다 예일 때만)

| # | 조건 | 왜 |
|---|---|---|
| 1 | 네이버 원본을 **먼저** 올렸다 | 네이버는 먼저 쓴 글을 원본으로 본다. 늦게 올린 네이버 글이 사본 취급을 받은 사례가 있다 |
| 2 | 네이버 원본이 검색에 노출된 것을 확인했다(`guides/make/blog-naver.md` 10절) | 원본 자리부터 잡는다 |
| 3 | 원본 발행 뒤 **24시간 이상** 지났다 | 실무 관행(공식 수치 아님) |

하나라도 아니면: "네이버 글이 검색에 자리 잡은 뒤(내일 이후) 티스토리 글을 쓸게요."

## 2) 왜 새로 써야 하나 (사장님께 한 줄로)

- 네이버는 티스토리 글도 '외부 블로그'로 블로그 검색에 넣는다. 같은 글이면 한쪽만 나온다.
- 네이버·구글 모두 단어만 바꾼 글(동의어 바꾸기)을 스팸 쪽으로 본다.
- 말: "같은 글을 두 곳에 올리면 한 곳만 검색에 나와요. 그래서 티스토리용은 정보 위주로 새로 쓸게요."

## 3) 문체만 바꾸면 재작성이 아니다

아래를 **전부** 바꾼다. 같아도 되는 것은 사실(가격·주소·영업시간·메뉴 이름)뿐이다.

| 바꿀 것 | 네이버 원본 | 티스토리 재작성 |
|---|---|---|
| 독자·각도 | 동네 손님, 방문 경험·현장 | 검색하는 사람, 가격·비교·FAQ 정보형 |
| 제목 | 지역+상품+상황 | 정보형 질문·정리형 ("○○ 가격·메뉴 총정리", "○○ 고를 때 볼 3가지") |
| 도입 | 장면·경험으로 시작 | **결론 요약 3줄**로 시작 |
| 구성 | 원본 유형의 순서 | 소제목 순서·개수를 다르게 (예: 원본 B09 → 재작성은 B03 비교형이나 B10 FAQ형) |
| 예시·사례 | 원본에 쓴 사례 | 다른 사례나 다른 각도(같은 사례를 쓰면 다른 면을) |
| 결론 | 원본 마무리 | 새 문장. 정리 표나 체크리스트 |
| 사진 | 원본 사진 | **절반 이상 다른 컷**. 같은 컷이면 자르기·순서를 바꿈 |
| 분량 | 유형별 범위(권장) | 2,500자 이상 권장(실무 권고, 공식 아님). 소재가 모자라면 지어내지 말고 짧게 + 소재 요청 |

## 4) 구조 (정보형)

1. 제목 (H1은 글 제목이 대신함)
2. 결론 요약 3줄
3. `H2` 소제목 3~5개. 하위 항목은 `H3`. (티스토리 에디터의 '제목2·제목3')
4. 가격·구성은 표로. 이미지 속 정보는 글로도.
5. 자주 묻는 질문 3~5개 (H2 하나 아래 H3로 질문)
6. 정리 + 원본 네이버 글 링크 1개 + 지도·찾아오는 길
7. 태그 3~5개

원본 링크 문장 예: "매장에서 직접 굽는 과정은 네이버 블로그 글에 사진과 함께 올려 두었어요: [링크]"

## 5) 유사도 점검 (스킬 기준값, 공식 수치 없음)

다 쓰면 원본과 나란히 놓고 확인한다.

| # | 점검 | 기준 |
|---|---|---|
| 1 | 같은 문장 | 띄어쓰기 빼고 15자 이상 같은 문장이 전체 문장의 **20% 이하** |
| 2 | 제목 | 겹치는 말은 지역·업종 1~2개뿐 |
| 3 | 도입 3문장 | 전부 새 문장 |
| 4 | 소제목 | 순서·개수가 원본과 다름 |
| 5 | 사진 | 절반 이상 다른 컷 |
| 6 | 원본 링크 | 1개 들어감 |

스크립트 모드면 두 글을 문장으로 나눠 띄어쓰기를 뺀 뒤 15자 이상 겹치는 문장 수를 세는 짧은 코드를 돌린다. 브라우저 모드면 문단마다 눈으로 비교한다.

기준에 걸리면 걸린 문단만 다시 쓴다.

## 6) 브런치에 올릴 때 (선택)

브런치는 광고·홍보를 스팸 묶음에 넣었다. 홍보 글이 아니라 **사장님 에세이**(1인칭, 가게를 하며 생각한 것)로 쓰고 홍보 문구는 최소로. 같은 글을 반복해서 올리지 않는다.

## 7) 출력 형식

```
제목: …
요약 3줄: …
## H2 소제목
### H3 …
[사진A: 새 컷 — 설명]
[표] … [/표]
원본 링크: (네이버 글 주소)
태그: …
유사도 점검: 같은 문장 n% / 사진 다른 컷 n장 중 n장
```

올리는 방법은 `guides/upload/tistory.md`.

## 8) 남은 불확실

- 네이버가 티스토리↔네이버 블로그 사이에 유사문서 판독을 적용한다는 명시 문장은 없다(정황 근거만 강함).
- 20%·24시간·2,500자는 실무·추정 값이다. 사장님 블로그의 실제 노출 결과로 고쳐 간다.
