# 소재 1개 → 원본 3종 → 플랫폼별 버전 → 짧은 소식

같은 글·파일을 그대로 여러 곳에 붙여 넣지 않는다. 원본 3종을 한 번 공들여 만들고, 플랫폼마다 **제목·첫 줄·해시태그·행동 안내·길이**를 새로 쓴다. 채널 등급(핵심/확장/제외)은 브랜드 프로필을 따른다. 제외 채널은 만들지 않는다. 브랜드 프로필이 없으면 최소 프로필(업종·규제 플래그·말투 한 줄·금지 표현·사실 자료)만 만들고 바로 제작한다(`guides/00-start.md` 중간 요청 규칙).

## 1) 순서

1. **소재 카드**를 만든다: 사실(가격·기간·주소·영업시간), 사진·영상 원본, 사장님 경험 한 가지. 모든 버전의 근거다. 없는 사실은 `[직접 입력]`.
2. **원본 3종**을 만든다.

| 원본 | 규격 | 만드는 파일 |
|---|---|---|
| 블로그 글 | 네이버 블로그 | `guides/make/blog-naver.md` |
| 카드뉴스 | 1080×1350(4:5) JPEG, sRGB, 장당 8MB 이하. 핵심 글자는 가운데 1080×1080 안 | `guides/make/cardnews.md` |
| 숏폼 | 1080×1920, 30fps, H.264 MP4, 15~45초 기본, 이야기·정보형 30~90초(상한 90초), **음원 없음, 워터마크 없음** | `guides/make/shortform.md` |

3. 아래 2절 표대로 플랫폼별 문구 세트를 만든다.
4. 3절대로 짧은 소식을 만든다(`guides/make/local-posts.md`).
5. 4절 순서대로 올린다(올리는 방법은 `guides/upload/index.md`).

## 2) 플랫폼별로 바꿀 것 (14곳)

SNS **해시태그**(인스타·릴스·쇼츠·틱톡·스레드 등)는 **5개 이하**. 네이버 블로그 **태그**(글 아래 태그 칸)는 이것과 다른 것으로 3~7개다(`guides/make/blog-naver.md` 8)). 링크·로고 규칙은 표 아래 '공통 금지'.

| 플랫폼 | 원본 | 제목 | 도입(첫 화면·첫 줄) | 해시태그 | 행동 안내·링크 | 길이·형식 |
|---|---|---|---|---|---|---|
| 네이버 블로그 | 블로그(원본) | 지역+상품+상황, 낚시 금지 | 경험·상황으로 | 본문 태그 3~7 | 플레이스·예약 링크 | 유형별 분량 |
| 티스토리·워드프레스 | 블로그 재작성 | 정보형("○○ 가격·메뉴 총정리") | 결론 요약 3줄 | 3~5 | 원본 블로그 글·지도 링크 | 2,500자 이상(실무), `guides/make/blog-tistory.md` |
| 브런치 | 블로그 재작성 | 이야기형 | 사장님 1인칭 | 3 안팎 | 매장 소개 링크 1개 | 에세이, 홍보 문구 최소 |
| 인스타 캐러셀 | 카드뉴스 | (없음) 1장 표지 문구가 제목 | 1장 = 훅. 캡션 첫 줄 125자 안에 핵심(실무) | **≤5** | "저장"·"프로필 링크"·DM. **캡션에 링크 넣지 않음** | 5~10장(최대 20), 4:5 |
| 스레드 | 카드뉴스 또는 블로그 요약 | 없음 | 첫 줄이 곧 글 | 주제 태그 1 | 대화형 질문 | 500자 이하 + 이미지 2~20장 |
| 페이스북 페이지 | 카드뉴스 | 없음 | 정보 한 줄 | ≤5 | **링크는 캡션 말고 댓글·프로필에**(Meta: 링크 없는 캡션이 성과가 가장 좋음) | 짧게, 4:5 |
| 유튜브 게시물 | 카드뉴스 1:1 자른 것 | 없음 | 질문·투표형 | — | 쇼츠·영상 링크 | 10장 이하, **1:1** |
| 링크드인 (B2B만) | 카드뉴스 PDF | 문서 제목 | 업계 관점 한 줄 | 3 안팎 | 상담 문의 | 같은 크기 페이지 PDF, 8~12쪽(실무) |
| 핀터레스트 | 카드뉴스 | 검색어형 | — | — | 웹사이트(블로그) 링크 | 2:3 표지(1000×1500), 캐러셀 2~5장 |
| 유튜브 쇼츠 | 숏폼 | 100자 이하, 검색어 넣기 | 첫 1~2초 훅 문구 | **3개 이하**(제목 옆엔 3개만 보임) | 고정 댓글·관련 동영상 | 60초 이하 권장(1분 넘고 Content ID 걸리면 전 세계 차단) |
| 인스타 릴스 | 숏폼 | (캡션) | 첫 화면 문구 + 캡션 첫 줄 | ≤5 | 저장·공유·프로필. 캡션에 링크 넣지 않음 | 15~45초 기본, 정보형 30~90초 |
| 페이스북 릴스 | 숏폼 | 제목·설명 | 인스타와 비슷하게, 문장은 새로 | ≤5 | 페이지 링크는 댓글·프로필에 | **90초 이하** |
| 틱톡 | 숏폼 | (캡션) | 첫 1초 훅, 틱톡 말투 | 3~5 | 프로필 링크·댓글 유도 | 3분 이하. 음원은 틱톡 상업용 라이브러리(CML)만 |
| 네이버 클립 | 숏폼 | 설명 3,000자 안 | 지역·장소 말 넣기 | **≤5** | 외부 URL 불가 → **'콘텐츠 링크'로 원본 네이버 블로그 글 연결** | 3분 이하(편집기), **'AI 활용' 설정**: AI로 만들거나 바꾼 영상이면 ON |

### 자막·글자 위치 (숏폼 공통, 1080×1920)

- 자막·핵심 글자는 **x 65~890, y 270~1250** 안에 둔다. 위 270px, 아래 670px, 왼쪽 65px, 오른쪽 190px은 비운다(버튼·계정명 자리).
- 훅 문구는 y 300~500, 자막 기준선은 y 1150~1250.
- 공식 수치는 Meta 광고 가이드(위 14%·아래 35%·좌우 6%)뿐이고 나머지는 실무 값이다.

### 공통 금지

1. **로고·워터마크를 이미지·영상 안에 넣지 않는다.** 인스타는 "보이는 워터마크"가 있으면 누구 것이든 추천에서 뺀다. 브랜드는 표지의 상호 글자로 보여 준다.
2. **다른 앱에서 내려받은 파일을 다시 올리지 않는다.** (틱톡 로고 박힌 파일을 릴스·쇼츠·클립에 올리는 것이 가장 흔한 실수) 플랫폼마다 원본 파일을 따로 올린다.
3. **상업용 음원을 넣어 렌더링하지 않는다.** 배경음악은 올릴 때 사장님이 각 앱의 상업용 라이브러리에서 고른다(틱톡 CML, 메타 사운드 컬렉션, 클립 에디터 음원, 유튜브 오디오 보관함).
4. 같은 문장을 그대로 붙여 넣지 않는다. 첫 줄·해시태그 조합은 플랫폼마다 새로 쓴다.
5. AI로 만든 인물이 추천·후기를 말하면 '가상인물' 표시 의무(공정위, 2026-06-01). 이 스킬은 AI 인물 후기를 만들지 않는다.

## 3) 짧은 소식 (플레이스·당근·카카오)

원본을 3~5줄로 줄이고, 원본(블로그) 링크를 달 수 있으면 단다. 가장 안전한 재사용 방식이다. 문구 틀·예시는 `guides/make/local-posts.md`를 따른다. 여기서는 언제 무엇을 만드는지만 정한다.

| 곳 | 무엇을 | 규격·제한 | 올리는 길 |
|---|---|---|---|
| 스마트플레이스 새소식 | 블로그 핵심 3~5줄 + 사진 1~3장 | 예약 기능 없음(으로 설계) | 사장님 폰 앱 붙여넣기 기본 |
| 당근 비즈프로필 소식 | 동네 이웃 말투 3~5줄 + 사진 | 사진 최대 20장, 영상 1개(1분·200MB 이하). 예약 없음 | 폰 붙여넣기 또는 브라우저 |
| 당근 스토리 | 숏폼 원본을 5~60초로 | 설명 1,000자 이하, 가까운 이웃에게 먼저 노출 | 당근 앱 |
| 카카오톡 채널 소식 | 단골 공지용(시즌·주문·휴무) + 블로그 링크 | 예약 발행 가능 | 에이전트 브라우저 → 관리자센터 [소식] 예약 |

카카오 채널 **메시지**(친구에게 발송)는 유료다(건당 15·20원, 2026-11 확인, 바뀔 수 있음 — 발송 전 관리자센터에서 확인). 에이전트는 초안만 만들고 발송은 사장님이 한다.

## 4) 발행 순서·시간차 (스킬 기준, 공식 수치 아님)

| 때 | 올릴 것 | 이유 |
|---|---|---|
| D0 | 네이버 블로그 원본 | 먼저 올린 글이 원본 |
| D0 (블로그 뒤) | 스마트플레이스 새소식, 카카오 채널 소식 | 블로그 링크가 생긴 뒤 |
| D0~D1 | 네이버 클립(콘텐츠 링크로 블로그 연결), 인스타 캐러셀·릴스 | 클립은 블로그가 있어야 연결 가능 |
| D1 | 쇼츠, 페이스북, 스레드, 틱톡, 당근 | 동시·시간차의 공식 차이는 없음. 사장님 손을 나누려고 하루에 몰지 않음 |
| D1 이후(노출 확인 + 24시간) | 티스토리·브런치 재작성 | 원본 노출 확인 뒤 |
| 다음 주 | 핀터레스트·링크드인·유튜브 게시물 | 확장 채널일 때만 |

- 하루 게시 상한은 `guides/upload/index.md`의 공통 수치 표를 따른다. 네이버는 빨리 많이 올리면 보안문자가 뜬다.
- 만들 양은 `guides/04-weekly.md` ①에서 한 번 승인받았다. 여기서 다시 묻지 않는다(양이 늘 때만 ⑤).

