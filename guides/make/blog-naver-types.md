# 네이버 블로그 유형별 구조 템플릿 (B01~B13)

`guides/make/blog-naver.md` 3단계에서 고른 유형의 줄만 본다. 수치는 사장님 블로그 471편에서 다시 계산한 값을 기본값으로 정리한 것이다. 글자 수는 공백 제외.

## 공통 규칙

1. **소제목은 인용구 블록**으로 만든다. 실제 사장님 글의 인용구 75%가 짧은 제목형 문구였다. 소제목 기능은 안 써도 된다.
2. **지도 블록**(네이버 플레이스)은 기본으로 넣는다. 빼는 유형: B06 일기, B10 가격 안내(필요할 때만).
3. **마지막 20%**에 문의 방법 하나를 넣는다(문의·예약·주문·카톡 중 하나). 전화번호는 B08·B10·B13에서만 기본으로.
4. 지역 키워드는 제목에 한 번만.
5. 첫 문단 3문장 안에 "누가, 언제, 어떤 상황"이 나온다.
6. 사장님이 직접 겪은 장면·숫자·실패를 한 군데 이상 넣는다. 없으면 사장님께 묻는다(지어내지 않는다).
7. 분량·사진 수는 **권장**이다. 소재가 모자라면 분량을 맞추려고 지어내지 않는다. 짧게 내고 필요한 소재를 구체적으로 부탁한다("크루아상 굽는 시간과 처음 실패했던 일 한 가지만 알려 주세요").
8. B04 전후 옵션: 반영구는 쓰지 않는다. 의료·한의원·치과는 기본값 '권하지 않음'. 복지부 가이드라인 Q3의 5조건과 사전심의를 모두 갖출 때만 가능하다(`guides/compliance/medical.md` 점검표). AI로 만들거나 보정한 전후사진은 금지.

## 템플릿 표

| 코드 | 구조(이 순서로) | 분량 · 사진 | 꼭 지킬 것 |
|---|---|---|---|
| B01 정보 칼럼 | 인사·자기소개 → 손님이 겪는 상황 1~2문장 → **결론 한 줄** → 인용구 소제목 2~4개 → 항목별 설명(표 1개 권장) → 3줄 정리 → 상담 안내 + 지도 | 1,400~2,200자 · 사진 5~10장(개념도·현장) | 근거 없는 수치 금지. 병의원은 효과 단정 금지. **하위 '시장·제도 해설'**: 2,500~3,500자, 출처·기준일 필수 |
| B02 Q&A | B01과 같은 뼈대. **제목 = 질문 하나**. 첫 문단에 "상담하다 보면 자주 듣는 질문" + **답 먼저** → 경우별 설명을 인용구 소제목 4~6개로 → 정리 → 상담 + 지도 | 1,600~2,500자 · 사진 5~11장 | 한 글에 질문 하나. 같은 틀로 여러 편 찍어 내지 않는다 |
| B03 비교 가이드 | 고민 상황 → 체크리스트 N개(인용구 번호 소제목 3~5개) → **비교 표** → "저희는 이렇게 합니다" → 상담 | 1,550~2,200자 · 사진 5~13장. 첫 사진을 빨리(첫 사진 앞 50자 안팎) | 병의원·식품·변호사: 다른 업체를 깎는 비교 금지, 손님이 확인할 '기준'만 |
| B04 작업 사례 | 현장·손님 상황(평수·이력·인원·날짜) → 고민 포인트 → 과정 "사진 1~3장 + 짧은 설명" 반복 → 완성 → 자재·약제·가격 범위 → 문의. **옵션 '전후 비교'**: 같은 각도 전·후 사진을 나란히 + 유지 관리 팁으로 마무리 | 1,250~2,100자 · 사진 **인테리어 15~25장, 그 외 8~14장** | 손님 동의, 주소 동·호수 가림. 가격은 사장님이 준 범위만. 반영구는 전후 옵션 잠금. 의료는 5조건 점검표 통과 때만 |
| B05 고객 변화 이야기 | "※ 손님 동의를 받았고, 개인정보 보호를 위해 가명을 썼어요" → 처음 상태와 고민 → 기간·횟수 → 지금 모습 → 손님 한마디(직접 받은 문장만) → 안내 + 지도 | 1,000~2,000자 · 사진 8~20장 | **병의원 사용 불가.** 헬스·필라테스·피부관리는 질환명·'치료·개선' 금지 → 자세·체력·생활 변화로 |
| B06 사장님 일기 | 인사 없이 장면부터 → 시간순 이야기 → 숫자나 실패담 하나 → 느낀 점 → 한 줄 근황·영업 안내. 연재 번호 권장(#5) | 700~2,000자 · 사진 3~18장(0장도 됨), 영상 있으면 넣음 | 소제목 없음. 숫자는 사장님이 말한 것만. 손님 사진은 동의 필수 |
| B07 가게 소식·실적 | 제목 "○월 소식" 또는 "[소식] ○○ 선정·납품" → 소식 2~4개를 인용구 소제목으로 → 사진 → 다음 달 일정 → 문의 | 800~1,800자 · 사진 6~20장 | 수상·인증은 **발급 기관 이름**을 쓴다. 병의원 사용 불가(정부·공공 인증 예외는 확인 필요). 학원 합격 소식은 실명·성적 동의, 과장 금지 |
| B08 이벤트·공지·모집 | 인사 → 핵심 한 줄(기간·혜택·대상, 첫 사진 전에) → 상세 조건 표나 목록 → 신청·문의(전화 포함). 하위 틀: **휴무 공지**(300~500자, 사진 1장), **감사 인사**(500~900자) | 800~1,500자 · 사진 2~14장 | **학원: 교습비·등록번호 필수.** 병의원: 비급여 할인 표현 제한. 리뷰 조건 혜택 금지 |
| B09 신메뉴·신상품 | 인사 → 출시 한 줄 → 메뉴마다 "사진 + 맛·재료·가격 2~4줄" 반복 → 판매 기간 → 주문·예약 + 지도 | 600~1,500자 · 사진 5~12장 | 식품 효능 단어 금지(질병·증상명, '면역', '디톡스' 등) |
| B10 가격·주문·이용 안내 | 누구에게 맞는지 → 구성·가격(**글이나 표로**, 이미지만 쓰지 않음) → 주문 순서 1·2·3 → 픽업·배송·마감 → 주문 링크·카톡. 하위 틀: **자주 묻는 질문 모음**(질문 5~8개를 인용구로), **단체·납품 안내**(최소 수량·준비 기간·샘플) | 900~1,900자 · 사진 5~16장 | 가격 기준일 표시("2026년 11월 기준"). 프로필 고정 글로 쓰라고 안내 |
| B11 가게·사람·만드는 방식 소개 | 인사 → 만든 이유·철학 → 공간·사람·**만드는 과정(재료·시간)**을 사진 흐름으로 → 위치·주차·영업시간 → 예약 + 지도 | 1,100~2,100자 · 사진 3~16장(숙박은 20장 이상) | 병의원 원장 인터뷰는 비교·비방 금지. 식품 공정 글은 효능 금지. '수제·무방부제·국내산'은 사실 근거가 있을 때만 |
| B12 시즌·선물 | 시즌 도입 → 세트 구성(사진 많이) → 가격·**예약 마감일(요일 포함)** → 픽업·택배 → 예약 링크. 마감 뒤 제목 앞에 [마감] | 850~3,000자 · 사진 6~30장 | 검색용이 아니라 **단골 공지용**. 프로필 고정 + 카카오 채널 공유를 함께 권한다. 식품 효능 금지 |
| B13 매물 소개 | 중개사무소 정보(명칭·소재지·연락처·**등록번호**·개업공인중개사 성명) → 매물 요약 → **필수 항목 표**(소재지·면적·가격·종류·거래 형태·총층수·사용승인일·방향·방/욕실 수·입주가능일·주차대수·관리비) → 실사 사진 → 입지 설명 → 연락처 + 지도 | 1,100~1,550자 · 사진 9~24장 | 표에 빈칸이 있으면 발행하지 않는다. **중개보조원 이름 금지.** 매물 사진은 실사만. AI 이미지는 대표 이미지에만, 표시 필수 |

빈 값은 지어내지 말고 `[직접 입력: 예) 예약 마감일]`로 둔다.
