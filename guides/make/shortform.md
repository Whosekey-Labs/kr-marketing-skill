# 숏폼 만들기 (릴스·쇼츠·클립·틱톡 공통 원본)

소재 1개로 세로 숏폼 원본 1개를 만든다. 원본은 **워터마크 없는 파일 하나**이고, 플랫폼마다 이 파일을 따로 올린다. 다른 앱에서 내려받은 파일(로고가 박힌 것)은 절대 다시 올리지 않는다.

## 1) 입력 (모자라면 이것만 묻는다)

| 입력 | 어디서 | 없으면 |
|---|---|---|
| 소재 | 이번 주 계획(`guides/04-weekly.md`) 또는 사장님 말 | "이번 주에 손님께 보여 주고 싶은 것 하나만 말씀해 주세요" |
| 사진·클립 | **실제 촬영**(사장님·직원·동의한 손님, 세로) | 세 단계 요청(`guides/04-weekly.md` ②, 업종 목록 `guides/make/shot-lists.md`). **사진만 와도 만든다**(사진형). 설명·배경 장면만 누가 봐도 그림인 생성 그림으로(5절) |
| 사실 | 가격·기간·수량·주소 | `[직접 입력: …]`. 짐작해서 채우지 않는다 |
| 카드·편집 느낌 | `guides/styles/shortform.md` 3절(목적 → 가진 재료 → 카드) | 사진만 있으면 G3·G4·G2·G5 중 하나 + '잔잔하게'. 재료 분류(P1~P7)는 올린 재료를 보고 에이전트가 정한다 |
| 브랜드 프로필 | 말투, 금지 표현(색은 이 파일 3절에서 정한다) | 브랜드 프로필이 없으면 최소 프로필(업종·규제 플래그·말투 한 줄·금지 표현·사실 자료)만 만들고 바로 제작한다(`guides/00-start.md` 중간 요청 규칙) |

## 2) 고정 규격 (바꾸지 않는다)

| 항목 | 값 | 근거 |
|---|---|---|
| 크기 | 1080×1920 세로, 30fps, H.264 mp4 | 각 플랫폼 업로드 규격 [공식] |
| 길이 | 담을 내용만큼. 기본 **15~45초**, 사장님 이야기·정보형 **30~90초**, 반복 재생 노리는 비주얼형만 10~15초. **90초 이하**(5개 플랫폼 공통 최대). 길이보다 끝까지 보게 하는 구성이 먼저 | 상한: 페이스북 릴스 API 3~90초 [공식]. 기본값: 2026 릴스 표본 Buffer 273만·Socialinsider 977만에서 30초 미만이 가장 약했다. 단 차이는 한 자릿수 %로 작다 [조사 09b] |
| 원본 소리 | 클립 소리는 **기본 끔**. 소리가 내용일 때(굽는 소리·조리음·사장님 말)만 살린다 | 현업 편집 순서 [조사 09] |
| 자막 안전 영역 | 위 270px · 아래 670px · 왼쪽 65px · 오른쪽 190px 비움 → 글자는 **x 65~890, y 270~1250** 안. HyperFrames 템플릿은 틱톡까지 맞춰 **x 120~890, y 288~1248** | 위 14%·아래 35%·양옆 6%는 Meta 릴스 광고 가이드 [공식]. 오른쪽 190px(버튼 열)과 쇼츠·틱톡·클립 적용은 [추정] |
| 훅 문구 위치 | y 300~500 | [추정] |
| 자막 기준선 | y 1150~1250 | [추정] |
| 워터마크·로고 | 넣지 않는다. 가게 이름은 마지막 장면에 글자로 | 인스타 추천 조건 "no visible watermarks", 클립 "타 플랫폼 워터마크" 불인정 [공식] |
| 음원 | 원본에는 넣지 않는다(직접 녹음한 소리·저작권 없는 효과음만). 음악은 올릴 때 각 앱의 상업용 라이브러리에서 | 8절 |

## 3) 레퍼런스 3~5개 → 디자인 문법 → 시안 2안

디자인은 사장님 홈페이지·로고 색을 기본으로 따라가지 않는다. **같은 업종에서 반응이 좋은 숏폼**의 문법을 먼저 뽑는다.

1. 같은 업종 숏폼 3~5개를 고른다(그 계정 평소 영상보다 반응이 뚜렷이 좋은 것). 이번 주 기획(`guides/04-weekly.md`)에 레퍼런스가 있으면 그것을 쓰고 모자란 만큼만 더 찾는다. 못 본 수치는 '확인 못 함'으로 적는다.
2. 아래 표를 채운다(생각용, 사장님께는 한 줄 요약만).

| 항목 | 영상 1 | 영상 2 | 영상 3 | 공통 문법 |
|---|---|---|---|---|
| 0~3초 화면·첫 글자 | | | | |
| 위계(제목·자막·이름표 중 무엇이 가장 큰가) | | | | |
| 여백(글자 주변이 빈가, 꽉 찼나) | | | | |
| 사진 비중(화면을 사진이 얼마나 채우나) | | | | |
| 글자 크기(제목·자막) | | | | |
| 색 쓰는 법(바탕·글자·강조 몇 색, 어디에) | | | | |
| 컷 수·장면 길이·소리 | | | | |
| 마지막 행동 안내 | | | | |

3. '공통 문법'을 사장님이 고른 갤러리 카드(G1~G9)와 편집 느낌에 합쳐 디자인을 정한다. 강조색도 레퍼런스 문법에서 정한다.
4. 묻지 않고 **시안 2안을 만든다**(첫 정식 제작 때. 중간부터 요청받은 첫 결과물은 1안만 만들고 2안은 다음에 제안 — `guides/07-design-kit.md` 1)). 첫 장면 3초를 두 가지로 만들어 한 장씩 뽑거나(HyperFrames `snapshot --at 1`, ffmpeg 경로는 `shortform.py frames out.mp4 --at 1`), 못 만들면 색 견본과 글로 설명한다.
   - 1안(A안) 레퍼런스안: 레퍼런스 문법 그대로(정보형이면 정보 카드 템플릿·`theme: "info"`, 가게 일상이면 시간 자막 루틴·쇼케이스·`theme: "warm"`). **고르기 전 기본.**
   - 2안(B안) 기존 색 살린 안: 같은 문법에 기존 가게 색(간판·로고 색)을 강조색으로 얹음(HyperFrames `--accent`, ffmpeg `highlight_color`). 기존 색이 없으면 같은 성격 카드의 다른 스타일 후보.
   - 말 예: "두 가지로 만들어 봤어요. 1번은 요즘 반응 좋은 빵집 영상 방식, 2번은 가게 간판 색을 살린 안이에요. 1번/2번, 번호만 알려 주세요. 안 고르시면 1번으로 갈게요."
5. 답이 없으면 1안으로 저장한다. 밝은 브랜드 색은 면(띠·박스)으로만 쓰고, 강조 글자는 같은 계열 진한 색으로 한다(4.5:1). 고른 결과는 브랜드 프로필 디자인 키트에 적어 다음에도 쓴다.

문장·화면·음원은 가져오지 않는다(구조만 빌린다). 팔로워가 많아서 나온 조회수는 분석하지 않는다. 다른 계정에 붙은 'AI 생성' 표시는 화면과 안 맞는 경우가 많으니 믿지 않는다.

## 4) 대본

```
[훅 0~3초] 화면: (첫 장면)  글자: (두 줄, 줄마다 8~12자)  말: (있으면 한 문장)
[본론]     장면마다 한 줄 — 무엇을 보여 주고 무슨 자막을 넣나
[마무리]   행동 하나: 위치 / 예약 / 댓글 / 저장 중 하나만 (없어도 됨)
```

1. 훅은 `guides/styles/shortform.md` 7절에서 고른다. **첫 3초 안에 무엇에 관한 영상인지와 가장 강한 장면**을 보여 준다(틱톡 광고 도움말: 핵심은 첫 3초, 훅은 6초 안). 첫 장면은 **움직임이 가장 큰 컷 또는 결과물**. 없으면 가장 좋은 구간을 복제해 맨 앞에 둔다.
   - 훅 다음부터 끝까지 위쪽에 **고정 훅 제목 1줄**(`fixed_title`)을 기본으로 둔다(정보형 위 띠만 2줄까지).
2. 숫자를 쓰면 다음 장면에서 근거를 보여 준다.
3. 자막은 **1초에 7자 이하**, 한 장면 두 줄까지.
4. 사장님 말투(브랜드 프로필)로 쓴다. 과장·"무조건" 금지.
5. 경험담은 사장님이 말한 것만. AI 가상인물이 나오면 경험담을 말하게 하지 않는다.
6. 거부감 부르는 표현("AI 직원", "딸깍", "알아서", "100% 자동", "무조건 상위노출" 등, SKILL.md 규칙 12)은 쓰지 않는다(`guides/compliance/common.md`). 단 공식 상호·상품명이면 SKILL.md 규칙 12대로 처음 한 번 묻고 프로필 '내 요청사항'의 답을 따른다.
7. **화면 글자에 작업용 이름을 쓰지 않는다.** `fixed_title`·`title`·`caption`·`hook`에 "마지막", "사진 1", "장면 3", "훅", "본론" 같은 내부 표시를 넣지 않는다. 장면 이름은 `"_note"` 칸에 적는다. 제목 칸이 필요 없으면 비운다.
8. 첫 장면 훅은 이번 소재의 **지금 올 이유**(`guides/04-weekly.md` ③-1)를 담는다. 같은 소재 카드뉴스 표지와 같은 훅 문구를 쓴다.
9. **글자와 사진이 같은 것을 가리킨다.** 훅·자막·제목이 말하는 대상(예: "겨울 타르트")이 그 장면 사진에 없으면(사진은 공간·다른 메뉴) 둘 중 하나: ① 그 장면을 `"_note": "사진 필요: 겨울 타르트 단면"`으로 두고 사장님께 그 사진을 요청 ② 문구를 화면에 보이는 사실로 바꾼다(공간 사진이면 "12월 1일부터 성수에서"처럼 날짜·장소만). 다른 메뉴 사진에 새 메뉴 이름을 붙이지 않는다.
10. **남의 상표가 보이는 사진은 뺀다.** 다른 가게·브랜드 로고, 포장지·컵 상표, 간판, 앱 워터마크가 읽히는 사진은 쓰지 않는다(자르기로 완전히 안 보이게 할 수 있을 때만 자른다). 렌더 뒤 장면마다 한 번 더 눈으로 본다.

## 5) 장면표

장면표 위에 `빌린 것: 레퍼런스 A의 ○○(구조), B의 ○○(훅 틀)` 한 줄을 먼저 적는다(빌린 게 없으면 만들지 않는다, `guides/04-weekly.md` ⑥). 고른 카드에 맞는 템플릿 JSON을 하나 골라 채운다: `guides/make/shortform-scenes.md`(공통 규칙·키 설명·T1 전후·T2 쇼케이스·T3 가게 구경), `guides/make/shortform-scenes-2.md`(T4 정보 카드·T5 만드는 과정·T6 오늘 하루·T7 가게 이야기). 사장님께는 아래 표 모양으로 보여 준다.

| # | 소재(사장님 클립/사진) | 길이 | 위 글자(훅·꼬리표) | 아래 자막 | 소리 |
|---|---|---|---|---|---|
| 1 | 완성된 소금빵 단면 클로즈업(사진) | 3초 | 훅: 오픈 전 *2시간* | 빵집 사장의 아침 | 없음 |
| 2 | 반죽 꺼내는 손(클립 5초) | 3.5초 | 꼬리표: 07:10 | 반죽 꺼내기 | 현장음 |
| … | | | | | |

- 컷 길이는 박자 기준이다(현업 0.7~3초). 음원은 올릴 때 앱에서 붙이므로 **0.5초 배수**로 둔다(120BPM이면 1박 = 0.5초).

| 편집 느낌 | 클립 컷 | 사진 장면 | 박자 |
|---|---|---|---|
| 빠르고 신나게 | 0.7~1.5초 | 2~2.5초 | 2~3박마다 컷 |
| 정보 또박또박 | 1.5~3초(자막 1초 7자 다 읽히게) | 2.5~3초 | 4박 안팎 |
| 잔잔하게 | 2~3초 | 3~3.5초(천천히 확대) | 4~6박 |

- 말이 있는 클립은 박자보다 문장 단위로 자른다. 합계는 2절 길이 기본값. 재료가 모자라면 장면을 지어내지 말고 짧게 만든 뒤, 더 필요한 재료를 구체적으로 요청한다(예: "진열대 전체 세로 사진 1장, 오븐 여는 손 5초").
- **찍을 것을 요청할 때**는 장면표의 소재 칸을 그대로 보낸다. 예: "내일 오픈 전에 ① 반죽 꺼내는 손 5초 ② 오븐 문 여는 장면 5초 ③ 진열대 전체 사진 1장, 모두 **세로로**, 손만 나와도 돼요."
- 손님·직원 얼굴이 나오면 동의 받은 것만 쓴다. 아이 얼굴은 쓰지 않는다.
- **그림 장면은 네 이미지 생성 기능으로**(0단계에서 '있음'일 때): 훅 배경, 정보형(T4) 설명 장면, 과정·상황 연출, 질감 바탕을 1080×1920 그림으로 만들어 장면 `photo`로 넣는다(`fit: cover`, `zoom`). **장면 3개까지**, 같은 스타일 문장으로 그림체를 맞추고, 글자는 그림에 넣지 않고 `caption`·`title`·`hook`으로 쓴다(프롬프트 틀·금지: `guides/make/image-gen.md`). 가게 일상·상품 소개(T2·T3·T5·T6)는 사장님 사진·영상이 주인공이고 그림은 1~2장면 보조로만. 기능이 없으면 글자 카드 장면 + 사장님 사진.
- 실제 매장·상품·사람처럼 보이는 AI 사진·영상, 실제 상품 대신 AI 상품 장면은 만들지 않는다. 2026년 광고 업계는 AI 영상을 널리 쓰지만, 사람이 만든 광고가 단기 14%·장기 17% 더 강했다는 독립 조사(Ipsos·시러큐스대, 2026-07)가 있고, 실제 가게·음식처럼 보이면 손님을 속일 위험이 있다. 누가 봐도 그림(일러스트·캐릭터·무늬)만 쓴다. AI 인물을 쓰면 나오는 동안 인물 옆에 "가상인물" 글자를 넣고 경험담은 말하게 하지 않는다(공정거래위원회 추천·보증 심사지침, 2026-06-01).
- 의료 업종의 치료 전후 사진은 기본값 '권하지 않음'. 가림·동의만으로는 부족하고 5조건+사전심의가 필요하다(`guides/compliance/medical.md`). AI로 만들거나 보정한 것은 금지.

## 6) 조립 (세 갈래 중 되는 것 하나, 처음 한 번 정하고 기억한다)

1. **HyperFrames**: Node 22+·ffmpeg·크롬(헤드리스)이 있으면. 설치 확인 명령 4줄, 템플릿 4개(시간 자막 루틴·정보 카드·쇼케이스·전후), 장면표 → HyperFrames 매핑, 점검·렌더는 `guides/make/shortform-hyperframes.md`.
2. **`tools/shortform.py`(ffmpeg)**: Node·크롬이 없고 파이썬·ffmpeg는 될 때. `guides/make/shortform-ffmpeg.md`.
3. **장면표 + 캡컷 안내**: 영상을 만들 수 없을 때. 아래 '대체 경로'.

**두 렌더러는 같은 장면표(5절)를 읽는다.** 길·도구가 바뀌어도 장면표는 고치지 않는다. 피클 같은 사장님용 환경에 Node·크롬이 있는지는 짐작하지 말고 그 자리에서 확인 명령으로 본다(실기 시험에서 확인 예정). 만든 뒤 장면마다 한 장씩 뽑은 시트를 직접 열어 글자 크기·위치·가독성을 보고 고친다.

기본 산출물은 **완성 영상 1개 + 플랫폼별 문구**다. **캡컷 키트는 사장님이 "직접 손보고 싶다"고 할 때만**: 순서·이름 붙인 클립(`01_첫장면_빵가르기.mp4` …), 자막 `.srt`(PC 캡컷 '캡션 가져오기'로 넣는다. 모바일 캡컷은 확인 못 함), 훅 제목 문구, 컷 길이표.

### 대체 경로 (영상을 만들 수 없는 에이전트)

사장님께 **장면표 + 자막 문구 + 대본**을 드리고, 캡컷 같은 무료 앱으로 조립하게 안내한다.

1. "캡컷 앱을 열고 '새 프로젝트'에서 장면표 순서대로 사진·영상을 고르세요."
2. "비율을 9:16으로 맞추세요."
3. "장면마다 길이를 장면표대로 맞추세요(사진을 길게 눌러 끝을 끌면 돼요)."
4. "'텍스트'로 자막을 넣으세요. 화면 **가운데보다 조금 아래**, 오른쪽 끝과 맨 아래는 비워 두세요(좋아요 버튼·계정 이름이 가려요)."
5. "첫 장면 위쪽에 큰 글씨로 '[훅 문구]'를 넣고, 그 글자를 영상 끝까지 늘려 두세요."
6. "영상 원래 소리는 끄고(소리가 중요한 장면만 살려요), 음악은 넣지 말고 저장하세요. 음악은 올리는 앱에서 고를게요."
7. "끝에 붙는 앱 로고(엔딩)는 지우고 저장하세요."
8. 템플릿을 쓰면: 템플릿 음악은 끄고, 로고가 남지 않는지 확인한다.
