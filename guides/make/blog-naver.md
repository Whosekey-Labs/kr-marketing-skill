# 네이버 블로그 글 만들기

소재 1개로 네이버 블로그 원본 글 1편을 만든다. 네이버 블로그가 원본 채널이다(먼저 올린 글이 원본으로 인정된다). 다른 플랫폼 버전은 이 글을 올린 뒤 `guides/make/repurpose.md`로 만든다.

## 1) 입력 (모자라면 이것만 묻는다)

| 입력 | 어디서 | 없으면 |
|---|---|---|
| 소재 | 이번 주 계획(`guides/04-weekly.md`) 또는 사장님 말 | "이번 주에 손님께 알리고 싶은 것 하나만 말씀해 주세요" |
| 사진 | 사장님이 이번에 새로 찍은 사진 | 유형별 사진 수를 알려 주고 찍을 컷을 구체적으로 요청 ("내일 오픈 전 크루아상 단면 3장, 진열대 1장") |
| 사실 | 가격·기간·수량·영업시간·주소 | `[직접 입력: …]`로 비워 둔다. 짐작해서 채우지 않는다 |
| 사장님 경험 | 이번 소재에 얽힌 장면·숫자·실패 한 가지 | 한 가지만 묻는다: "이거 만들면서 제일 애먹은 점이 뭐였어요?" |
| 브랜드 프로필 | 말투(V1~V5), 금지 표현, 내 요청사항 | 브랜드 프로필이 없으면 최소 프로필(업종·규제 플래그·말투 한 줄·금지 표현·사실 자료)만 만들고 바로 제작한다(`guides/00-start.md` 중간 요청 규칙) |
| 레퍼런스 분석 | 이번 주 기획(`guides/04-weekly.md` ③)의 레퍼런스 한 세트(장부 재사용 + 이번 소재용 1~2개)를 그대로 쓴다. 소재마다 새로 찾지 않는다 | 세트에 블로그 구조용이 없을 때만 1편 더 찾아 4단계 표대로 분석한다. 글 끝 메모에 `빌린 것: 레퍼런스 A의 ○○(구조), B의 ○○(훅 틀)` 한 줄(빌린 게 없으면 쓰지 않는다) |

## 2) 하루 1편 원칙

- 네이버 블로그는 하루 게시 수가 제한되고, 빨리 많이 올리면 보안문자(캡차)가 뜬다(네이버 도움말: "천천히 글을 등록하길 권합니다"). **한 계정에 하루 1편까지만** 만든다.
- 여러 가게 글을 같은 틀로 찍어 내지 않는다. 네이버는 "문장 일부만 바꾼 템플릿 글 대량 발행"을 스팸으로 본다(2026-07-06).

## 3) 유형과 문체 정하기

1. 유형: `guides/styles/blog.md` 2절 업종 표에서 고른다. 사장님이 고른 게 있으면 그대로.
2. 막힌 유형인지 같은 파일 3절에서 확인한다.
3. 구조: `guides/make/blog-naver-types.md`에서 그 유형 줄만 본다.
4. 문체: 브랜드 프로필의 프리셋(V1~V5)을 쓴다.

## 4) 레퍼런스 분석 (구조만 빌린다)

잘 쓴 글 2편을 열어 아래 표를 채운다(생각용, 사장님께는 한 줄 요약만).

| 항목 | 글 1 | 글 2 | 우리 글 |
|---|---|---|---|
| 제목 틀 | | | |
| 첫 3문장이 하는 일 | | | |
| 소제목 수·순서 | | | |
| 사진 수·첫 사진 위치 | | | |
| 사장님 경험이 나오는 곳 | | | |
| 마무리 행동 안내 | | | |

문장·사진·사례는 가져오지 않는다. 구조만 빌리고 표현은 우리 것으로 쓴다.

## 5) 제목 규칙

1. 25~35자 안쪽(스킬 기준값). 지역 키워드는 **한 번만**.
   - **검색어를 제목 앞 15자 안에.** 조사에서 순위를 잰 검색어(`guides/01-research.md` 4)) 1개, 없으면 손님이 실제로 칠 말(리뷰·손님 말)을 넣고, 같은 말을 태그 첫 번째에 둔다. 매장 없는 업종(07·23·24·25)도 같다 — 지역 대신 그 검색어. 소식형 제목도 검색어를 앞에: "소상공인 마케팅 자동화, 무료 지침 이번 달 공개". 아무도 검색하지 않는 우리 쪽 말("마케팅 지침")로 시작하지 않는다.
2. **"지역+업종, ~할까요?" 틀을 기본으로 쓰지 않는다.** 대행사 템플릿으로 퍼진 틀이다(표본 제목 29%). 같은 틀 반복은 네이버 스팸 사례에 해당한다.
3. 실제 상황을 담는다: 지역 + 상품·업종 + 구체 상황. 예: "망원동 빵집 토요일 아침 7시, 크루아상 첫 판 굽는 날".
4. 낚시성 제목 금지(본문에 없는 내용, 과장, "무조건").
5. 실제 상호·메뉴 이름을 쓴다. 검색량 많은 다른 말로 바꿔 쓰지 않는다.
6. 최근 제목 5개와 같은 틀이면 바꾼다.

## 6) 네이버 공식 작성 가이드 5원칙 (2026-05-26) → 이렇게 지킨다

| 원칙 | 할 일 |
|---|---|
| ① 직접 경험 | 사장님 장면·숫자·실패를 1곳 이상. 공식 자료를 인용하면 출처 |
| ② 한 주제 | 한 글에 소재 하나. 블로그 글 대부분이 가게 주제 안에 있게 |
| ③ 진정성 | 협찬·제공받은 것이 있으면 글 맨 위에 한눈에 표시. 인용하면 원문 링크 |
| ④ 읽기 쉬운 구조 | 인용구 소제목, 짧은 문단(2~4줄). **사진 속 핵심 정보(가격·기간·메뉴판)는 글로도 쓴다** |
| ⑤ 최신 정보 | 가격·기간에 기준일. 바뀌면 원래 글을 고친다(새 글을 또 쓰지 않음) |

피할 것: 복제·짜깁기, 과도한 광고 문구, 외부 링크 여러 개, 글과 상관없는 키워드·사진.

## 7) 사진 처리

1. **이번 글을 위해 새로 찍은 사진**을 쓴다. 예전 글과 같은 사진이 많으면 유사문서로 묶일 수 있다.
2. 사진 순서와 위치는 유형 템플릿을 따른다. 사진마다 한 줄 설명을 붙인다.
3. 장당 10MB 이하. PC 편집기 기본 폭은 700px.
4. 다른 앱 로고·워터마크가 박힌 사진(캡처 포함)은 쓰지 않는다.
5. 손님 얼굴·이름은 동의 없이 쓰지 않는다. 동의 없으면 가린다(의료 전후사진은 아래 7번).
6. 실제 매장·음식·상품·사람처럼 보이는 AI 이미지는 쓰지 않는다(실제처럼 오해할 수 있으면 금지). 누가 봐도 그림인 것(일러스트·아이콘·패턴 배경)은 장식용으로만 쓰고, 사진 아래 "이해를 돕기 위한 AI 생성 그림"을 적고 8)의 'AI 활용' 표시를 켠다.
7. 의료(의원·치과·한의원) 전후사진은 기본값 '권하지 않음'. 가림·동의만으로는 부족하고, 복지부 가이드라인 Q3의 5조건과 사전심의를 모두 갖춰야 한다(`guides/compliance/medical.md` 점검표). AI로 만들거나 보정한 전후사진은 금지.

## 8) 태그 · 'AI 활용' 표시 · 사업자 정보

- **태그**: 3~7개(스킬 기준값). 블로그 **태그**(글 아래 태그 칸)는 SNS **해시태그**(인스타·쇼츠 등 5개 이하, `guides/make/repurpose.md`)와 다른 것이다. 블로그는 3~7개로 쓴다. 상호, 지역(동 단위 1개), 상품명, 유형 말(예: 신메뉴). 글과 상관없는 인기 키워드는 넣지 않는다.
- **'AI 활용' 표시**: 네이버는 AI로 생성·편집한 이미지·영상이 들어간 글에 작성자가 'AI 활용' 표시를 직접 켜기를 **권장**한다(블로그·카페·클립). 사진이 모두 사장님 실사이고 글만 함께 다듬었으면 켜지 않아도 된다. AI 이미지·영상이 하나라도 있으면 켜라고 안내한다.
- 판매 글(주문·결제를 받는 글)이면 사업자 정보 표시 기능을 확인하라고 안내한다(확인 필요).

## 9) 출력 형식 (에디터에 넣기 쉬운 순서표)

아래 형식 그대로 준다. 기호는 에디터에서 바꿀 자리 표시다.

```
제목: …
태그: #상호 #망원동빵집 #크루아상 …
AI 활용 표시: 켬 / 끔 (이유 한 줄)
---
[사진1: 대표 사진 — 크루아상 단면 클로즈업]
본문 문단…
[인용구] 소제목 문구 [/인용구]
본문 문단… **굵게 할 말**은 별표 두 개로.
[사진2: …] [사진3: …]   ← 사진 여러 장을 한 자리에
[표] 항목 | 내용 … [/표]
[구분선]
[지도: 상호명]
---
사진 순서표: 1=단면, 2=진열대, 3=… (파일명과 짝지어 줌)
빈칸: [직접 입력: …] 목록
```

- 본문은 서식이 없어도 읽히게 쓴다(폰 앱에 붙여 넣으면 서식이 빠질 수 있다).
- 올리는 방법은 사장님 폰 붙여넣기 묶음 하나다(`guides/upload/naver-blog.md`). 이 순서표를 묶음 블록으로 바꾸는 법은 `guides/upload/index.md` 6).

## 10) 발행 뒤 노출 확인

1. 올린 지 24시간 안에 확인한다(네이버 도움말: 보통 24시간 안에 노출).
2. 네이버 블로그 탭에서 **제목을 큰따옴표로 묶어** 검색한다. 안 나오면 본문 한 문장을 큰따옴표로 검색하고 '유사문서 포함'을 켠다.
3. 결과를 기록한다: 날짜, 노출 여부, 순위(보이면). 이 확인이 끝나야 티스토리 재작성(`guides/make/blog-tistory.md`)을 시작한다.
4. 안 나오면 사장님께: "글이 아직 검색에 안 보여요. 하루 더 보고, 그래도 없으면 네이버 '검색 노출 제보하기'로 알릴게요(결과는 보장되지 않아요)."

## 11) 자가 점검표 (모두 예여야 보여 준다)

| # | 점검 | 예/아니오 |
|---|---|---|
| 1 | 제목 앞 15자에 순위 잰 검색어(또는 손님이 칠 말) — 매장 없는 업종도 동일, 태그 첫 번째도 그 말. 지역 키워드는 1번만, "지역+업종, ~할까요?" 틀 아님, 최근 제목과 틀이 다름 | |
| 2 | 첫 3문장에 누가·언제·어떤 상황 | |
| 3 | 사장님 실제 경험(장면·숫자·실패) 1곳 이상, 지어낸 것 없음 | |
| 4 | 가격·기간·영업시간은 사장님 자료와 같음, 모르는 건 `[직접 입력]` | |
| 5 | 유형 템플릿의 분량·사진 수 범위 안(권장 — 모자라면 지어내지 않고 소재 요청) | |
