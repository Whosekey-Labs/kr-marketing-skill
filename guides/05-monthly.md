# 5. 4주 회고 (월 1회)

목표: 4주 동안의 숫자로 실험을 판정하고, 채널 등급과 계획 크기를 고치고, 다음 4주를 정한다. 결과는 1장 리포트로 사장님 문서에 남긴다.

## 1) 숫자 모으기

| 무엇 | 어디서 | 누가 |
|---|---|---|
| 플레이스 통계(유입·길찾기·전화·저장·예약) | 스마트플레이스 통계 화면 캡처 1장 | 사장님(월 1회 필수) — 연결돼 있으면 에이전트가 직접 |
| 포스 건수·객단가 | 포스 화면 캡처 또는 범위 | 사장님 (모르면 추정 유지) |
| 채널별 게시 수·반응 | 게시 기록(04-weekly ⑨)과 각 플랫폼 통계 | 에이전트 |
| 리뷰 수·최근 30일 리뷰·답글률·별점 | 플레이스 화면 (`guides/01-research.md` 1)) | 에이전트 |
| 핵심 검색어 노출 | `mk.py rank`(키) 또는 사장님 폰 검색 캡처 | 에이전트 |
| 손님 반응 한 줄 4개, "어떻게 알고 오셨어요?" 집계 | 매주 받은 것 | 에이전트가 모은다 |

- 반응은 총조회수보다 **비율**(도달 대비 저장·공유)로 본다.
- 순위 기록(`rank --log` CSV)은 `source` 열(api / screen)이 같은 행끼리만 비교한다. API 순서와 화면 순위는 다르다.
- 캡처를 못 받았으면 그 칸은 비우고 진행한다. 다음 달 첫 주에 다시 한 번만 요청한다.

## 2) 실험 판정

`guides/03-strategy.md` 9)에서 정한 실험 1개를 판정한다.

**첫 달에 기준값이 없으면**(①·④ 갈래, 숫자 답이 없던 가게) 판정하지 않는다. 이번 달 숫자를 **기준값으로 확정**해 프로필에 적고, 실험은 2달째에 시작한다. 첫 달 리포트에는 "판정: 기준값 확정"으로 쓴다.

1. 기간은 시작 전에 정한 그대로 본다(기본 전 4주 vs 후 4주, 월~일 꽉 찬 주). 중간에 끝내지 않는다.
2. 기준선 두 개와 비교한다: 직전 4주 평균, 요일 맞춘 지난해 같은 주(있으면). **둘 다 같은 방향일 때만** 인정한다.
3. 공휴일·날씨·동네 행사·배달앱 할인이 낀 주는 표시하고 뺀다.
4. 매출이 아니라 **이익**(할인·원가·추가 인건비를 뺀 것)으로 본다. 전·중·후 3구간으로 본다.
5. 아래 문턱으로 판정한다. 이 문턱은 작은 가게용 실무 기본값이다.

| 지표 크기 | 효과 있음(추정) | 약한 신호 | 판정 불가 |
|---|---|---|---|
| 주 30건 이상(방문·주문 등) | 4주 합계 **+20% 이상** | +10~20% → 4주 연장 | ±10% 안 |
| 주 30건 미만(리뷰·예약·문의 등) | **2배 이상** | 늘었지만 2배 미만 → 연장 | 그대로 |

- "효과 없음"이라고 쓰지 않는다. **"판정 불가"**로 쓴다(작은 숫자로는 없다고도 말할 수 없다).
- 숫자가 적으면 쿠폰 코드별 사용 수, "어떻게 알고 오셨어요?" 응답, 사장님 체감을 같이 적는다. 이것만으로 "효과 있음"을 주지는 않는다.
- 광고를 했다면: 광고 하나가 한 주에 결과(클릭·문의 등) 50건을 못 채우면 판정하지 않는다(광고를 합치거나 더 자주 일어나는 결과로 목표를 바꾼다). 광고를 켠 뒤 첫 1주는 플랫폼이 보여 줄 사람을 찾는 기간이라 고치지 않는다. 미리 정한 손님 1명당 비용 상한을 넘으면 멈춘다.

판정 결과는 셋 중 하나로 적는다: **계속 / 키우기 / 접기**. "판정 불가"가 두 번 연속이면 접고 다른 큰 변화를 고른다.

## 3) 채널 등급 조정

| 상황 | 조정 |
|---|---|
| 핵심 채널에서 행동 지표(길찾기·저장·문의)가 오름 | 유지. 되는 쪽에 더 건다(새 채널보다 먼저) |
| 확장 채널 반응이 핵심 채널보다 2달 연속 좋음 | 핵심으로 올린다 |
| 핵심 채널이 2달 연속 판정 불가 + 사장님 부담 큼 | 확장으로 내린다 |
| 확장 채널이 2달 연속 반응 거의 없음 | 제외하고 이유를 한 줄로 적는다 |
| 소재가 2주 이상 안 옴 | 채널 수를 줄인다(계획 크기 조정) |

## 4) 잘된 것·안 된 것 기록

1. 4주 게시물 중 반응 상위 3개, 하위 3개를 고른다.
2. 각각 왜 그랬는지 한 줄(주제·훅·사진·올린 시간 중 무엇이 달랐나). 팔로워가 많아서 나온 숫자는 이유로 쓰지 않는다.
3. 매주 ⑩(`guides/04-weekly.md`)에서 '추정'으로 올린 변주가 실제로 평균 이상이었는지 확인해 확정한다. 2번 이상 통한 첫 장면·형식은 프로필에 "우리에게 통하는 것"으로 적는다.
4. 상위 게시물이 쓴 레퍼런스는 브랜드 프로필 **레퍼런스 장부**에서 상태를 "잘됨"으로, 하위는 "안 됨"으로 바꾼다. 다음 기획에서 "잘됨"을 먼저 본다.
5. 반복 질문·불만이 새로 보이면 다음 달 소재 후보로 올린다. 같은 불만(맛·응대·위생)이 반복되면 본질 문제로 먼저 알린다.

## 5) 계획 크기 점검 (지속 가능한 양)

- 사장님이 실제로 쓴 시간이 주 1~2시간을 넘었는지, 소재가 제때 왔는지 본다.
- 넘쳤으면 줄인다. 늘리자는 제안은 숫자(이번 달 결과)와 함께만 한다.
- **하지 않을 것 1개**를 제안한다(예: "블로그는 반응이 없어서 다음 달엔 빼고 그 시간을 플레이스 소식에 쓸게요").

## 6) 다음 4주

1. 목표 유지 또는 교체(1~2개, 기준값·목표값·날짜).
2. 실험 1개(`guides/03-strategy.md` 9) 방식).
3. 연간 달력에서 다음 4주 + 그다음 2주 안의 시즌·행사(D-14~21 예열).
4. 다음 달 행사·신메뉴를 묻고 촬영 목록을 제안한다.
5. **첫 회고면** 온보딩에서 미룬 광고 예산을 한 번 묻는다: "한 달에 광고에 쓸 수 있는 돈이 있어요? ① 없음 ② 10만 원 안쪽 ③ 10~50만 원 ④ 그 이상" (`guides/03-strategy.md` 5-1)).
6. 3달마다: 플레이스 정보 전면 점검, 경쟁 3~5곳 다시 조사(`guides/01-research.md` 4)).

## 7) 1장 리포트 (사장님 문서에 추가, 매달 같은 날)

사장님께 가는 리포트는 판정·등급 같은 말 대신 쉬운 말로 쓴다(판정 '약한 신호' → "조금 나아진 것 같지만 확실하지 않아요", '판정 불가' → "아직 차이를 말하기 어려워요", 기준값 → 지금 숫자).
```
[11월 정리 — 11/18~12/15]
결과: 평일 점심 길찾기 주 [처음 숫자] → [지금 숫자]. 조금 나아진 것 같지만 확실하지 않아요. 4주 더 볼게요.
손님 행동: 게시물을 저장해 둔 사람이 늘었어요. 전화는 그대로예요. 최근 30일 리뷰 [n]개, 답글 [n]%
잘된 것: 크루아상 단면 릴스(저장 많음) — 완성된 빵을 첫 장면에 보여 줬어요
안 된 것: 블로그 메뉴 소개 — 검색에 안 떴어요
다음 달: 네이버 클립에 더 힘줄게요. 블로그는 쉬어요.
다음 4주: 연말 선물 세트(3주 전부터 알림), 이번에 새로 해 볼 것 = 알림받기 쿠폰 1회
하지 않을 것: 블로그 메뉴 소개 글
```
채팅에는 링크와 3~5줄 요약만 보낸다.
