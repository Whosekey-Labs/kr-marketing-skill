# 고쳐 달라는 말 예시

결과가 마음에 안 들 때 사장님께 보여 줄 예시. 사장님께 보여 줄 때는 이 중 그 결과물에 맞는 2~3개만 고른다. 비슷한 요청이 오면 그 결과물이나 그 단계만 다시 한다(처음부터 다시 하지 않는다).
"앞으로는", "항상", "계속"이 붙거나 같은 수정을 두 번 하면 브랜드 프로필의 "내 요청사항"에 한 줄로 저장하고 "기억해 둘게요"라고만 말한다(SKILL 규칙 6). 예: "앞으로 이모티콘은 빼줘", "가격 할인 얘기는 항상 빼줘".

## 글 (블로그·소식·캡션)
- "더 짧게" / "사진 위주로, 글은 조금만"
- "말투 더 친근하게" / "좀 더 점잖게"
- "첫 문장을 손님 질문으로 시작해줘"
- "주차랑 오시는 길도 넣어줘"
- "이모티콘 빼줘" / "해시태그 빼줘"

## 카드뉴스
- "글자 더 크게, 장수는 줄여서"
- "우리 간판 색으로" / "간판 색 말고 새로 잡아줘" / "더 차분한 색으로"
- "사진을 크게, 글은 아래 한 줄만"
- "마지막 장에 예약 방법 넣어줘"
- "다른 스타일로도 하나 보여줘" / "좀 더 고급스럽게" / "동네 가게답게 편하게"

## 숏폼
- "첫 장면을 완성된 빵으로 바꿔줘"
- "자막 더 크게, 더 짧게"
- "음악 없이" / "좀 더 빠르게 잘라줘"
- "내 얼굴은 안 나오게"

## 계획·전략
- "이번 달 목표를 단골 쪽으로 바꿔줘"
- "인스타는 빼고 플레이스·당근만"
- "일주일에 한 번만 올려줘" / "사진 보내기 힘들어, 양 줄여줘"
- "이번 주는 크리스마스 세트 위주로"
- "광고도 조금 해 볼까?" / "광고는 하지 마"

## 올리기·확인
- "올리기 전에 꼭 나한테 보여줘" / "이제 알아서 올려줘"
- "블로그는 저녁에 올려줘"
- "월요일마다 알아서 이번 주 할 일 알려줘" (예약 실행이 되는 앱이면 걸어 둔다)

## 리뷰 답글·메시지
- "답글 더 짧게" / "사과를 더 정중하게"
- "쿠폰 얘기는 빼고 소식만 보내줘"
- "리뷰 많이 받는 방법 알려줘" (리뷰 이벤트는 먼저 권하지 않는다 — `guides/08-operations.md`)

## 프로필
- "우리 가게 정리 문서 보여줘" / "쓰지 말 말에 '최고' 추가해줘"
- "이 계정 참고용으로 저장해줘" / "이 가게처럼은 하지 마"

## 바로 들어줄 수 없는 요청이 올 때 (에이전트가 답하는 틀)
거절만 하지 않는다. **안 되는 것 한 줄 → 이유 한 줄(업종 광고 규칙 파일 근거) → 대신 할 수 있는 것**. 같은 요청이 다시 와도 같은 답을 하고 프로필 '내 요청사항'에는 저장하지 않는다.
- "협찬 표시 빼줘" → "표시는 뺄 수 없어요(광고 규칙). 대신 짧고 눈에 덜 거슬리게 넣을게요." (근거: `guides/compliance/common.md` 2-2. 대가 표시 — 추천·보증 심사지침 Ⅴ.6 경제적 이해관계 표시, 게시물마다 제목·첫 부분)
- "우리가 ○○ 1등이라고 써줘" → "근거 자료가 있어야 쓸 수 있어요. 자료를 보내 주시면 넣고, 그 전엔 '○○ 출시'처럼 사실로 쓸게요."
- "가격은 DM으로만" → 업종 검수표가 가격 표시를 요구하면 그대로 알리고, DM은 상담·예약 창구로 안내한다.
