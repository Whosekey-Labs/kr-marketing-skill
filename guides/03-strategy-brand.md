# 3-1. 브랜드 성격 카드 → 실제로 바뀌는 칸

3단계 4-1)에서 성격 카드를 정할 때, 그리고 **첫 제작(블로그·카드뉴스·숏폼) 전 갈림 점검** 때 연다. **업종 파일 기본값보다 이 표가 우선한다.**
코드 뜻: 문체 V는 `guides/styles/blog.md` 4), 카드 구성 C·스타일 S는 `guides/styles/cardnews.md` 2)·4), 숏폼 느낌은 `guides/styles/shortform.md` 5), 블로그 유형 B는 `guides/styles/blog.md` 1).

## 1) 카드 유형별 기본값 (상권·가격·손님 관계로 열을 고른다)

| 칸 | 동네형 (동네·저가~중간·단골) | 목적지형 (일부러 찾아옴·프리미엄·경험) | 전문형 (병의원·세무·학원·인테리어 등) | B2B형 (매장 없음·기업 고객, 업종 07·23·24·25) |
|---|---|---|---|---|
| 문체 V | V2 친근(화자 '저희', 이모티콘 조금) | V3 담백(화자 가게 이름, 이모티콘 없음, 짧은 문장) | V1 전문가 칼럼형(실명 원장·대표) | V1 또는 V3(화자 대표·회사 이름) |
| 카드 스타일 S | S07·S05·S04 | S09·S03·S01 | S05·S03 | S05·S10 |
| 숏폼 느낌 | 잔잔하게(`theme: "warm"`) 또는 빠르고 신나게 | 잔잔하게 | 정보 또박또박(`theme: "info"`) | 정보 또박또박 |
| 사진 톤 | 밝고 가깝게, 손·진열대·오늘 나온 것 | 단면·질감 한 컷, 옆에서 드는 빛, 여백 넓게 | 공간·도구·과정, 정돈된 정면(의료 전후 사진은 검수표 먼저) | 작업 화면·결과 자료·대표 얼굴(동의) |
| 제목 공식 (지금 올 이유를 넣는다, `guides/03-strategy.md` 1-1)) | {동네}+{시간}+{그때만 있는 것}: "[동네] 오후 3시, [상품] 두 번째로 나와요" | {상품 이름}+{출시일·한정}: "[상품 이름], [날짜] 출시" | {상황 질문}: "[상황]일 때 [무엇]부터 확인하세요" | {대상}+{문제}+{손님이 얻는 숫자·결과}: "[대상]이 [문제]로 쓰던 [시간·돈]을 줄이는 [n]가지", "[대상] [일], 주 [n]시간이면 끝나요" — 숫자는 손님 쪽(줄어든 시간·돈·결과), 우리 쪽 숫자(질문 수·기능 수) 아님 |
| 색·제목 글씨 | 따뜻하고 진한 색 1개를 면으로, 굵은 고딕·손글씨 | 무채색 넓게 + 강조 1곳, 명조(고운바탕) | 차분한 색, 굵은 고딕 | 차분한 색 1개 + 먹색, 굵은 고딕 |
| 채널 | 플레이스·알림받기·당근 | 인스타·릴스 > 플레이스 | 업종 파일 순서 | 업종 파일 순서(홈페이지·플랫폼 상품 페이지) |
| 성과 숫자 | 재방문, 알림받기 수, 쿠폰 회수 | 저장·공유 비율, 지역 밖 길찾기, 웨이팅 | 예약·문의 | 상담 신청·문의 |

- **혼합·중간**이면 동네형과 목적지형 사이: V3 또는 V2, S02·S05 기본 고딕, 플레이스 + 인스타, 길찾기·저장.

## 2) 분위기 형용사 3개 → 같은 열 안에서 어느 칸이 바뀌나

형용사는 장식이 아니다. **형용사마다 아래 칸 중 최소 1개를 바꾼다.** 근거는 사장님 말·리뷰 말에서 나온 형용사뿐이다. 없는 형용사를 지어내지 않는다.

| 형용사(예) | 문체 | 카드 스타일 | 숏폼 느낌 | 사진 톤 | 제목·문장 |
|---|---|---|---|---|---|
| 따뜻한·다정한 | V2 쪽 | S07·S04 | 잔잔하게, `theme: "warm"` | 사람 손·밝은 자연광, 가깝게 | 오늘 일·인사로 시작 |
| 소박한·정직한 | V3·V4 쪽 | S01·S05 | 잔잔하게 | 보정 적게, 있는 그대로 | 가격·수량을 숫자 그대로, 꾸밈 단어 0개 |
| 차분한·세련된·고급스러운 | V3 | S09·S03 | 잔잔하게, 장면 길게 | 한 컷에 하나, 여백 넓게 | 짧게 끊음, 형용사 1개 이하 |
| 활기찬·유쾌한 | V2(캐릭터 V5는 실험, 의료·법률·부동산 제외) | S08·S10 | 빠르고 신나게 | 사람·움직임, 여러 컷 | 질문·숫자로 시작 |
| 꼼꼼한·믿음직한·전문적인 | V1 | S05 | 정보 또박또박, `theme: "info"` | 과정·도구·결과 기록 | 근거·순서·숫자 |
| 감각적인·트렌디한 | V3 | S02·S03 | 빠르고 신나게 또는 잔잔하게 | 색감 통일, 구도 반복 | 상품 이름 먼저 |

- 1)에서 고른 열이 기본이고, 형용사는 그 열 안에서 후보를 고르거나 칸을 하나씩 옮긴다(예: 동네형 + '차분한' → S07 대신 S05, 이모티콘 0개).
- 형용사 3개가 서로 다른 줄을 가리키면 **사장님이 직접 말한 형용사**를 먼저 따른다. 의료·법률·금융 업종은 업종 검수표가 형용사보다 우선한다.

## 3) 같은 업종 두 가게가 이렇게 달라야 한다 (예: 빵집·디저트)

같은 업종이면 업종 기본값(미색 배경 + 갈색 강조 + 굵은 고딕, 정보 표 + 지도)으로 수렴하기 쉽다. 카드가 다르면 아래 칸이 **실제로 달라야** 한다.

| 칸 | 동네형 빵집 (거의 단골, 1~3만 원, 빈 시간 채우기, 형용사: 따뜻한·소박한·정직한) | 목적지형 디저트 카페 (거의 처음, 주말 웨이팅, 형용사: 차분한·세련된·감각적인) |
|---|---|---|
| 화자·첫 문장 | "저희" + 오늘 일: "오늘 [빵 이름] [시간]에 나와요." | 가게 이름 + 한 장면: "[가게 이름]의 겨울은 [재료]로 시작합니다." |
| 문장 | 해요체, 말하듯, 이모티콘 1~2개, 시간·요일 구체적 | 짧게 끊음, 이모티콘 없음, 형용사 1개 이하, 해요·합니다 섞음 |
| 제목 공식 | "[동네] 오후 3시, [빵 이름] 두 번째로 나와요"(갓 나온 시간) | "[상품 이름], [날짜] 출시 · 하루 [n]개"(한정) |
| 블로그 유형 | B10 이용 안내·B06 사장님 일기 (짧고 자주) | B09 신메뉴·B11 만드는 방식 (사진 위주, 공들여) |
| 카드뉴스 | C12 일상·C02 가격표, 표지 S07·본문 S05, 장 수 3~5 | C01 출시, 표지 S09(사진)·본문 S03, 장 수 5~6 |
| 숏폼 | 잔잔하게 `warm`, 오늘 나온 빵·진열대 | 잔잔하게, 단면 한 컷씩 길게 |
| 색 방향 | 따뜻하고 진한 색 1개를 면으로 크게(밀 노랑·벽돌색), 배경 흰색 | 무채색 넓게(흰·회색·먹색) + 강조 1곳만, 여백 많이 |
| 제목 글씨 | 굵은 고딕 또는 손글씨(S07) | 명조(고운바탕) |
| 사진 | 진열대·손·오늘 나온 빵, 밝고 가깝게 | 단면·질감 한 컷, 옆에서 드는 빛, 여백 넓게 |
| 마지막 할 일 | "알림받기 해 두시면 갓 나온 시간 알려 드려요" | "저장해 두고 주말에 들러 주세요", 웨이팅 안내 |
| 힘줄 곳 | 플레이스 소식·알림받기·당근 | 인스타 릴스·캐러셀 > 플레이스 |
