# 카드뉴스 (단독 사용)

전체 마케터 스킬의 카드뉴스 부분만 쓴다. 원문 주소 앞부분(BASE): `https://raw.githubusercontent.com/Whosekey-Labs/kr-marketing-skill/main/`

## 순서

1. 업종을 확인하고 `guides/compliance/index.md`에서 규제 플래그를 고른다. `guides/compliance/common.md`는 모든 업종에 열고, 법규에 걸리는 업종이면 해당 플래그 파일도 연다.
2. 유형·스타일을 고른다: `guides/styles/cardnews.md` (업종 추천 3~4개만 보여 준다).
3. 만든다: `guides/make/cardnews.md` — 같은 업종 레퍼런스 3~5개(디자인 문법 표) → 원고 → 시안 2안(레퍼런스 기반 / 가게 색 살리기) → 렌더 → 점검 → 캡션.
4. 렌더러(0.4.0): `BASE + tools/cardnews.py`를 받아 `python3 cardnews.py render spec.json -o out/`. 원고 칸·시각 앵커: `guides/make/cardnews-spec.md`. 견본: `examples/cardnews-spec-sample.json`(빵집 신메뉴), `examples/cardnews-spec-faq-sample.json`(B2B 자주 묻는 질문, 장마다 다른 앵커).
5. Pillow가 없으면 사장님께 묻지 않고 차례로: ① `pip install pillow` 시도 → ② `--html`로 만들어 네 브라우저로 캡처 → ③ 장별 원고+디자인 지시를 주고 사장님이 미리캔버스·캔바로 만들게 안내.
6. 브랜드 프로필이 없으면 최소 프로필(업종·규제 플래그·말투 한 줄·금지 표현·사실 자료)만 만들고 바로 만든다.

## 꼭 지킬 것 (지침을 못 열어도)

- 내보내기 전에 항상 `guides/compliance/common.md`(모든 업종) + 이 업종 플래그 파일을 열어 검수한다(전체 스킬 `SKILL.md` 규칙 4). 스크립트 모드면 `python3 mk.py lint`도. 결과 끝에 `검수: 연 파일 이름` 한 줄, 못 열었으면 '검수 안 됨'으로 표시하고 올리지 않는다.
- 1080×1350 JPEG, 장당 8MB 이하, 10장 이하. 핵심 글자는 가운데 1080×1080 안. 로고·워터마크는 넣지 않는다.
- 표지 제목 12~19자, 본문 장당 80자 안팎(권장), 마지막 장은 행동 1개(예약·방문·저장). 그 바로 앞에 저장용 요약 장(체크리스트).
- 장마다 숫자나 예 하나 + 시각 앵커 하나(`anchor`: number·icon·flow·vs·button·chips·table·timeline). 같은 레이아웃·같은 바탕이 이어지지 않게 `tone`(light·dark·brand·deep)을 섞는다.
- 디자인은 사장님 홈페이지·로고 색을 기본으로 따르지 않는다. 시안은 늘 2안: 1안 레퍼런스안(고르기 전 기본), 2안 기존 가게 색 살린 안. 사장님께는 번호로 고르게 한다.
- 본문 최소 40px, 장 제목·질문 96~112px, 표지 제목은 렌더러가 자동 크기. 본문은 위에서부터 채운다. 글자 대비 4.5:1 이상. 렌더 점검의 '고칠 것'(`[직접 입력]` 빈칸 포함)을 0으로 만들고, 이미지를 직접 열어 보고 고친다.
- 사진은 문구와 맞아야 한다. 안 맞으면 문구를 사진에 맞춰 바꾸지 않고 '사진 필요'로 두고(`photo_hint`, 다른 점은 `photo_match`) 사장님께 그 장 사진을 부탁한다. 사진이 필요한 장은 원고에 표시한다.
- 사장님 실제 사진이 먼저다. 실제 매장·상품·사람처럼 보이는 AI 이미지는 만들지 않는다. 누가 봐도 그림(일러스트·아이콘·패턴 배경)만 장식용으로 쓰고, 한글은 렌더러로 쓴다. 의료 전후사진은 기본으로 권하지 않는다(원장님이 원하면 guides/compliance/medical.md 전후사진 점검표를 모두 채우고 사전심의를 거친 경우만).
- 가격·기간·효능·후기는 지어내지 않는다. 모르면 `[직접 입력: …]`.
- 가게 조사·4주 계획까지 하려면 전체 스킬 `SKILL.md`를 연다.
