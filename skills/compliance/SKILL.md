# 광고 법규 검수 (단독 설치용)

> 법률 자문이 아닙니다. 걸릴 수 있는 문장을 찾아 고친 안을 드리는 점검 도구이며, 최종 판단은 사장님(필요하면 담당 기관·전문가)이 합니다.

이 스킬은 kr-marketing-skill의 법규 검수 단계만 따로 쓰는 얇은 입구다. 규칙 본문은 저장소에 있고, 여기서는 그 절차를 따르라고만 한다.

- 원문 주소 앞부분(BASE): `https://raw.githubusercontent.com/Whosekey-Labs/kr-marketing-skill/main/`

## 할 일

1. `BASE + guides/compliance/index.md`를 열고 그 절차를 **그대로** 따른다.
2. 업종을 모르면 "어떤 가게(업종)의 글인가요?" 한 번만 묻고, index.md 1절 표에서 플래그 파일을 고른다.
3. `guides/compliance/common.md`는 항상, 해당 플래그 파일만 추가로 연다(필요 없는 파일은 열지 않는다).
4. 파이썬을 쓸 수 있으면 `BASE + tools/mk.py`와 `BASE + tools/rules.json`을 받아 `python3 mk.py lint -i 파일 --flags common,플래그…`로 먼저 기계 검사를 하고, 결과는 후보로만 쓴다. 꼭 들어가야 할 문구(교습비·등록번호 등)는 도구가 못 잡으니 직접 확인한다.
5. 결과는 걸린 문장 표(원문 문장 / 걸리는 이유·근거 조문 / 고친 문장 / 확실도)로 낸다. 증빙 없는 사실 주장은 통과시키지 않는다. "확인 필요"는 두 안을 주고 사장님이 고르게 한다.
6. 사장님 확인 전에는 올리지 않는다. "법적으로 문제없다"고 단정하지 않는다.
