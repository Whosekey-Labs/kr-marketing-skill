# 블로그 글 (단독 사용)

전체 마케터 스킬의 블로그 부분만 쓴다. 원문 주소 앞부분(BASE): `https://raw.githubusercontent.com/Whosekey-Labs/kr-marketing-skill/main/`

## 순서

1. 업종을 확인하고 `guides/compliance/index.md`에서 규제 플래그를 고른다. `guides/compliance/common.md`는 모든 업종에 열고, 법규에 걸리는 업종이면 해당 플래그 파일도 연다.
2. 유형·말투를 고른다: `guides/styles/blog.md`
3. 네이버 글을 쓴다: `guides/make/blog-naver.md` + 고른 유형의 줄만 `guides/make/blog-naver-types.md`
4. 발행 뒤 노출이 확인되면(24시간 이상 뒤) 티스토리용을 새로 쓴다: `guides/make/blog-tistory.md`

## 꼭 지킬 것

- 내보내기 전에 항상 `guides/compliance/common.md`(모든 업종) + 이 업종 플래그 파일을 열어 검수한다(전체 스킬 `SKILL.md` 규칙 4). 스크립트 모드면 `python3 mk.py lint`도. 결과 끝에 `검수: 연 파일 이름` 한 줄, 못 열었으면 '검수 안 됨'으로 표시하고 올리지 않는다.
- 가격·영업시간·경험담·수치는 지어내지 않는다. 모르면 `[직접 입력: …]`. 분량은 권장값이다. 소재가 모자라면 짧게 내고 필요한 소재를 부탁한다.
- 브랜드 프로필이 없으면 최소 프로필(업종·규제 플래그·말투 한 줄·금지 표현·사실 자료)만 만들고 바로 쓴다.
- 실제 매장·음식·사람처럼 보이는 AI 이미지는 쓰지 않는다. 의료 전후사진은 기본으로 권하지 않는다(원장님이 원하면 guides/compliance/medical.md 전후사진 점검표를 모두 채우고 사전심의를 거친 경우만).
- 남의 글 문장·사진을 베끼지 않는다. 구조만 빌린다.
- 네이버 블로그는 한 계정에 하루 1편. "지역+업종, ~할까요?" 제목 틀을 기본으로 쓰지 않는다.
- 가게 조사·4주 계획까지 하려면 전체 스킬 `SKILL.md`를 연다.
