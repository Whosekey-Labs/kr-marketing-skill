# 짧은 소식 · 리뷰 답글

- 원문 주소 앞부분(BASE): `https://raw.githubusercontent.com/Whosekey-Labs/kr-marketing-skill/main/`
- 본문 지침: `BASE + guides/make/local-posts.md`를 열어 그대로 따른다.
- 올릴 때: `BASE + guides/upload/index.md` → 해당 플랫폼 파일 하나만.

## 꼭 지킬 것 (지침을 못 열어도)
0. 내보내기 전에 항상 `guides/compliance/common.md`(모든 업종) + 이 업종 플래그 파일(`guides/compliance/index.md`에서 고름)을 열어 검수한다(전체 스킬 `SKILL.md` 규칙 4). 결과 끝에 `검수: 연 파일 이름` 한 줄, 못 열었으면 '검수 안 됨'으로 표시하고 올리지 않는다.
1. 가격·기간·수량·영업시간은 사장님 자료로만. 없으면 `[직접 입력: …]`.
2. 리뷰는 먼저 갈래를 나눈다: 칭찬 / 불만(공감 → 사실 확인 → 조치) / 악성(신고: 스마트플레이스 → 권리침해 신고 → 권리보호센터) / 위생·안전(마케팅 금지, 사장님께 즉시).
3. 네이버 사업주 답글은 리뷰 1개당 1개. 리뷰 쓴 손님에게 따로 연락해 삭제를 부탁하지 않는다.
4. 리뷰 이벤트는 먼저 권하지 않는다. 사장님이 원하면 허용 조건(실제 결제 영수증, 별점·내용 관여 금지)과 금지 행위(별점·표현 요구, 화면 확인·대신 작성, 저가 영수증, 대행·리워드 앱 — 한 번 걸리면 리뷰 전체가 안 보일 수 있음, 네이버 공지 957 2026-01)를 알리고 진행. 병의원·의료로 오인될 업종은 금지.
5. 재방문 메시지: `(광고)`, 보내는 사람·연락처, 무료 수신거부, 10~20시. 사전 동의한 사람만. 발송은 사장님.
6. 사장님 계정에 올리기·예약·삭제는 첫 업로드 직전에 정한 승인 방식(매번 확인 / 처음 몇 주만 확인 / 알아서)을 따른다.
7. 실제 매장·상품·사람처럼 보이는 AI 이미지, 로고·워터마크는 넣지 않는다.
