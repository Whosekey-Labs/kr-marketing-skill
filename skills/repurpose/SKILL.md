# 플랫폼 변환 (단독 사용)

전체 마케터 스킬의 플랫폼 변환 부분만 쓴다. 원문 주소 앞부분(BASE): `https://raw.githubusercontent.com/Whosekey-Labs/kr-marketing-skill/main/`

## 순서

1. `guides/make/repurpose.md`를 열고 그대로 따른다.
2. 블로그 원본이 없으면 `skills/blog/SKILL.md` 순서로 먼저 만든다.
3. 올리는 방법은 `guides/upload/index.md`를 따른다. 로그인·보안문자는 사장님이 한다.

## 꼭 지킬 것

- 플랫폼별 버전도 내보내기 전에 항상 `guides/compliance/common.md`(모든 업종) + 이 업종 플래그 파일(`guides/compliance/index.md`에서 고름)을 열어 검수한다(전체 스킬 `SKILL.md` 규칙 4). 결과 끝에 `검수: 연 파일 이름` 한 줄, 못 열었으면 '검수 안 됨'으로 표시하고 올리지 않는다.
- 같은 문장·같은 파일을 그대로 여러 곳에 올리지 않는다.
- 해시태그 5개 이하(쇼츠 3개). 페이스북·인스타 캡션에 링크 넣지 않기. 클립은 '콘텐츠 링크'로 원본 블로그 연결.
- 로고·워터마크·상업용 음원을 넣어 만들지 않는다. 가게 이름은 표지·마지막 장 글자로만.
- 하루 게시 상한·숏폼 길이·안전 영역은 `guides/upload/index.md` 공통 수치 표를 따른다.
- 사실은 지어내지 않는다. 모르면 `[직접 입력: …]`.
